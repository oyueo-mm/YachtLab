# YachtLab v0.4 기보와 공통 전략 평가

기보는 `format: YachtLabReplay`, `version: 1`, `metadata`, `initialState`, `frames`, `finalState`로 구성한다. 규칙 버전은 `YachtLab-12-v1`이다. 프레임은 실제 행동, 행동 전 플레이어, 행동 후 전체 Game 스냅샷과 선택적으로 AI 판단을 기록한다. 고유 주사위 ID, 표시 순서, 고정 상태, 두 RNG 스트림, 점수판을 함께 보존한다. 보너스와 총점은 기존 엔진 함수로 계산한다.

외부 파일은 최대 8MiB, 최대 4096프레임으로 제한한다. 처음 시드에서 `createGame`을 실행하고 모든 행동을 `transition`으로 재생한다. 각 스냅샷과 최종 상태의 모든 필드가 계산 결과와 일치해야 한다. 잘못된 버전·행동·점수·난수·주사위는 거부한다. AI 판단 메타데이터는 실제 행동과 일치해야 하며 게임을 제어하지 않는다. 기존 v0.3의 Match 내보내기도 이 검증을 거쳐 변환한다.

기보 뷰어는 live Game과 별개의 복사본을 탐색한다. AI 행동 중 열면 진행을 일시정지하며 닫은 뒤 다시 이어간다. 가져온 JSON으로 live Game을 덮어쓰지 않는다. 재생은 저장된 스냅샷만 표시하며 난수를 다시 뽑지 않는다. 탭이 숨겨지면 자동 재생과 사람 대전의 행동 간 대기를 멈춘다.

로컬 저장소는 IndexedDB `YachtLabReplays`, object store `replays`, key path `metadata.id`다. 저장·목록·이름 변경·삭제 및 JSON 왕복을 제공한다. transaction 완료 이후 성공을 표시하며 저장 실패는 오류로 보여준다. 브라우저 데이터는 삭제될 수 있으므로 JSON 백업 기능도 제공한다.

분기 시 원본을 검증하고 IndexedDB에 보존한다. 선택한 프레임의 Game 복사본으로 `simulateFromState`를 실행한다. 고정을 이미 결정한 프레임이면 그 고정을 유지한 재굴림부터 진행한다. 새 기보는 원래의 초기 상태와 선택 프레임까지의 행동 전체를 유지하고, 이후 새 AI의 행동을 붙인다. `metadata.source`는 원본 ID와 프레임 번호를 기록한다. 새 AI 설정과 과거 프레임의 실제 행위자 이름을 구분한다. 종료된 프레임은 이어하기를 비활성화한다.

`dpActionValues`는 44개 행동의 동일한 DP 기준 Q값을 계산한다. 0~31은 고유 ID 고정 비트마스크, 32~43은 카테고리 기록이다. 불법 행동은 −Infinity로 마스킹한다. 기록은 현재 총점 + 획득 점수 + 보너스 증가 + 남은 카테고리 DP 미래 가치, 재굴림은 현재 총점 + 현재 턴의 남은 굴림에 대한 정확한 확률 합산이다. 고정한 눈의 멀티셋이 같으면 대칭 ID 행동의 가치도 같다.

분석실의 손실은 `max_a Q_DP(s,a) − Q_DP(s,선택)`이다. 선택 후에는 최적 DP 정책을 따른다는 단독 기대 총점이며 상대 승률이나 해당 AI가 끝까지 플레이했을 때의 예측 총점이 아니다. 실제 기보 행동은 행동 직전 상태에서 평가한다. 입력을 수정하면 가상 분석으로 구분하고 실제 행동 비교를 제거한다. AI 자체 확률·휴리스틱 효용과 공통 DP 점수를 따로 표시한다.
