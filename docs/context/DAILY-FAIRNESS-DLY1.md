# DLY-1 — 오늘의 요트 일일 랭킹 공정성 개선 연구 (2026-11-28, SEC-1 2차 감사 후속)

> **상태(갱신): 소유자가 대안 B(같은 주사위 비경쟁)를 채택했다 → D-141.** 경쟁 순위 연구(E1~E5)는 보류한다. `DAILY = "off"` 유지.
> 감사 재현: 정찰 계정 1판으로 테이프 180면 전체 확보, 완전정보 플레이 60일 평균 248.1점(sd 34.8)으로 정직한 최적 약 191.8점 대비 +56점(SEC-1 2차 DLY-1).
> 기준: INT-1 통합 트리(LIVE-1 #142 설계, D-117~D-122). 게임 규칙은 12칸 Nintendo-style Yacht Dice.

## 1. 현재 구조에서 생기는 경쟁상 이점

LIVE-1은 모든 참가자에게 같은 주사위를 준다. 주사위 눈은 위치 `face(날짜, 라운드, 굴림, 주사위 칸)`로 정해지므로, 누가 무엇을 고정하든 같은 위치에서는 같은 눈이 나온다(D-117). 그 결과 다음 성질이 생긴다.

- **위치 정보는 재사용할 수 있다.** 한 번 본 위치의 눈은 그날 다른 계정에서도 같다. 그날 키는 마감 전까지 비밀이지만, 플레이하면서 본 눈 자체는 감출 수 없다.
- **탐색 비용이 낮다.** 한 판에서 볼 수 있는 위치는 최대 12라운드 × 3굴림 × 5칸 = 180개다. 매 굴림에 주사위를 모두 다시 굴리는 "탐색용" 플레이 한 번이면 그날 테이프 전체를 볼 수 있다.
- **이점의 경로**는 세 가지다.
  1. 다른 계정으로 먼저 플레이(다중 계정)
  2. 먼저 플레이한 친구가 공유
  3. 같은 날 재도전(DLY-2, 이번 후속에서 차단)
- **현재 완화책:**
  - 당일 가입 계정은 순위 제외(`DAILY_NEW_ACCOUNTS_RANKED = "off"`)
  - 참가 상한
  - 공식 도전은 계정당 1회
  - 탈퇴 후 같은 날 재도전 차단(DLY-2)
- **남는 문제:** 미리 만들어 둔 오래된 계정과 친구 사이 공유는 막지 못한다.

정보를 가진 쪽은 각 굴림의 결과를 미리 알고 판단한다. 그러면 기대값 기준 최적 전략(DP Expert, 테이프 평균 191.98점)보다 훨씬 높은 점수를 노릴 수 있다. 이점의 크기는 아래 §3 실험으로 잰다. 측정 전이므로 이 문서는 수치를 추정해서 적지 않는다.

## 2. 대안 비교

| 대안 | 공정성(정보 공유 내성) | 재미 | 운의 영향 | 악용 가능성 | 서버 비용 | 구현 난이도 |
|---|---|---|---|---|---|---|
| **현행** 같은 테이프 + 원점수 순위 | 낮음: 본 위치를 공유·재사용 가능 | 높음: "같은 조건" 비교, 공유 이미지 | 같은 조건이라 비교 안에서는 0, 하루 간 차이는 큼 | 다중 계정·친구 공유 | 기준(공식 1판 ≈ 37요청, ≈ 42행) | — |
| **A. 계정별 독립 테이프** (그날 키 + 계정 ID → 계정 키) | 높음: 남의 정보가 쓸모없음 | 중간: "같은 주사위" 이야기가 사라짐 | **큼**: 순위가 운에 크게 좌우됨 | 여러 계정 중 운 좋은 결과 고르기(계정 수만큼 시도) | 현행과 같음 | 낮음: 키 유도·확인값을 계정별로 |
| **B. 같은 테이프 비경쟁** (순위 없음, AI 기준 점수·분위만 표시) | 경쟁 자체가 없어 무관 | 중간: 공유·비교는 남고 경쟁은 없음 | 무관 | 경쟁 동기 없음 | 현행보다 적음(보드 쓰기 감소) | 낮음: 순위 화면을 기준 점수 표시로 |
| **C. 여러 경기 합산** (예: 3판 합계 또는 최고점) | 같은 테이프면 낮음, 계정별 테이프면 높음 | 중간: 참여 시간 증가 | 판 수의 제곱근만큼 감소(3판 ≈ 0.58배) | A와 같음(계정별 테이프일 때) | 판 수 × 현행(3판 ≈ 111요청, ≈ 126행) | 중간 |
| **D1. 판단 정확도 순위** (DP 후회 합계: 각 결정에서 DP Expert 최선 행동과의 기대값 차이) | 높음: 미래 눈을 알아도 기대값 기준 후회는 줄지 않음(오히려 늘 수 있음) | 중간~높음: "실력 점수", 결정별 해설과 연결 | **거의 0**: 결과가 아닌 결정을 평가 | 외부 DP 도구로 결정을 대신 고르기(엔진 보조) | 결정마다 DP 값 계산(테이블·CPU 측정 필요) | 높음: 서버에서 DP 값 평가, 번들·CPU 한도 확인 |
| **D2. 동시 시작 창** (정해진 시간대에만 공식 도전) | 중간: 친구 공유는 줄지만 다중 계정은 남음 | 낮음: 시간 제약 | 현행과 같음 | 다중 계정 | 현행과 같음(순간 부하 증가) | 중간 |

**조합안(권장 후보, 승인 필요):** 계정별 독립 테이프(A)와 판단 정확도 순위(D1)를 함께 쓴다. 원점수는 개인 기록으로만 보여 준다. A로 정보 공유를 무력화하고, D1으로 A가 키운 운의 영향을 없앤다.
- 남는 악용은 엔진 보조다. 이것은 기존 온라인 대전과 같은 문제라 별도 정책으로 다룬다.
- 대안으로 B(비경쟁)는 구현 비용이 가장 낮고 공정성 문제가 사라진다. 대신 랭킹 재미를 포기한다.

## 3. 정량 검증 방법 (기존 SEC-1·LIVE-1 실험 기준)

기존 실험 기반을 재사용한다.
- LIVE-1 200일 테이프 측정(DP 최적 평균 191.98, DP 기대 191.76)
- `scripts/daily/` 테이프 생성
- `dpActionValues`(DP Expert 행동 가치)

| 실험 | 내용 | 지표 |
|---|---|---|
| E1 정보 이점 | 같은 테이프에서 (a) DP Expert, (b) 테이프 전체를 아는 탐색 플레이(테이프 조건부 결정 문제를 빔 탐색 또는 분기 한정으로 최적화), (c) 일부 위치만 아는 경우(친구가 본 위치 수 k = 30·60·90·180) | 평균 점수 차와 근사 95% 신뢰구간, 참가자 분포에서 1위·상위 10% 진입 확률 |
| E2 운의 몫 | DP Expert를 서로 다른 테이프(현행·A)에서 반복 | 점수 분산 분해(테이프 간 대 전략 간), 실력 순서와 순위의 Kendall τ |
| E3 대안별 순위 안정성 | 실력이 다른 정책 묶음(DP Expert, 기존 약한 AI 단계들)을 현행·A·C(3판)·D1 방식으로 순위화 | 진짜 실력 순서 복원율(Kendall τ), 상위권 뒤집힘 빈도 |
| E4 D1 내성 | 정보 이점 플레이(E1-b)의 DP 후회 합계 | 후회 합계가 DP Expert보다 작아지지 않는지(정보 이점이 순위에 반영되지 않는지) |
| E5 비용 | 대안별 공식 1판 요청 수·SQLite 쓰기·CPU(D1은 결정당 DP 평가 시간) | Workers Free 한도 대비 비율 |

보고 규칙(AGENTS.md):
- 규칙: 12칸 Yacht Dice
- 시드: 개발 시드로 표시. 학습·선택에 쓴 시드를 홀드아웃이라 부르지 않는다
- 반복 수, 근사 신뢰구간, 평균 점수, 실행 비용
- 승패를 비교할 때는 무승부를 0.5로 센다

## 4. 결정이 필요한 것 (사용자)

1. 일일 랭킹의 목표: 같은 조건의 원점수 경쟁(현행), 판단 정확도 경쟁(D1), 또는 비경쟁(B)
2. A(계정별 테이프)를 쓰면 "모두 같은 주사위"라는 소개와 공유 문구를 바꿔야 한다
3. E1~E5 실험을 실행할지와 그 비용(계산 자원). 실행해도 운영 데이터는 쓰지 않는다

`DAILY`와 관련 랭킹 활성화는 결정과 검증이 끝날 때까지 보류한다.
