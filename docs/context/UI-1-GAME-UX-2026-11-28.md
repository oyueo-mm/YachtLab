## 1. 경기 화면·점수판
**원인(재현):** 로컬 다인전 데스크톱(2인 포함, 768·1280px)에서 점수 버튼이 약 10px 폭으로 줄어 족보 이름(하단 족보의 주사위 그림 포함) 위에 겹쳤다. `.scoreboard .score-option { width: auto }`(table-v4) + `.multi-scoreboard.compact .score-option { padding: 2px 0; min-width: 0 }`(multi-compact)가 겹쳐 `<button>`이 내용 폭으로 수축한 것. 스크린샷 `docs/ui/ui1-2026-11/before-local*`.

**공통 점수판(`src/MultiScoreboard.tsx`, `src/ui/sheet-layout.ts`, `src/ui/scoreboard-ui1.css`)** — 로컬·온라인 다인전·1인·기보 보기가 같은 컴포넌트를 쓴다(온라인/AI 1:1은 기존 `Scoreboard` 유지, 같은 버튼 규칙).
- 최소 크기: 족보 열 96px(시트 폭 < 480) / 124px(< 760) / 164px, 플레이어 열 60px / 72px, 점수 버튼 ≥ 44×36px이고 칸을 채움. 하단 족보의 주사위 그림은 점수판에서 숨기고 이름만(말줄임 + `title`).
- 실제 지원 인원(소스 확인): 로컬 2~50명(`MAX_LOCAL_PLAYERS`), 온라인 2~20명(`MAX_SEATS`). 테스트·설계 범위 2~20명.
- 적응형: 측정한 폭에 모든 열이 최소 크기로 들어가면 좌석 순서 그대로 한 화면. 아니면 **고정 열**(온라인 = 나, 로컬 = 현재 차례)을 족보 열 옆으로 옮겨 sticky로 고정하고 나머지 열은 가로 스크롤(안내 "옆으로 밀어 다른 플레이어 보기").
- 현재 차례: 헤더 빨간 하단 띠 + "· 차례" + 열 배경. 총점 줄도 현재 열을 구분.
- 9인 이상 기본값을 "전체 점수표"로 변경(이전: 한 명만). "현재 차례만"/"내 점수판" 전환은 유지.
- 휴대폰 로컬 다인전: 점수판 시트에 "현재 차례 / 전체 점수표" 전환 추가(전체 = 같은 공통 점수판).
- 데스크톱 배치: 2~4인은 ≥ 1100px에서 보드 옆에 점수판(폭 = 164 + 인원×100px), 5인 이상·좁은 폭은 보드 아래 전체 폭, 보드 최소 높이 `clamp(280px, 40vh, 420px)`로 빈 공간 축소.

## 2. 자동 매칭 팝업 (`src/play/MatchPopup.tsx`, `src/ui/floating.ts`)
- `createPortal(…, document.body)` + `position: fixed` → 본문 레이아웃·스크롤 높이 불변(테스트로 확인).
- 빠른 대전 시작 즉시 표시, 기본 위치 우측 하단(휴대폰은 하단 바 위 88px), 마우스·터치 드래그(창 밖으로 끌어도 window 리스너로 추적, 4px 미만은 탭), 화면 밖 방지(8px 여백, 창 크기 변화·회전 시 재보정), 위치는 화면 비율로 이 기기에 저장, 손잡이에 포커스 후 방향키로 이동.
- 최소화 → 경과 시간이 보이는 알약, 다시 눌러 복원. 매칭 취소·경과 시간·AI 대안·재연결·진행 중 경기 복귀 버튼은 기존 상태 기계(`useBackgroundMatch`) 그대로. 상태는 App 수준이라 페이지 이동 중 유지, 매칭 성사 시 기존 입장 절차(`entered()`로 숨김).
- 접근성 이름("빠른 대전 상태", "최소화", "빠른 대전 상태 보기", 타이머 "매칭 경과 시간")은 기존 테스트와 호환.

## 3. 글로벌 헤더·친구 패널
- 버튼 44×44(≤ 374px는 40×44), PC(≥ 1024px)는 아이콘 + 메뉴명(상점·인벤토리·친구), 그 아래는 아이콘만. 휴대폰은 로고 글자를 먼저 숨겨 겹침 방지(이전 390px에서 버튼 추가 시 로고와 겹침 확인). 재화는 PC에서 알약형, 휴대폰은 2줄 축약.
- `html { scroll-padding-top }`으로 sticky 헤더가 앵커·포커스 이동 대상을 가리지 않게.
- **친구 패널**(`src/shell/FriendsPanel.tsx`): 헤더 "친구" 버튼(받은 요청+유효한 초대 수 배지, `.header-badge`는 향후 공지·보상함 알림에 재사용) → 모달 `<dialog>`(top layer): PC 우측 서랍, 휴대폰 하단 시트. 내용은 기존 친구 화면(`FriendsPage`: 목록·요청·코드로 추가·검색·서버 접속 상태). 어느 페이지에서나 열리고 본문 위치 불변.
- **하지 않은 것:** 패널에서 친구 경기 관전·방 초대 — 서버가 친구의 방 코드·초대 가능 상태를 주는 계약이 없으므로 표시하지 않음(04 계약 대기). 접속 상태는 서버 inbox 확인으로 생긴 값만.

## 4. 이모티콘·채팅
- 보드 아래 메시지 줄 40→54px(고정 높이라 도착해도 레이아웃 불변), 말풍선 46px, 보낸 이모티콘 22→36px(그림자), 좌석 고정 피드는 28px.
- 발신자 칩(내 메시지는 빨간 글자), 등장 애니메이션(작게 → 튀어 오름), 퇴장은 기존 페이드. 동작 줄이기에서는 기존 규칙대로 애니메이션 없음.
- 퀵 이모티콘 버튼 PC 52px·글자 27px, 휴대폰 46px·25px. 보유권·전송 제한(서버·`useTableChat`)은 그대로. 상품별 이펙트·사운드는 03.

## 5. 경기 종료·결과 공유
- **온라인 1:1 결과를 A3 결과창(`MatchResultPanel`)으로 교체**(D-099의 후속). 입력은 `match-result/adapters.fromOnline`(공개 이벤트 로그) → 승리·패배·무승부·기권승/기권패(시간 초과·이탈 사유 포함)·역전/접전, 2인 대결형. 보상은 기존 `MatchRewardSummary`(서버 receipt만). 방 전적·재대결 요청 알림(다시 열기 버튼 "경기 결과 · 재대결 요청") 유지. 버튼 순서 재대결 → 게임 리뷰 → 결과 공유 → 나가기.
- 리뷰할 기록이 없는 경기(경기 중 새로고침 등): "리뷰 기록 없음" 비활성 버튼 + 이유(`title`).
- 다인전·관전 결과창 교체는 하지 않음(A3 §8 목록 그대로 남음).
- **공유 창이 좌측 상단에 붙는 버그:** CSS 리셋이 `<dialog>`의 `margin: auto`를 지워서. 공유 창을 공통 `Sheet`(PC 가운데 모달, 휴대폰 하단 시트, 배경, Esc, 포커스 복귀)로 교체하고, 공통 규칙으로 모든 `dialog.modal`·결과창에 `margin: auto`.
- 공유 이미지: 어두운 그라데이션, 결과 제목, 두 점수 패널(이긴 쪽 강조), 경기 종류 알약, VS. 닉네임 기본 비공개(체크해야 표시) 유지. 분석 지표 없음.

## 6. 게임 리뷰·프로필
- **주요 장면 한 글자씩 줄바꿈:** 행운/불운 행이 3열 그리드(주사위 5개·텍스트·수치)에 들어가 250px 카드에서 텍스트 열이 수십 px로 줄고 `overflow-wrap: anywhere`가 글자마다 끊었다. 카드 최소 폭 420px(2×2), 행운/불운은 주사위·수치 위 / 텍스트 아래 2줄, `word-break: keep-all`, 수치 `nowrap`.
- 실제 선택과 AI 추천을 "내 선택"/"AI 추천" 라벨 줄로 분리(화살표 인라인 제거). 분석 공식·모델·데이터 계약 불변.
- 프로필: 카드 행 높이 맞춤(2열 900px~, 3열 1100px~), 빈 상태 가운데 정렬, 기록이 없을 때 1인 카드의 중복 안내("공식 랭킹·보상에는…") 숨김. 대표 업적 편집은 A4 구현 그대로(서버 저장은 04 계약 대기).

## 7. 공통 디자인 규칙 (`src/ui/ui1-common.css`)
간격 4px 단위(`--ui1-space-*`), 터치 대상 44px(`--ui1-target`), 모서리 8(컨트롤)/12(카드)/18(대화상자), 떠 있는 요소 그림자 `--ui1-shadow-float`. 모달은 kit `Sheet` 사용(직접 `<dialog>`를 쓰면 `margin: auto` 필수). 상점·인벤토리(02)는 이 토큰과 Sheet 규칙을 사용하면 된다.
