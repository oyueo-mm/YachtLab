## 1. 기존 구조 검토

- 3D 테이블은 각진 `BoxGeometry` + 단일 `MeshStandardMaterial`(finish별 roughness/metalness 값만 다름), 반사 없음 → 금속·유리·보석이 광택 띠를 칠한 종이처럼 보였다.
- 2.5D는 SVG 평면 주사위(색·눈만). 저사양·WebGL 불가·동작 간단히 경로.
- 보드 Lv.1은 CSS 그라디언트: 원목=격자선, 펠트=대각 해칭 모아레, 대리석=평행 사선, 가죽=점 격자, 얼음·화산=한 점에서 뻗는 직선 — 재질보다 "인쇄된 선"으로 읽혔다(이미지 `compare-boards.jpg` before).

## 2. 주사위 재질 (FX1-D1, FX1-D2)

| 재질 | 대표 상품 | 표현 |
|---|---|---|
| plastic | 클래식·민트·파스텔·네온·초원 | 무광(클래식 그대로), 초원은 풀결 요철 + 광택(sheen) |
| resin | 로열·은하·오로라·홀로그램·번개·심연 | 클리어코트, 은하/오로라/홀로그램은 박막 간섭색 |
| porcelain | 꽃밭·벚꽃 | 반광 클리어코트 + 분홍 sheen |
| wood | 원목·호두 | 나뭇결 요철, 얇은 래커 |
| stone | 흰/흑 대리석 | 연마면 + 결 |
| ice | 서리 | 반투명 + 서리 결정 요철 |
| composite | 카본 | 직조 요철 + 클리어코트 |
| metal | 실버·브론즈·황금 | 금속, 브러시 결, 눈은 비금속 도료 |
| gem | 루비·사파이어·에메랄드·홀리 | 굴절률 1.77, 면 요철, 약한 투명 |
| glass | 블루·앰버 글라스 | 투명(눈은 불투명), 반사 |
| lava | 용암 | 거친 지각 + 균열 자체 발광 |

- 반사 환경: `RoomEnvironment`는 윗면에 천장 조명이 비쳐 유리·루비·대리석·서리를 하얗게 날려 버렸다 → 천장이 어둡고 35~55°에 조명판이 있는 자체 스튜디오(`studio-env.ts`).
- 가독성: 눈 대비(기존 테스트)·위치·크기 불변. 투명 재질도 눈은 불투명, 금속도 눈은 비금속, Lv.1 자체 발광은 눈 주변을 비운다.

### 2.1 재질 단계와 적응형 하향 (FX1-D5)

| 단계 | 내용 | 시작 조건 |
|---|---|---|
| 0 전체 | 위 표 전부(물리 재질 층 포함), 588삼각형 둥근 큐브, 역광 | 실 GPU + 고화질(기본 "자동") |
| 1 표준 | 클리어코트·박막·광택 제외, 맵·반사·범프 유지 | "성능 우선" |
| 2 가벼움 | FX-1 이전과 같은 음영 비용(스칼라 거칠기·금속, 맵·반사·역광 없음, 움직임 반응·주사위별 재질 없음) + 108삼각형 둥근 큐브 | 소프트웨어 GL(SwiftShader·llvmpipe — GPU 차단 기기의 대체 경로) |

"자동"에서는 연속 2회 느린 던지기(p95 > 22 ms)마다 **재질 단계를 먼저** 한 칸 내리고, 단계 2 이후에야 해상도를 낮춘다(기존 규칙). 세션 동안 유지, 던지기 사이에만 적용. `sessionStorage["yachtlab.dice.material"]`로 QA 강제 가능.

## 3. 강화 단계와 시간 흐름 (FX1-D3)

- Lv.1: 재질 자체(+ 용암·번개·심연 자체 발광 무늬).
- Lv.2: 기존 이동 궤적 효과 + 주사위 자신의 빛이 움직임에 반응. 속도(÷9)와 충돌로 차오르고 재질별 시간상수로 감쇠 — 번개 `charge` 0.35 s 지직거림, 용암 `heat` 1.6 s 달아오름→냉각, 보석·유리·오로라·우주·홀로그램 `shimmer` 0.6 s, 금속·네온 `pulse` 0.45 s. 멈춘 뒤 잔류하다 스스로 소멸(다음 던지기 사전 계산을 막지 않음). 단계 2에서는 꺼짐(공용 발광만).
- Lv.3: 기존 충돌·착지 연출 + 투척 순간 테마 보조음 + 착지음.
- 효과 줄이기·상대 효과 끄기(상대 Lv.1 표시)에서는 움직임 반응·보조음 없음.

## 4. 보드판·컬렉션 검토 (실제 브라우저 재생)

### 4.1 보드 Lv.1 바탕 (개선)

절차 노이즈 타일(SVG `feTurbulence`)을 시작 후 유휴 시간에 **한 번 PNG로 구워** CSS 변수로 넘긴다. SVG를 CSS 배경으로 바로 쓰면 트레이가 다시 그려질 때마다 필터가 재래스터화되는 것을 측정 중 확인해 바꿨다(굽기 전에는 무늬 없이 기존 바탕). 타일 주파수 × 크기를 정수로 맞추고 필터 영역을 타일과 같게 해 이음매를 없앴다. 대리석 결·얼음 균열·화산 균열은 노이즈의 좁은 등고선 대역만 남기는 방식(가지 치는 선)이며, 주사위를 방해하지 않게 불투명도를 0.3~0.5로 낮췄다.

| 보드 | 이전 | 이후 |
|---|---|---|
| 펠트 5종 | 대각 해칭 모아레 | 눌린 섬유 + 조명 웅덩이·가장자리 감쇠 |
| 원목·월넛 | 격자 원호 | 판자 이음 + 긴 나뭇결 + 램프 반광 |
| 가죽 2종 | 점 격자 | 시보(자갈 무늬) + 부드러운 광택 |
| 대리석 | 평행 사선 | 가지 치는 결 + 구름 무늬 + 연마 하이라이트 (Lv.1) |
| 황금 테이블 | 일정한 선 | 길이·밝기가 다른 헤어라인 |
| 얼음 | 한 점 직선 방사 | 서리 구름 + 미세 균열 (Lv.1) |
| 화산 | 한 점 직선 방사 | 식은 현무암 균열망 (Lv.1) |
| 사막 | 물결 | 물결 + 모래 알갱이 |

10개 컬렉션을 실제 게임(1인 플레이, 주사위·보드 Lv.3)에서 던지는 중·정지 후로 캡처해 비교했다(`review-synergy.jpg`). 테마마다 움직임·색·재질·시간 흐름이 분명히 다르고 주사위 눈이 모두 읽혀 구조는 유지했다.

| 테마 | 관찰 | 판단 |
|---|---|---|
| 번개 | 주사위 경로에 짧은 갈래 방전, 정지 후 주사위 사이 연쇄 번개, 비·구름 | 순간적·강렬 ✅ |
| 초원 | 풀이 경로를 따라 눕고 복원, 정지 후 빗질된 풀 연결 | 잔잔함 ✅ |
| 꽃밭 | 멈춘 자리 개화·꽃줄 | ✅ |
| 벚꽃 | 꽃잎이 천천히 내려앉아 쌓이고 흩어짐 | 부드러움 ✅ |

## 5. 특수 연출 검토

미리보기(`FxPreview`)로 요트·라지 스트레이트·승리를 실제 재생해 0.3~1.5 s 간격으로 캡처(`review-moments.jpg`).
- 요트: "요트!" 문구가 트레이 가운데에서 주사위와 눈을 가렸다 → **트레이 위쪽 가장자리로 이동**(타이밍·색·소리 그대로, 기존 페이드아웃 유지).
- 라지 스트레이트: 주사위 줄이 애니메이션 없이 컴포넌트 해제 순간 사라졌다 → **문구와 같이 페이드아웃**.
- 승리(보드 반응): 퍼짐 → 잔류 → 1.5 s 안에 자연 소멸, 밝기 과하지 않음 → 유지.
- 상품별 특수 연출(fx 아이템)은 이번 범위 밖 — 기존 유지.

## 6. 사운드

- 기본 물리음(재질, `dice` 버스)과 테마 보조음(`item` 버스: Lv.3 착지·투척 보조, 보드 반응, 시너지) 분리. 재질 매핑은 렌더러와 같은 표. 기존 매핑 보존, 플라스틱으로 떨어지던 6종만 `resin`.
- 라운드로빈 4테이크(직전 반복 금지), 충돌 속도 → 크기(+8~11 dB)·피치(×0.965~1.035)·상위 모드 밝기.
- 오프라인 측정(청취 아님): [materials-2026-11-28.json](../audio/materials-2026-11-28.json). 스펙트럼 중심 예: 원목×원목 172 Hz, 석재×석재 112 Hz, 유리×펠트 1.13 kHz, 유리×석재 1.92 kHz, 금속×금속 1.54 kHz. Lv.3 투척 보조음은 착지음보다 3~12 dB 작음. 100 % 음량 스트레스(충돌 40+굴림 8+착지+보조음+요트, 3.2 s): 피크 −0.7~−2.5 dBFS, 클리핑 없음.
- **청취 평가 준비(미실시)**: 주사위 실험실(`#lab` → 효과음 시연 → "재질·보드 표면 청취 비교")에서 재질 12 × 표면 11, 한 번 던지기, 약→강 5단계, 같은 충돌 12회(반복 피로), 테마 보조음 8종과 물리음 동시, 블라인드 A/B, 휴대폰 스피커 근사 필터(실험실 한정, 실기기 측정 아님), 복사용 평가 양식. 사용자 설정 메뉴는 추가하지 않았다.

## 7. 성능 (같은 컨테이너, 헤드리스 Chromium + SwiftShader 소프트웨어 GL, 60 Hz 상한 — **실기기·실 GPU 아님**)

SwiftShader는 GPU 작업을 CPU에서 하므로 픽셀당 음영 비용이 실제 GPU보다 훨씬 크게 드러난다. 실 GPU는 재질 단계 0으로 시작하므로 아래 "이후" 수치(소프트웨어 → 단계 2)는 저사양 대체 경로의 비용이고, 단계 0 비용은 §7.3이 소프트웨어 상한 참고값이다.

### 7.1 측정 중 발견과 조정

1차 구현(모든 기기에서 단계 0)은 데스크톱 소프트웨어 GL에서 평균 프레임 황금 Lv.1 16.6 → 21.1, 홀로그램 Lv.3 16.5 → 30.8, 블루 글라스 Lv.3 16.6 → 29.1, 용암 시너지 18.1 → 31.8 ms로 악화됐다([fx1-before-desktop](../perf/fx1-before-desktop.json), 이후 덮어쓴 1차 값은 커밋 기록). 원인을 단계별로 분리 측정해 (1) 물리 재질 층·반사·역광·맵 샘플링 → 재질 단계, (2) SVG 필터 배경 재래스터화 → PNG 굽기, (3) 주사위별 재질 복제 → 발광 주사위에만, (4) 둥근 큐브 삼각형 수 → 단계 2에서 108개로 해결했다.

### 7.3 단계 0(실 GPU용)을 소프트웨어 GL에서 강제했을 때 (참고)

황금 Lv.1 20.3 ms, 홀로그램 Lv.3 23.8, 블루 글라스 Lv.3 24.0(데스크톱, [tier0](../perf/fx1-after-desktop-tier0.json)) — CPU가 모든 픽셀을 그리는 상한. 실제 GPU에서의 비용은 측정하지 못했다(실기기 필요). 느리면 "자동"이 단계를 내린다.

### 7.4 자원 해제·저사양 경로

- 상점 상세 4회 열고 닫기: WebGL 컨텍스트 생성 4, 남은 것 ≤ 1(테스트). 재질 교체 시 이전 텍스처·재질 해제, 환경 맵은 테이블당 1개, `dispose`에서 모두 해제. 썸네일 렌더러는 마지막 요청 8 s 뒤 컨텍스트 해제.
- 2.5D·WebGL 불가·동작 줄이기 경로: 기존 테스트 통과, 2.5D에는 정적 CSS만 추가(애니메이션·필터·블렌드 없음).
