## 1. 기존 구조 검토 결과

- 3D 테이블(`DiceTable`)은 각진 `BoxGeometry` + 단일 `MeshStandardMaterial`(finish 5종에 따른 roughness/metalness 값만 다름), 환경 반사 없음. 금속·유리·보석이 "광택 띠를 칠한 종이"처럼 보였다(`before/` 황금·유리·루비). 눈은 텍스처에만 있고 입체감 없음.
- 2.5D 폴백(`Dice.tsx` DOM 주사위 + `Dice25Fx`)은 그대로 둔다. 재질 표현은 3D 경로 전용이며, 2.5D·WebGL 없음·동작 줄이기 경로는 변경 없음(기존 테스트 통과).
- 물리(`impulse`, 모서리 깎은 볼록 다면체, A1)·고정 이동(`carryPose`)·상대 주사위(같은 `PhysicalDice`/`DiceTable`)는 이미 일관되어 이번에 바꾸지 않았다. 시각 모서리 반경 0.085는 물리 모따기 0.1과 맞췄다.
- 사운드는 이미 재질(`dieSounds`)·보드 표면(`SURFACES`)·테마 착지음(`landVoice`)이 분리되어 있었으나, 재질 매핑이 렌더러와 따로 있었고 광택·번개·심연·꽃·벚꽃·로열 등은 플라스틱 소리였다. 반복 변화는 무작위 지터뿐.

## 2. 재질 (D-101, D-102)

| 재질 | 대표 상품 | 표현 |
|---|---|---|
| plastic | 클래식·민트·파스텔·네온·초원 | 무광(클래식 그대로), 초원은 풀결 요철 + 광택(sheen) |
| resin | 로열·은하·오로라·홀로그램·번개·심연 | 클리어코트, 은하/오로라/홀로그램은 박막 간섭색 |
| porcelain | 꽃밭·벚꽃 | 반광 클리어코트 + 분홍 sheen |
| wood | 원목·호두 | 나뭇결 요철·거칠기 줄무늬, 얇은 래커 |
| stone | 흰/흑 대리석 | 연마면(낮은 거칠기)·결 요철 |
| ice | 서리 | 반투명 + 서리 결정 요철·부분 거칠기 |
| composite | 카본 | 직조 요철 + 두꺼운 클리어코트 |
| metal | 실버·브론즈·황금 | 금속 1.0, 브러시 줄무늬 거칠기, 눈은 비금속 도료 |
| gem | 루비·사파이어·에메랄드·홀리 | 굴절률 1.77, 면(facet) 요철, 약한 투명 |
| glass | 블루·앰버 글라스 | 투명 0.8(눈은 알파 맵으로 불투명), 반사 |
| lava | 용암 | 거친 균열 지각 + 균열이 Lv.1부터 은은히 발광 |

- 반사 환경: three.js `RoomEnvironment`로 먼저 만들었더니 윗면에 천장 조명이 비쳐 유리·루비·대리석·서리가 하얗게 날아갔다(중간 이미지 확인). 자체 스튜디오(천장 어두움, 35~55° 조명판, 역광 띠)로 교체 후 색과 깊이가 유지됨.
- 성능 우선(`3d`)·적응형 해상도 단계 2에서는 `liteSpec`(클리어코트·박막·광택 제거, 반사는 유지)로 `MeshStandardMaterial`만 사용(테스트: `data-physical="false"`).
- 가독성: 눈 대비 규칙(기존 테스트)·눈 위치·크기 불변. 투명 재질도 눈은 불투명, 금속도 눈은 비금속. 자체 발광 무늬는 Lv.1에서 눈 주변을 비워 눈이 빛나지 않는다.

## 3. 강화 단계와 시간 흐름 (D-103)

- Lv.1: 위 재질 자체(+ 용암·번개·심연의 자체 발광 무늬).
- Lv.2: 기존 이동 궤적 효과(dice-fx `trail`) + **주사위 자신의 빛이 움직임에 반응**. 에너지는 속도(÷9)와 충돌 세기로 차오르고 재질별 시간상수로 감쇠: 번개 `charge`(0.35 s, 지직거리는 깜빡임), 용암 `heat`(1.6 s, 충돌마다 달아올랐다 천천히 식음), 보석·유리·오로라·우주·홀로그램 `shimmer`(0.6 s), 금속·네온 `pulse`(0.45 s, 충돌에 종처럼 울림). 멈춘 뒤에도 잔류하다 스스로 꺼지며(별도 루프, "주사위 이동 중"으로 세지 않아 다음 던지기 사전 계산을 막지 않음), 눈 발광 마스크는 기존과 같다.
- Lv.3: 기존 충돌·착지 연출(dice-fx) + 투척 순간 테마 보조음 + 착지음.
- 효과 줄이기: 발광 애니메이션·움직임 반응·Lv.3 소리 꺼짐(기존 규칙). 상대 아이템 효과 끄기: 상대는 Lv.1로 그려지므로 움직임 반응·보조음 없음.
- 보드 Lv.2/3 장면·시너지(A1, 26종·10종)는 그대로이며, 시너지 조합에서도 주사위 재질은 같은 표를 쓴다. 요트·라지 스트레이트·승리 연출은 기존 경로(`YachtFlash`·`StraightFlash`·보드 반응) 그대로이고 미리보기에서 같은 경로로 재생된다.

## 4. 사운드

- **기본 물리음(재질)**과 **테마 보조음(dice-fx `sound`, 보드 반응, 시너지)**은 다른 버스(`dice` vs `item`)로 분리(기존 구조 유지). 재질 매핑은 렌더러와 같은 표에서 온다. 신규 `resin` 음색(1.24 kHz 모드, 0.022 s 감쇠).
- 라운드로빈: 충돌 음색마다 4개의 "테이크"(모드 피치 −4.5%~+4.8%, 감쇠 ×0.9~1.2, 배음 간격)를 두고 직전 테이크를 반복하지 않음(테스트 400회). 재질 음색·플라스틱 바닥/주사위끼리 소리에 적용.
- 충돌 속도 → 크기(기존) + 피치(×0.965~1.035) + 상위 모드 밝기.
- 상황 구분: 굴림 시작(`throw`), 보드 충돌(`impact`+표면), 주사위끼리(`clack`), 굴러감(`roll`), 최종 착지(`settle`), 강화 발동(`diceFxRoll` 신규, Lv.3), 착지 강조(`diceFx`), 보드 반응(`boardFx`), 시너지(기존), 요트·라지 스트레이트·승리(기존 `yachtHit`·`straightHit`·`win`).
- 측정(헤드리스 오프라인 렌더, 기본 음량 70 %, 청취 아님): [materials-2026-11-28.json](../audio/materials-2026-11-28.json). 바닥 강타의 스펙트럼 중심 — 원목 위 원목 172 Hz, 석재 위 석재 112 Hz, 펠트 위 유리 1.13 kHz, 석재 위 유리 1.92 kHz, 석재 위 수정 1.95 kHz, 금속 위 금속 1.54 kHz → 재질·표면 조합이 구별됨. 약→강 타격 +8~11 dB, 금속·유리·금은 강할수록 밝아짐(예: 유리 1.25 → 1.93 kHz). Lv.3 투척 보조음은 착지음보다 3~12 dB 작게(물리음 앞에 나서지 않게).
- **클리핑·동시 재생**: 100 % 음량에서 5개 주사위 충돌 40회 + 굴림 8 + 착지 + Lv.3 보조음 + 요트를 3.2 s에 몰아 렌더 → 피크 −0.7 ~ −2.5 dBFS(0 dBFS 미만, 리미터 −3 dBFS), 동시 발음은 기존 예산(10개·같은 종류 최소 간격)으로 제한. 기본 70 %는 더 낮다.
- 무음·효과음 끄기·음량·효과 줄이기·상대 효과 끄기 설정을 그대로 따른다(새 경로 없음, 미리보기도 `playSfx` 경유).
- 모든 소리는 합성, 출처·권리: [LICENSES](../audio/LICENSES.md).

## 5. 미리보기 인터페이스 (02 · 01 담당자용, D-104)

```tsx
import { FxPreview, type FxPreviewHandle } from "../fx-preview";
const ref = useRef<FxPreviewHandle>(null);
<FxPreview ref={ref} dice="dice.lava" diceLevel={3} board="board.volcano" boardLevel={2} />
ref.current?.roll();                 // 실제 굴림 체험(킵 가능: 주사위 클릭)
ref.current?.moment("yacht");        // 요트로 착지 → 경기와 같은 YachtFlash·보드 반응·소리
ref.current?.moment("straight");     // 라지 스트레이트 착지 → StraightFlash
ref.current?.moment("win");          // 승리 보드 반응 + 승리음
ref.current?.scoreFx("large");       // 지금 주사위로 점수 기록 연출(족보 반응)
ref.current?.playSound("impact");    // throw | impact | clack | roll | land | accent | board | yacht | straight | win
```

- props: `dice`, `diceLevel`, `board`, `boardLevel`(아이템 최대 단계로 자동 제한), `autoRoll`(조합·단계가 바뀌면 다시 굴림, 동작 줄이기 시 안 함), `renderer`("2.5d" 강제 비교 가능), `sound`, `onRolled(values)`.
- 같은 컬렉션 주사위+보드면 시너지가 자동으로 켜진다(강도는 경기처럼 두 단계 중 낮은 값).
- 구성 요소는 경기 화면과 동일: `DiceArea`(3D 테이블/2.5D) · `BoardFx` · `SynergyFx` · `YachtFlash`/`StraightFlash`. 01은 별도 작업이 필요 없다(경기 화면이 이미 이 구성 요소를 사용). 상점 상세(`ItemStage`)가 이번에 `FxPreview`로 교체되었고, 주사위 Lv.3 상세에 "요트 연출"·"스트레이트 연출" 버튼을 추가했다.
- 진단 속성: `.dice-table-canvas[data-material]`(재질), `[data-physical]`(고급 층 사용 여부), `[data-glow-peak]`(직전 굴림의 움직임 반응 최대 배율).
- 경계: 미리보기는 장착·저장·점수·서버 요청이 없다(기존 economy 테스트의 요청 0건 검사 통과). 연출 지정 굴림은 미리보기 전용 면 선택이며 게임 엔진에는 영향이 없다.

## 6. 성능·자원

PERF_TABLE

- WebGL 컨텍스트: 상점 상세를 4회 열고 닫는 동안 생성 4, 남은 컨텍스트 ≤ 1(테스트, `forceContextLoss`). 재질 교체 시 이전 텍스처·재질을 해제하고 환경 맵은 테이블당 1개(재질이 반사를 쓸 때만 생성), `dispose`에서 모두 해제.
- 텍스처 비용: 면당 색 256² + 범프 256² + 거칠기/금속 128²(+투명 128², 발광 128²) — 주사위 외형이 바뀔 때만 다시 그림(굴림 중 없음). 주사위별 재질 복제(5×6)는 같은 셰이더 프로그램을 공유한다.
- 모바일: 기존 해상도 적응(2 → 1.5 → 1.25×)·장식 품질 단계(A1.1)를 그대로 쓰고, 단계 2·`3d`에서는 물리 재질 층을 끈다.

## 8. 하지 않은 것 / 한계

- **실기기 미측정**: 프레임·발열·배터리·GPU 비용은 헤드리스 Chromium + SwiftShader(소프트웨어 GL) 에뮬레이션 수치뿐이다. MeshPhysicalMaterial은 실제 저사양 GPU에서 더 비쌀 수 있다(적응 단계 2에서 꺼지도록 함).
- **청취 평가 없음**: 헤드리스 컨테이너라 스피커가 없다. 재질 음색의 자연스러움, 투척 보조음 크기, 모바일 스피커(저역 손실) 재생은 사람이 확인해야 한다.
- 보드 장면(A1 26종)과 시너지 장면은 이번에 바꾸지 않았다. 요청의 테마 방향(번개 전류·초원 바람·꽃 개화·벚꽃·숲 반딧불·심해 기포/굴절·용암 균열·얼음 결정·우주 성운·오로라 흐름)은 A1에서 보드·시너지로 구현되어 있고, 이번에는 같은 테마의 **주사위 재질·발광 반응**을 맞췄다.
- 2D 썸네일(상점 카드)은 기존 캔버스 그림 그대로(3D만 재질 표현).
- 굴림 녹화 영상은 저장소 용량 때문에 넣지 않았다(`node scripts/shoot-dice.mjs --mid`로 투척 중 프레임 생성 가능).
