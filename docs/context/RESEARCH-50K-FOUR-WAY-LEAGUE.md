## 연구 A — v3.4 시간 예산

이전의 예비 실험은 **모드당 80개 시드 × 양좌석 = 160경기**뿐이었다. 설정한 시간 예산은 최적 값이 아니라 계산량을 제어하기 위한 **소프트 한도**였고, 특히 `C`에서 평균 69.2롤아웃/탐색이 관측되었다(최대 256회).

| 탐색 모드 | 후보 수 | 표본 최대 | 소프트 시간 제한 | 게임 수 |
|---|---:|---:|---:|---:|
| legacy | 2 | 2 | 40ms | 50,000 |
| A | 2 | 16 | 60ms | 50,000 |
| B | 4 | 64 | 120ms | 50,000 |
| C | 8 | 256 | 240ms | 50,000 |
| C-relaxed | 8 | 256 | **1,200ms** | 50,000 |
| D | 4 | 64 | 120ms + eligible last-slot exact BR | 50,000 |
| adaptive | 국면별 A/B/C | 가변 | 60~240ms | 50,000 |

- 총 **350,000 완결경기**, 예비 960경기와 별도 신규 시드 5101~5110, 각 2,500쌍(=5,000게임).
- C-relaxed는 C와 **동일한 적용 국면·후보·롤아웃·조기 종료 규칙**을 쓰고 소프트 시간 제한만 240ms→1,200ms로 완화한다. `src/research-v34-adaptive.ts` 원본을 바꾸지 않음.
- 실제 실행 루프는 최소 샘플 이후 롤아웃 **배치가 끝나야** 시간 검사하므로 지정된 ms를 강제로 보장하지 않는다. 시간 한도를 연산이 끝날 때까지 넘길 수 있다.
- 평균 판단시간·최대 의사결정 시간·실제 평균 롤아웃·시간 한도 도달 횟수와 99% paired CI를 저장.
- 50,000경기 결과가 근소하면 후보를 **별도 미사용 시드**에서 200,000~1,000,000경기로 확장하되 결과를 보고 중간 수정/반복 시험으로 확증이라고 주장하지 않음.

## 연구 B — 네 모델 사이의 진짜 일대일 리그

- **4개 모델**: 기존 `v3`(`calibrated-v3`), 기존 `v3.3`(상대정책 알려졌을 때 조건부, 모르면 `Other` 폴백), 기존 `v3.4`(원본 탐색 2후보×2롤아웃), 후속 v4 절제의 `v4-D`(REINFORCE만 학습).
- 각 모델의 코드와 학습자료를 **실험 시작 전에 동결**, v3.3은 과거 연구 80만 경기에서 사용된 `v33-forecast-locked`를 같은 GitHub Actions run(44922054901)에서 복원, v4-D는 100만 경기 실험(44976868790)의 `followup-frozen-actors`에서 선정된 시드 1 체크포인트를 [고정 파일](../../training/research-archive/v4-reinforce-seed1-frozen.json)로 보관.
- **6개 대진**: v3-v3.3, v3-v3.4, v3-v4-D, v3.3-v3.4, v3.3-v4-D, v3.4-v4-D.
- **각 대진 50,000경기**(25,000 신규 시드쌍) × 6 = **300,000경기**. 시드 6101~6110, 각 2,500쌍. 예산 연구의 신규 시드군과도 분리.
- 모두 실제 플레이 상대의 행동으로 업데이트하며, 사전에 상대의 미공개 정책 정보를 제공하지 않는다. 정책명을 **실제로 확인할 수 있는 v3에만** `Win DP v3` 라벨을 전달한다.
- v3.3은 v3를 상대할 때는 정책 조건부 보정을 적용할 수 있으나, `v3.4`·`v4-D`의 정확한 내부 정책을 알지 못하므로 `Other`로 기본 정책을 사용한다. v3.4 내부 시뮬레이터도 모르는 상대를 `Other`로 취급하므로, 정책 불일치를 명시해야 한다.
- 주요 평가 기준은 일대일 50% 기준 통계 검정, 좌석 교대, 짝별 99% CI와 다중 비교 조정. 부가적으로 3상대 단순평균 승리점수율을 **설명용 순서**로 보고할 수 있으나, 이것만으로 보편적 최강/SOTA로 선언하지 않는다.

## 0.0053%p 개선 해석

기존 20만 경기에서 v3.3은 v3보다 관측 +0.0053%p였지만, **짝별 99% CI −0.0212~+0.0317%p**이므로 실재한 우위 여부는 미확정이다. 이번 직접 대국은 전형적인 기존 v2 대상 승률 비교와 다르다. 정확히 같은 게임 상황에서 행동들이 달라지는지와 그 차이가 경기 결과에 영향을 주는지를 평가한다. **50,000경기만으로 매우 작은 개선을 구별하지 못할 가능성**도 있다.

## 동작 및 예산 주의

- 실제 새 경기는 합계 **최소 650,000경기**이며 GitHub Actions 샤드 130개(예산 연구 70, 리그 60)로 나뉜다. 다량의 CPU 사용이 예상되므로 한 작업당 180분 제한, 최대 6개 동시에 실행한다. 실패한 샤드는 집계에서 제외해 허위 성공 보고를 만들지 않으며 전체 결과는 모든 샤드가 성공할 때만 발표한다.
- 기존 사용자의 100만 경기 v4 절제 재실행을 막기 위해 이미 존재하는 공용 연구 소스와 워크플로는 수정하지 않는다.
- `actions/download-artifact`로 과거 원본 학습자료를 **읽기 전용** 다운로드한다. 아티팩트는 90일 동안 보존되는 연구 입력으로, 장기 재현 시 별도 자료 보존이 필요하다.
- `production` AI, 배포 선택기, 기본 전술은 변경하지 않는다.
