## 1. 구조 (새 디자인 시스템 없이 기존 클래스 위에 얹음)

- `src/cosmetics-a2.css`: 기존 CSS **뒤에 추가만** 한다(크기·레이아웃·기존 클래스 의미 불변). 장식은 `::after`(말풍선; `::before`는 말풍선 꼬리), `::before/::after`(프레임). 애니메이션은 Lv.3 등 단계에 묶고 transform/opacity 또는 작은 의사요소의 배경 위치(단계형 `steps()`)만 쓴다.
- `src/play/ChatMessage.tsx`: **게임 피드·상점/인벤토리 미리보기·미리보기 페이지가 공유하는 단일 렌더러**(이전에는 각자 마크업 복제).
- `src/chat/{chat-mood,a2-fixture}.ts`: 채팅 움직임 분류, 38종 테스트 fixture.
- `src/lab/CosmeticsLab.tsx`(연구실 → 꾸미기 미리보기, `#cosmetics-lab`): 채팅 38종·채팅 선택창(실제 `SocialDock`)·말풍선·이모티콘·닉네임/칭호/프레임 조합·특수 효과.

## 3. 채팅 개편 (fixture 한정)

- 38종 문구(9/8/9/7/5)·무료 6 제안은 `a2-fixture.ts`(`fixture.chat.*` ID, 운영 미반영). 테스트가 문구·순서·개수·ID 비충돌을 고정.
- 선택창(`SocialDock`): 등급별 묶음(기본→신화), 44px 이상 터치 대상, 등급색 좌측 띠, 시트 최대 70dvh 스크롤·고정 헤더, 모바일 이모티콘 5열. 보내기 로직·속도 제한·소유권 검사는 불변(서버 검사 그대로). 자유 채팅 없음.
- 기존 무료 권한·보유 상품은 그대로 — 새 문구는 카탈로그에 넣지 않았다.

## 4. 미리보기 = 실제 게임?

- 같은 컴포넌트: `ChatMessage`, `PlayerTag`, `FxBurst`, `EmoteGlyph`, `SocialDock`/`TableFeed`(미리보기 전용 `resolve` 주입 외 동일). 같은 CSS.
- 상점 상세: 말풍선=샘플 문구 3종 전환, 특수 연출=승리/요트/라지 전환(Lv.2부터), 닉네임·칭호·프레임=**장착 중인 다른 꾸미기와 함께** 표시 + 어두운 좌석 표시.
- 한계: 게임 좌석에서의 실제 배치(좌석 칩 아래)는 Playwright의 DOM 검증(흰 배경 덮임 없음)으로만 확인했고, 온라인 대전 화면 전체의 새 스크린샷은 서버가 필요해 이번에는 찍지 않았다.

## 6. 성능 (헤드리스 Chromium + SwiftShader 에뮬레이션, 실기기 아님)

A1.1 회귀(`scripts/measure-board-fx-perf.mjs`, main `0939a27` vs A2, 같은 컨테이너·2회×6굴림): default 평균 16.6/16.6 ms; lava-synergy 16.7/16.8; thunder-synergy 16.9·17.3·17.7 (main) vs 17.5·17.2·17.7 (A2) — 시도 간 편차(p95가 16.8↔33)가 main끼리도 같아 **유의한 회귀 없음**. 이 경로(1인 플레이)는 A2가 건드리지 않는다.

꾸미기 고부하(미리보기 페이지, Pixel 7 에뮬 + CPU 4배 스로틀, 5초): 기준선 / 고부하 조합(네온 Lv.3 닉네임+크리스탈 Lv.3 프레임+홀로그램 말풍선 Lv.3+효과·이모티콘 초당 1회) 모두 **평균 16.7–16.8 ms, p99 16.8, 33 ms 초과 0**. CPU(작업 시간 비율)는 기준선 ~8% → 조합 ~55%(소프트웨어 렌더링 합성 비용; 실기기 GPU는 더 낮을 것으로 예상하나 **미측정**). 병목이던 홀로그램 프레임(conic+mask 회전)·홀로그램 말풍선(연속 배경 이동)은 SVG 링·단계 애니메이션으로 교체(프레임 단독 +23%p → +14~25%p로 하향). 항목별 단독 +1~25%p.
통제: 동작 줄이기(시스템/설정 `data-fx-reduced`)·효과 품질 낮음(`data-fx-tier=2`)에서 CSS 루프 중지, 화면 밖 썸네일 일시정지, 입자 0이면 DOM 미생성.

## 7. 남은 문제

1. 실기기(저사양 안드로이드) 프레임·배터리 미측정. 프레임 Lv.3 회전은 항상 켜져 있어 좌석 3개면 레이어 3개 상시 합성.
2. 온라인 대전 전체 화면(좌석 말풍선·요트/라지 효과)의 컬러 스크린샷은 서버 필요로 미촬영.
3. 채팅 mood는 문구 추정(`chat-mood.ts`): 새 문구가 어색하면 C5가 `mood` 필드를 줄 수 있음(제안서 §2).
4. 칭호 4종(새내기·주사위 장인·300·310클럽)은 표식 없음; fx 레벨 문구는 "요트 연출 추가" 그대로(라지 포함 문구는 C5 요청).
5. 채팅 효과음은 이번에 추가하지 않음(후보).
