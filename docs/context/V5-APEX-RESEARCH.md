# Win DP v5-Apex 연구 — 정확 정책 PMF · 정확 2인 종반 솔버 · PMF 롤아웃

> 12칸 Nintendo-style Yacht Dice(주사위 5개, 최대 3회 굴림, 상단 63점 이상 +35). 목표는 1:1 **승리 점수율**(승 1, 무 0.5, 패 0). 연구 전용 — `src/ai.ts`·기본 AI·제품 UI는 바꾸지 않는다. 브랜치 `ccr-4b6d4930-6rem08`.

> **요약 (2026-11-25):** 모든 상태의 DP Expert 미래 득점 분포를 정확히 계산한 PMF 은행으로 "이번 턴을 승리 점수율로 정확히 최적화하고 이후는 양측 DP Expert" 롤아웃을 만든 **v5-R**이 사전 등록 확증(9501)에서 **Win DP v2 상대 50.626%**(100k, 99% CI 50.372–50.879), **Win DP v3 상대 50.479%**(100k, 50.229–50.729), **DP Expert 상대 51.223%**(60k, 50.891–51.554)를 기록했고, 독립 시드 9502 CI 재현(각 40k)에서도 50.940% / 50.671% / 51.598%. 같은 시드에서 v3 대비 +0.450%p(99% CI +0.191~+0.709). 정확 2인 종반(≤3칸)·Bayesian 적응·depth-2 탐색·창 4 확대의 **추가 이득은 확인되지 않았다**. 판단 0.07 ms, 단 PMF 은행 299 MB. 기본 AI는 바꾸지 않았다. 외부 AI와의 비교가 없으므로 세계 SOTA가 아니다.

## 0. 사전 등록 (확증 대국 전에 커밋)

이 절은 확증 시드(9501~)로 단 한 판도 두기 전에 작성·커밋한다.

- **개발·선택 시드:** family 9001~9099 (9001 = 후보 비교, 9002 = 스모크, 9003 = 가치 정확도). 이 시드로 후보를 골랐으므로 9001의 수치는 "개발 결과"이며 홀드아웃이라고 부르지 않는다.
- **확증 시드:** family 9501 (주 확증), 9502 (CI 재현용). 기존 연구 시드군(1301~1500, 2201~2220, 5101~5110, 6101~6110, 7201~7210)과 겹치지 않는다. 시드 = `hash(0x5eed0000 + family·1000003 + shard·20011 + i)`, `createGame(seed, true)`, 시드마다 좌석 교대 2경기.
- **Apex 후보 선택 규칙:** 개발 시드 9001에서 Win DP v2 상대 승리 점수율이 가장 높은 v5 변형. 차이가 개발 표본의 오차(±0.3%p) 안이면 더 단순·빠른 구성을 고른다(복잡한 구성은 확증에서 별도 절제 실험으로 검정).
- **주 가설 H1:** Apex vs Win DP v2 승리 점수율 > 50%. **H2:** Apex vs Win DP v3 > 50%. **H3:** Apex vs DP Expert > 50%. 각각 시드쌍 단위 99% 정규 근사 CI, 3개 주 가설에 Holm 보정 p 병기.
- **표본 수(사전 지정):** v2·v3 상대 각 100,000경기(20 shard × 2,500 쌍), DP Expert 60,000경기, v4-D(src/ai.ts 등록 구성) 40,000경기, 나머지 상대 각 10,000~20,000경기. 결과를 보고 표본을 늘리거나 중단하지 않는다.
- **절제(같은 확증 시드, 상대 v2):** 롤아웃만(v5-R), 롤아웃+v2 종반(v5-A), DP Expert+정확 종반만(v5-X3), 롤아웃+정확 종반(v5-B3). 쌍별 대비(paired contrast) 99% CI.
- **보고 항목:** 승리 점수율·승/무/패율·평균 점수·점수차·Elo(로지스틱 환산)·판단시간 평균/p50/p95/p99/최대·DP Expert와 다른 행동 비율·CRN 분산 감소 계수·CPU 시간.

### 0.1 개발 결과에 따른 Apex 선택 (확증 2차 배치 전에 커밋)

개발 시드 9001, Win DP v2 상대 각 10,000경기: v5-D 50.930%, v5-B3 50.860%, v5-A 50.810%, v5-B2 50.810%, v5-R 50.755%, v5-E/E5 50.725%, v5-X3 50.215%. 최고값(v5-D)과 ±0.3%p 안에 v5-B3/A/B2/R이 모두 있으므로 사전 규칙에 따라 **가장 단순·빠른 v5-R(전 구간 정확 PMF 롤아웃)을 Apex 주 후보**로 확정한다. v5-B3(정확 종반 추가)·v5-D(Bayesian 추가)는 확증에서 **같은 시드의 절제/보조 비교**로만 보고하며, 확증 결과를 보고 Apex를 바꾸려면 새 시드군(9502)에서 다시 확인해야 한다.

확증 2차 배치(9501, 사전 지정): v5-R vs v3 100,000 · vs DP Expert 60,000 · vs v4-D 40,000 · vs Win DP v1 20,000 · vs Greedy/myopic/switcher 각 10,000 · vs Expectimax 2,000. 보조: v5-B3 vs v3 100,000, v5-D vs myopic/switcher/greedy 각 10,000. 메타게임용 기준선: v3 vs DP Expert, DP Expert vs v2, v4-D vs v2 각 40,000.

## 2. 정확 확률분포 (축 A)

### 2.1 Exact Policy PMF — DP Expert (방법 1)

| 항목 | 값 |
|---|---|
| 상태 | 4096 마스크 × 64 상단값 = 262,144 → 정규화 후 **199,744개 고유 상태** (23.8% 병합) |
| 저장 | 37,256,480 Float64 = 298.9 MB (지원 구간만) |
| 확률 합 오차 | 최대 **2.8×10⁻¹⁵** |
| 평균 vs DP 표 | 최대 **7.4×10⁻¹³** (모든 262,144 상태) |
| 초기 상태 | 평균 191.7608797521652, P(≥250)=7.034%, P(323)=4.41×10⁻¹⁶, 동일 정책끼리 무승부 0.780% — 2026-11-24 경제 연구의 독립 계산과 일치 |
| 계산 시간 | TypeScript 56.4 s(단일 코어) · **C++ 3.04 s** · 캐시 로드 0.4 s |
| 정규화 검증 | DP 표에서 `V(mask,u) = V(mask, canonical(u))`가 262,144 상태 전부에서 비트 단위로 성립 |

**중요한 발견 — DP Expert의 PMF는 유일하지 않다.** 독립 C++ 구현(고정 순서만 다름)과 비교하면 평균은 전 상태에서 1e-12 이내로 같지만 **97,838 상태(별칭 포함)에서 분포가 1e-6 이상 다르고 최대 총변동거리 0.74%**(초기 상태 4.2×10⁻⁶). 기대점수가 정확히 같은 최적 행동이 여러 개일 때(동률) 어느 것을 고르느냐에 따라 점수분포가 달라지기 때문이다. 이 연구의 TS 은행은 배포 `dp.ts`와 같은 순서(점수 기록 우선 → `dp-kernel.json` 고정 순서)를 쓰므로 실제 DP Expert 상대에 맞춘 분포다. "DP Expert의 정확 분포"를 말할 때는 동률 처리 규칙을 함께 명시해야 한다.

### 2.2 Multi-Policy PMF Bank (방법 2)

같은 코드로 W = 0(myopic: 이번 턴 점수만 최대화) 은행을 만들었다. 두 은행은 v5-D의 Bayesian 가설로 쓰인다. **한계:** 이 방식은 자기 점수판에만 반응하는 정책에만 정확하다. Win DP v2/v3/v4·v5처럼 상대 점수판에 반응하는 정책의 분포는 상대 상태에 따라 달라지므로 고정 PMF는 근사일 뿐이다.

### 2.3 Post-Action PMF (방법 3)

행동 후 분포는 따로 저장하지 않는다. 카테고리 기록 후 분포 = 자식 상태 PMF의 이동(shift)이고, 재굴림 후 분포는 그 위의 chance 백업이라 **지연 계산이 메모리 0 추가로 충분**했다(롤아웃 1회 0.07 ms). 전체 캐싱은 상태 × 행동 수배의 메모리가 필요해 채택하지 않았다.

## 3. 정확 2인 솔버 (축 B)

### 3.1 Exact Best Response vs 상호작용 솔버 (방법 4)

- **비상호작용 BR**(상대가 내 점수판에 반응하지 않는 고정 정책): 상대 미래 점수는 내 행동과 독립이므로 승리 점수율 = 두 PMF의 합성곱. v5 롤아웃이 이것을 현재 턴에 정확히 적용한다.
- **상호작용 솔버**: 양측이 승리 점수율을 최대화하는 **expectiminimax**. 완전정보 순차 확률게임이므로 역진 귀납법으로 순수 전략 균형 가치를 정확히 얻는다(CFR 불필요, §7).
- 교차검증: P0 마지막 칸 1v1에서 기존 독립 구현 `research-last-turn-br`의 정확 BR 가치와 **1e-9 이내 일치**, P1 마지막 칸에서 Win DP v1 가치와 1e-9 이내 일치, 2v2 자기 대국 1,500 몬테카를로가 정확값과 4σ 이내.

### 3.2 상태 압축·가지치기 (방법 5)

상단 정규화(§2.1)와 **안전 경계 가지치기**(현재 점수차 > 상대 최대 추가점 → 승리 1, 점수차 + 내 최대 추가점 < 0 → 0; 무승부 경계는 계산)만 사용한다. 가치가 같다고 증명되지 않은 상태 병합은 하지 않았다.

### 3.3 국면별 가치 정확도 (방법 4·10 교사 자료)

DP Expert 자기 대국에서 수집한 P0 차례 시작 국면(family 9004, k=1~3 각 3,000, k=4 600). 정확 상호작용 가치 대비 오차(승리 점수율 %p):

| 남은 칸 k | 비상호작용 정확 PMF: 편향 / MAE / 최대 | v5 롤아웃: 편향 / MAE / 최대 |
|---|---|---|
| 1 | +0.03 / 0.21 / 5.5 | +0.13 / 0.13 / 5.5 |
| 2 | +0.26 / 0.79 / 12.7 | +0.68 / 0.73 / 18.2 |
| 3 | +0.38 / 0.83 / 8.1 | +0.65 / 0.81 / 8.3 |
| 4 | +0.42 / 0.70 / 3.9 | +0.55 / 0.72 / 4.3 |

두 근사 모두 선공 P0의 가치를 **과대평가**한다(후공이 P0의 결과를 보고 최적 대응하는 상호작용 효과). 개별 국면 오차는 최대 18%p까지 커서 "PMF가 정확하면 승률도 정확하다"는 가정은 틀리다.

## 4. 상대 모델링 (축 C)

- **Expanded Bayesian Filter (방법 7):** 우도는 공개 점수판에서 정확 계산(P_π(c,p|state)). 턴 안의 고정 선택은 AI 입력 상태에 없어 쓰지 않으므로 식별이 느리다. 가설은 DP Expert와 myopic 두 개뿐이다(인간 성향 가설은 인간 대국 자료가 없어 만들지 않음).
- **Discounted Bayes (방법 8):** λ=0.7 감쇠 버전(v5-Dd) 구현. HMM 전환 확률 추정은 구현하지 않았다.
- **Safe exploitation (방법 9):** ε=0.02 혼합이 오지정 시 사후확률 붕괴를 막는 유일한 안전장치다. **보장 가능한 안전 하한은 증명하지 않았다**; 경험적 성능만 §6에 보고한다.

## 7. 게임이론적 자기 대국 (축 E)

- **PSRO (방법 13):** 새 오라클을 학습하지 않았다. 측정된 확증 대국 승리 점수율로 **제한 메타게임**을 만들고 fictitious play로 혼합을 계산한다(`scripts/research-v5/metagame.ts`, §6.4). 제한 exploitability는 관찰된 정책 집합 안에서의 값이며 전체 게임 exploitability가 아니다.
- **CFR / Deep CFR (방법 14): 채택하지 않음.** 요트다이스 1:1은 숨은 정보가 없는 **순차 완전정보 확률게임**이다(상대 점수판·주사위 공개, 동시 행동 없음). Zermelo/Kuhn 정리에 따라 역진 귀납법이 순수 전략 부분게임 완전 균형과 그 가치를 정확히 준다. §3.1의 expectiminimax가 2v2를 ms 단위, 3v3을 평균 21 ms에 정확히 풀므로 같은 축소 문제에서 CFR이 줄 수 있는 이점(혼합 전략·정보집합 처리)이 없다. 정보집합이 없는 게임에서 CFR의 평균 전략은 반복할수록 같은 균형으로 수렴할 뿐이어서 비교 실험은 하지 않았다.

## 8. 고급 탐색 (축 F)

- **PMF-Expectimax (방법 15):** v5-E — 내 기록 → 상대 다음 턴(DP Expert 정확 결과 분포) → 내 다음 턴(정확 롤아웃) → 이후 DP Expert. 정확 PMF 말단. 개발 시드에서 v5-B3 대비 **−0.135%p**(99% CI −0.308~+0.038, 46쌍 변경) — **개선 실패**, 보존. 원인 가설: 상대를 DP Expert로 고정한 depth-2가 실제 반응형 상대(v2)에 대해 편향된 말단을 만든다(§3.3의 과대평가 편향과 같은 방향).
- **Expectiminimax vs Expectimax vs MCTS:** 종반 exact expectiminimax(상대 최적 대응), v5-E expectimax(상대 고정), 기존 DP-guided MCTS(표본 롤아웃, 2026-11-20 48경기 42.7%)를 구분한다. 새 MCTS는 구현하지 않았다 — 정확 PMF 말단이 있는 한 표본 기반 탐색은 분산만 추가한다고 판단했으며, 이 판단 자체는 실험으로 검증하지 않았다.
- **Variance reduction (방법 16):** 같은 시드 + 좌석 교대(공통 난수·대칭 대조)를 모든 대국에 적용. 시드쌍 분산이 "두 경기가 독립일 때"보다 얼마나 작은지를 CRN 분산 감소 계수(VRF)로 측정했다(§6 표). 비슷한 정책끼리일수록 크다(v3 vs v2 10.2×, v5-X3 vs v2 8.5×, v5-R vs v2 2.6×). 편향은 없다(각 시드의 두 경기 모두 실제 규칙대로 진행). Antithetic/control variate는 별도 구현하지 않았다.
- **Adaptive compute / VOI (방법 17):** v5-E는 롤아웃의 상위 두 카테고리 차이 < 0.02(또는 0.05)일 때만 depth-2를 실행 — 판단 평균 3.5 ms(p99 81 ms) vs 고정 0.07 ms. 성능 이득이 없어 채택하지 않았다.

## 9. 엔지니어링 (축 G)

- **네이티브 엔진 (방법 18):** C++ 은행 빌더 3.04 s(TS 56.4 s, 18.5×). WASM·SIMD·Web Worker는 구현하지 않았다. 롤아웃 의사결정 자체는 TS에서 0.07 ms라 네이티브화 필요가 없고, 병목은 은행 메모리·로딩이다.
- **Paired stratified evaluation (방법 19):** 시드 family 분리(개발 9001~9099 / 확증 9501~), 좌석 교대, 시드쌍 CI, 같은 시드 paired contrast, 사전 지정 표본 수, Holm 보정. SPRT는 쓰지 않고 고정 표본으로 진행했다.
- **Red-team (방법 20):** DP Expert, Win DP v1/v2/v3/v4-D, Greedy, Expectimax, myopic(극단적 즉시 득점형), switcher(전반 6턴 myopic → 후반 v2 전략 전환형, 학습·개발에 쓰지 않은 상대). 외부 공개 AI의 원본 실행 파일과 동일 규칙 대결은 하지 않았다(2026-11-21 규칙 적응판 연구 참고).
- **Expert Iteration / Distillation:** v5-R은 이미 0.07 ms라 경량 정책으로 증류할 계산상 이유가 없다. 남은 과제는 은행 메모리를 줄이는 "가치 증류"(PMF 은행 → 작은 신경망)이며 구현하지 않았다.

## 11. 한계·미완료

- **세계 SOTA 아님.** 외부 공개 AI 원본과의 동일 규칙 대결, 인간 상대 평가는 하지 않았다. 확증은 이 저장소의 AI들(+ 레드팀 2종)에 대해서만이다.
- v5-R의 개선은 "이번 턴만 승리 목적 최적화 + 이후 DP Expert" 1단계 정책 개선이다. 상대 반응을 포함한 전체 게임 최적성(완전 Nash)과는 거리가 있으며 그 거리는 측정하지 못했다(4칸 이하만 정확).
- 정확 PMF는 **자기 점수판에만 반응하는 정책**에서만 정확하다. v2/v3/v4/v5 같은 반응형 상대에 대한 PMF는 근사다(§2.2).
- 확증 9501은 개발 9001과 같은 코드로 사전 지정했지만, 한 연구 안에서 여러 후보·상대를 비교했으므로 다중 비교를 고려해야 한다(§6, Holm). 9502 CI 재현은 9501과 독립 시드다.
- 판단 시간은 CI runner(Ubuntu 24.04, Node 24) 기준이며 휴대폰·브라우저에서 측정하지 않았다. WASM·Web Worker 미구현.
- 잔차 신경망·분포형 가치·Cross-Attention·PSRO 새 오라클·CFR·MCTS는 측정만 했거나 근거를 들어 구현하지 않았다(§5, §7, §8).
- 동일 시드 공통 난수 구조 때문에 시드쌍 결과가 같은 경우가 많아(VRF 2.6×) 효과 크기가 작아도 CI가 좁다. 이는 정상적인 분산 감소이며 편향이 아니다.
