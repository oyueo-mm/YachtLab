이 절은 확증 시드(9501~)로 단 한 판도 두기 전에 작성·커밋한다.

- **개발·선택 시드:** family 9001~9099 (9001 = 후보 비교, 9002 = 스모크, 9003 = 가치 정확도). 이 시드로 후보를 골랐으므로 9001의 수치는 "개발 결과"이며 홀드아웃이라고 부르지 않는다.

- **Apex 후보 선택 규칙:** 개발 시드 9001에서 Win DP v2 상대 승리 점수율이 가장 높은 v5 변형. 차이가 개발 표본의 오차(±0.3%p) 안이면 더 단순·빠른 구성을 고른다(복잡한 구성은 확증에서 별도 절제 실험으로 검정).
