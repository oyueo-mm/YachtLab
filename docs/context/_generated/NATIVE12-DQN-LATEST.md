# 12칸 한국식 요트다이스: 독립 사전학습 DQN vs YachtLab Win DP v2

## 재현 범위 및 규칙 감사

- 최초 출처: https://github.com/The7Even/Yacht_AI (커밋 984ba6644644700a9f3465f84f3a39b8b447947b)
- **실제 모델:** 12칸 요트다이스로 훈련한 원본 PyTorch DQN의 공개 가중치 파일을 직접 다운로드하고 SHA256 검증하여 실행했음. 원본 AILearning.py의 30→256→256→128→12 모델 구조와 feature scaling, 카테고리별 argmax 유지.
- **중요한 구조적 제약:** DQN은 재굴림을 학습하지 않았다. 저자 학습 코드의 smart_reroll_turn 규칙으로 1·2차 리롤을 고른 뒤, 3번째 주사위 결과를 보고 DQN이 카테고리를 선택. 원저자의 RL은 솔로 득점 최대화 훈련이며 2인 승률은 따로 학습하지 않았음.
- **거의 같은 12칸이나 완전 동일하지 않음:** 저자는 5개 같은 눈을 풀하우스에도 허용하나, YachtLab 기본 규칙은 3+2 조합만 풀하우스로 인정함. 이번 대국에서 해당 조건 때문에 점수가 달라질 수 있었던 선택 수: **20건**. 따라서 이런 오차까지 원본 학습이 고려한 룰의 정확한 직접 대전으로 해석하지 말 것.
- 선후공 교환·1000개의 비중복 실험 시드 쌍·총 2000경기; **같은 시드는 동일한 난수 출발점이지 정책이 다를 때 모든 주사위가 동일하다는 보장이 아님.**

## 3. 실험에서 얻은 연구 가설

- **정확한 DP를 학습 교사로 사용:** DQN은 리롤 결정을 규칙 기반으로 수행하여 장기 점수 손실이 커질 수 있다. 원래 소스와 차별화해 12칸의 정확한 기대점수·선택을 teacher로 사용하는 imitation/DAgger/ExIt 형태를 비교하면 유의미한 개선 연구가 가능함.
- **경쟁형 목표가 필요:** DQN은 솔로 기대점수 최적화 및 63점 보너스 shaping에 초점을 맞춘 반면 Win DP v2는 후반 경쟁 승률을 최적화. 동일한 모델 구조로 reward를 final score vs win-credit vs margin-shaped reward로 바꾸는 ablation을 진행할 것.
- **상단 보너스 장기 계획:** upper completion rate, 카테고리별 기회비용, 실패한 점수판 마스크에 대한 진단을 해야 하고, 보너스 여부가 승률에 미치는 효과를 일반화하기 전에 독립적인 추가 시드가 필요.
- **학습 목적과 규칙 불일치:** 외부 모델은 5-of-a-kind/Full House 인정 규칙이 달라 전이 성능 평가에 약간의 어긋남. 모델의 독립 평가와 별개로 원본 12칸 버전/완전히 동일한 규칙으로 재학습한 모델의 비교가 더 엄밀함.

## 4. 논문 가능성과 새로움 검증용 기준

- 기존에 Pawlewicz의 multiplayer Yahtzee 최적 근사 연구, 2026 Yahtzee RL 논문, 알고리즘 전수조사 및 일반 DP가 존재함. 단순히 게임 AI가 강하고 여러 모델을 이겼다는 결과만으로 독창성이 증명되진 않음.
- 후보 연구 질문: **정확한 12칸 단일 게임 DP 교사 + 상대 정책 조건부 종반 exact best response + 불확실성을 정량화한 경쟁형 정책 개선**이 임의 상대에 대해 일반화되는가?
- 필수: 규칙 불변/변형별 실험 프로토콜, 독립 학습 시드, 사전 정의된 모델 선택 규칙과 평가 시드, 보수적 CI·다중 비교 보정, 정상 상대 모델 대결, 휴리스틱·기대점수 DP·다른 승률 DP·MuZero/PSRO 기준, worst-case/expected exploitability bound 또는 엄밀한 finite-horizon regret bound(가능 범위), 해당 주장에 맞는 아블레이션 및 공개 재현 코드.
- 특히 'SOTA'는 본 연구의 일부 규칙/프로토콜에서 검증된 경우에만 조건부 표현해야 함.
