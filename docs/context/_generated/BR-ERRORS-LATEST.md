# YachtLab: 마지막 턴 Win DP v2 판단 오류 전수 검색

> Win DP v2가 실제 Win DP v2 후공의 행동을 DP Expert로 대신 가정하는 경우의 정확 최종턴 Best Response. **실제 기준 점수판 400개 × 모든 첫 주사위 252가지 = 100,800 상태를 전수 계산**. 이 전수는 전체 12라운드 상태공간 전수가 아니다.

**해석:** 기존 행동과 정확 BR의 첫 행동이 같더라도, 이후 재굴림에서 최적 선택이 달라져 실제 조건부 승률 이득이 발생할 수 있다. 따라서 첫 행동 변경 확률보다 양의 승률 손실이 발생하는 확률이 클 수 있다. 각 점수판에서 모든 처음 주사위 결과를 정확 확률로 가중했다. Win DP v2 전체 마지막 턴 정책의 실제 승률과, 후공 Win DP의 적응을 알고 최적화한 선공 정책의 승률을 같은 점수판에서 비교했다. 관측 점수판 사이의 변동을 신뢰구간에 반영했다. 100,800개의 주사위 상태를 독립 표본으로 간주하지 않았다.

## 주의
- 후공의 고정 점수 대응 Win DP 정책은 정확히 모델링했지만, 2개 이상 남은 부분게임에는 다른 분석이 필요하다.
- 정확히 분석한 범위는 **이미 주어진 마지막 1대1 점수판에 조건부로 계산하는 승률 차이**다.
- 상대 정책을 바꾸거나 전체 12라운드 최강이라고 주장할 수 없다.
- 실제 전역 승률 개선은 다른 난수 시드와 독립적으로 많은 선후공 맞대결로 확인해야 한다.
- 기본 웹 AI Win DP v2는 변경하지 않았다.
