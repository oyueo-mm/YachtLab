## 검증 규칙과 한계
- Win DP v2를 상대로 실제 12카테고리 2인전 선후공 쌍을 평가. 승리=1, 무승부=0.5, 패배=0.
- 각 훈련 시드는 서로 다른 가중치와 훈련 난수. 최종 5개 모델은 후보를 선택한 뒤 새로 20,000게임씩 학습.
- 최종 확인용 난수와 예선/본선 평가용 난수 분리. 정해진 후보 하나만 최종 확증. 후보를 확증 결과로 교체하지 않음.
- 5시드 t(4)와 1,200 독립 주사위 시드간 CI가 모두 50%를 넘어야 경쟁 우위 가능성을 표기.
- 후보 24개는 현실적 예산 내의 사전 지정 탐색이고 **가능한 모든 AI 알고리즘을 완전 탐색한 것은 아님**. 반복적 탐색이나 다른 상대·규칙에 대한 우위는 별도 검증 필요.
- 최종 판정: **No 95% independent, across-training-seed confirmed advantage vs Win DP v2.**.
