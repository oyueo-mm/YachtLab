# QR-DQN 4대 개선 연구 — 기존 실행 무효 / 수정 재실험 준비

> **경고: 최초 실행 #44871846426의 모델 성능 통계는 무효입니다.** 10개 실험 설정의 TD 할인율 `gamma` 누락으로 모델 가중치가 NaN으로 오염되었으며, 원시 아티팩트에서도 null로 직렬화된 네트워크 가중치를 확인했습니다.

- 오류 감사 및 확인 증거: [QR-FOUR-PILLARS-INVALID-RUN.md](../QR-FOUR-PILLARS-INVALID-RUN.md)
- 수정 연구 구현: 할인율 `gamma=0.99`, 비정상 TD target/행동 가치/네트워크 가중치 검증, 회귀 테스트.
- **오류 수치의 49.767%, 49.267%, 0.000% 등의 모델 간 비교를 정상 QR-DQN 학습 성적이라고 해석하면 안 됩니다.**
- 검증 통과 후 새 실행에서 발생한 값만 이 경로에 게시할 예정입니다.
- 기본 Win DP v2는 계속 유지합니다.
