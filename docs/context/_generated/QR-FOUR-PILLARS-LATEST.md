## 구현과 해석상의 경계
- control은 기존 Double-Q target 구조이며 noDouble은 target 네트워크의 max-value로 업데이트하는 단일 요인 절제 실험.
- lr02 / target250 / perIS는 learning rate, target sync, importance correction 각각 독립 대조. richStable은 조합 효과이므로 단일 인과 기여로 분해할 수 없음.
- unrestricted는 DP 기대점수 손실에 따른 행동 후보 제외를 해제하고 마지막 2칸 Win DP v2 강제 정책도 해제. **DP의 기대점수 Q는 상태 입력으로 여전히 사용**하므로 완전히 DP-free 모델은 아님.
- normalized rich state는 상대·자신의 공개 점수판과 보너스, 남은 칸, 주사위로 구성되며 비공개 RNG/게임 seed는 관측하지 않음.
- 5k 실험을 서로 비교하고 20k 실험은 별도 집합으로 구분. 50개 이상의 설정·시점 비교에서 다중검정 및 모델 선택 편향 경고가 적용됨.
- 안전장치의 행동당 근사 신뢰하한과 전체 게임 정책 신뢰구간은 서로 다름. 후속 게임은 DP 정책에 의존하는 시뮬레이터 가정이므로 진정한 최적 대응/Nash 보장 없음.
- 원시 5시드 경기별 paired win-credit, 모델 가중치, checkpoint별 기록은 실행 아티팩트에 90일 저장. 배포 기본 AI 자동 변경 없음.
