### 검증 및 해석

- 탐색에 사용한 최초 64·800게임과 별도 시드로 수집했다. 승점은 승리 1 / 무승부 0.5 / 패배 0. 정규 근사에 기반한 신뢰구간이며 최적성 보증은 아님.
- v2.1의 exact BR은 player0 마지막 카테고리의 **상대가 Win DP v2 정책인 경우에만** 정확한 국소 베스트리스폰스. 다른 상대에는 v2 폴백. 패배 사례 없이 근소한 국소 향상이어도 전체 경기 승률은 차이가 안 날 수 있음.
- v3는 자기 남은 3카테고리 행동을 정확한 chance DP로 계산하지만, 상대의 3개 이상 남은 점수분포는 근사. 3카테고리 이후에만 v2 대신 선택하도록 했음.
- MCTS는 정확한 확률나무 MuZero가 아닌 **유한 샘플 롤아웃과 프록시 보상**. 탐색을 더 많이 돌렸을 때 효과가 재현되는지는 추가 검증 필요.
- 이번 표에서 후보가 통계적으로 승리해도, 실전 승격에는 지연 시간·독립 외부 모델·최소 3개 학습 시드(학습 정책)·다른 상대군·정책 노출 없는 validation 등 별도 통제 필요.
- 사이트 기본 Win DP v2와 배포 동작에는 변경 없음.
