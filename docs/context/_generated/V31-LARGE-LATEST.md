## 해석 규칙

1. CI에 50%/0%가 포함되면 승률 우위는 **미입증**이다. CI가 0으로 수렴해도 sampled outcomes가 같았다는 뜻일 뿐 정책 동일·동등성 증명이 아니다.
2. 동일 시드라도 행동이 다르면 뒤 주사위 경로는 달라진다. 양쪽 자리 교대 + 동일 초기 시드의 짝별 평균으로 측정한다.
3. 대규모 반복 검증으로 발견한 개선사항을 재튜닝하면 새 미사용 시드에서 별도 확인해야 한다.
4. 어떤 모델도 실사용 기본값으로 자동 승격하지 않는다.
