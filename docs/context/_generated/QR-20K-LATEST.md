20,000 vs 미학습: -3.320%.

## 보존 및 해석
- 0, 1,000, 5,000, 10,000, 20,000에 해당하는 초기/중간/최종 네트워크 모델 가중치, validation, 0/1k/20k 원시 paired 대국은 각 시드 Actions artifact에 저장.
- Win DP v2 상대 확인 결과만으로 QR-DQN이 일반적으로 우수하다고 단정하지 않음. 시드 상관/모델 간 분산/복수 검정에 주의.
- DP Expert는 단독 기대점수 최적이며 승률 최적 정책이라는 가정은 연구 결론에 쓰지 않음.
- DP 2점 행동 후보 제한과 학습자 최종 2칸 Win DP v2 폴백은 **이번 20k에도 유지**. 완전한 DP 비제약형 학습이 아님.
- 배포 중 AI 유지. 확인 우위 및 안전성/성능 검증 전 승격 금지.
