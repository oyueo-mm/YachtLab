## 3. 출처와 규칙 적응 범위

### Rust HeuristicBot — 실제 규칙 기반 로직을 옮긴 적응판
- 원본: https://github.com/jdh8/yahtzee-engine/blob/f606c6188590b3fe68964d42665fb45e4cef2f28/src/heuristic.rs
- 변환: 같은 눈 3개, 스트레이트, 상단 페어, 높은 눈을 고정하는 우선순위. 완성된 족보를 기록하며 점수에서 파값(par)을 빼는 카테고리 선택. 13칸 three-of-a-kind 삭제, 12칸 득점 사용. 원본 par 미재학습.

### Rust OptimalBot — 동등한 목적함수의 대리 정책
- 원본: https://github.com/jdh8/yahtzee-engine/blob/f606c6188590b3fe68964d42665fb45e4cef2f28/src/solver.rs
- 원본은 정확한 전체 기대점수 Expectimax. YachtLab 12칸에서는 DP Expert가 동일 Bellman 목적을 풀기 때문에 이를 대리 정책으로 사용했다. **원본 Rust 코드를 직접 실행하지 않았고, 독립 구현 비교가 아니다.**

### Pancht C++ DP — 공개 알고리즘 재구현
- 원본: https://seoh136199.github.io/posts/yacht-dice-optimal-selection-algorithm/
- 변환: 상단 1~6 득점 x3 가중 후 후속 카테고리 및 2회 재굴림을 후진 DP로 최적화. 저자의 getAvgScore처럼 **서로 다른 주사위 멀티셋 252개 균등 평균**을 유지하여 실제 멀티셋 발생 확률과의 차이를 일부러 보정하지 않음. 3-of-kind 삭제, 12칸 점수로 대체.

### Benji 경쟁형 승률 최적화 — 목적함수 대리 정책
- 원본: https://github.com/BenjiHilton/yahtzee-vs-optimal/tree/9bc995468fdad998020203c0543d9f0039024d36
- 원본은 **13칸·2회 굴림·joker/+100 보너스**. 원본 Python 실행 파일을 우리 규칙에 직접 사용할 수 없어, 목적함수의 원리만 비교하도록 **YachtLab의 기존 Win DP v3**를 대리로 사용했다. 이는 원저자 Python 솔버 직접 대결이 아니다.

## 4. 원본 AI와 실제 맞붙기 위한 후속 작업
- 13칸 원본 규칙의 별도 경기장을 만들고 Win DP 계열도 13칸으로 포팅하거나, 원저자의 전체 코드를 12칸/3회 굴림 규칙에 독립적으로 포팅해 테스트해야 함.
- 어떤 방향이든 원본 공개 코드가 그대로 실전에서 사용됐다는 주장과 규칙 적응판 비교를 구별할 것.
- 모든 원시 시드·대국은 GitHub Actions 아티팩트에 저장. 사이트 기본 AI 변경 없음.
