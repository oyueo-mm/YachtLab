## 5. 성능 판정과 한계

- 단일 상태의 Bellman 우수성은 *고정된 상대 최종턴 정책에 대해서만* 엄밀하다. 전체 게임 상대 우위 주장은 독립적이고 큰 다중 시드 대국이 필요하다.
- 이전 Win DP v3는 자신의 3턴만 정확 DP하고 상대 미래 점수는 근사 분포를 사용했다. 본 연구의 마지막 1턴은 그와 달리 실제 후공 Win DP 응답까지 정확 계산한다.
- 대량 데이터로 전체 후반부를 확장하려면 상태 캐시, 정책 조건부 점수 분포, 계산 비용 최적화가 선행되어야 한다.
- 모든 결과는 별도 연구 아티팩트이며 **Win DP v2 사용자 기본값을 그대로 유지했다**.
