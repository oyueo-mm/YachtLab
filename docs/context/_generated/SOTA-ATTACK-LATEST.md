## 구성 요소별 의미·주의사항

- **신경망+정확 DP:** 'distilled-policy'는 이미 DP Expert를 교사로 모방학습한 모델이며, 'distilled-ppo'는 이후 PPO fine-tuning한 모델. 이번 워크플로는 별도 고정 테스트 세트에서 재평가한 것이며 **신규 학습은 별도 QR 리서치 작업**으로 분리함. 신경망은 정확 DP보다 강하다는 보장 없음.
- **전체 게임 RL:** 'ppo-fullgame'은 재굴림과 점수 기록을 함께 선택하는 기존 PPO 학습 정책. QR factorial 별도 작업에서 훈련 중 새 체크포인트를 연구; 독립 시드 검증 전에는 배포 금지.
- **정확 상대 최적대응:** 'conditional-br-v21'은 player0 마지막 1칸 vs player1 마지막 1칸에서, 고정 Win DP v2 상대가 최종 점수를 알고 적응하는 최선 응답을 정확히 계산. 그 외 상태와 다른 상대는 v2로 폴백. 마지막 턴 국소 후회 개선은 수학적이지만 전체 경기 이득은 매우 작을 수 있음.
- **MuZero·MCTS 계열:** 'dp-guided-mcts'는 기존 연구용 DP 유도 UCB/확률표본 롤아웃+상대 점수 프록시로, **MuZero를 학습하거나 정확한 chance-node 계산을 구현했다고 주장하면 안 됨**. 성능이 나쁘다면 샘플링 오차·프록시 오차·비교 시뮬레이션 예산 부족이 가능한 원인.
- **v3 3칸 경쟁형:** 'calibrated-v3'은 이름은 유지하되 실제로는 **기본 미보정 상대 분포**를 사용한다(캘리브레이션 파라미터를 넘기지 않았음). 자기 남은 3칸의 조건부 확률 DP는 정확하나 상대가 3칸 이상이면 분포 근사. 하위 결과는 근사된 상대 분포 성능 평가이지 정확 게임이론적 최적성 평가 아님.

## 신뢰도

- 대국은 모든 상대에 대해 공개 주사위 상태를 입력으로 사용. 동일 시드·선후공 교대의 1쌍을 표본 단위로 계산하며 서로 다른 정책은 주사위를 다르게 다시 굴릴 수 있으므로 전체 난수 경로가 반드시 같지는 않음.
- 6개 모델 비교의 보정은 z≈2.638의 정규 근사이며 소규모 샘플에서 정확 검정이 아님. 0.5가 신뢰구간에 포함되면 '동급'이 아니라 **우열 미확정**이라고 해석.
- 알려진 고정상대 정책에만 유리한 BR을 전혀 다른 상대에 적용하면 악화될 수 있으므로, 임의 상대에 대한 강함은 별도 시험 필요.
- Main Win DP v2와 홈페이지 변경 없음. 이 실험으로 통과된 모델도 추후 3개 이상 독립 학습 시드/분리 검증/latency/관측 상태 불변성 조건 전까지 자동 승격하지 않음.

## 다음 연구로 연결

- 관측된 반례/최종 상태를 저장해 정확 BR과 기준 행동을 비교하고, 유효한 국소 개선만 축적.
- 확률 노드는 모든 가능한 주사위 분포를 이미 DP가 정확히 계산하므로, 실제 MuZero 도입의 차별점은 **거대 게임 상태·상대 전략 불확실성 탐색**에 있어야 함.
- 가치/정책 신경망 학습·MCTS에서 공통 주사위 시드와 독립 홀드아웃을 유지하고 고비용 계산 전략의 결정 지연까지 측정해야 함.
