## 해석 및 재현성

- 99% 신뢰구간은 **25,000개 시드쌍**의 좌석 교대 결과를 한 관측 단위로 계산. Holm 조정 p와 Bonferroni 다중검정 구간은 각 대진이 50%인지 별도 평가.
- DP Expert: 단일 게임 총점 기대값 최적. 대전 상대에 따른 승률 최대 정책을 뜻하지 않음.
- v4 원본: imitation+REINFORCE, 후반 v3.4 (2후보×2롤아웃). v4-D: REINFORCE 단독 학습, 후반 v3.3.
- 사전 등록된 네 모델 상대에게만 검증했으므로 임의의 사람/다른 AI를 대상으로 한 세계 최강이라는 주장은 불가.
- 서비스 AI 기본값은 변경하지 않음.
- 시드별 원본 기록: GitHub Actions `foundation-4way-*`.
