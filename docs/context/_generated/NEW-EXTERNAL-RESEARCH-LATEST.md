## 3. 원본 구현에서 얻을 아이디어

- **Dart HardAI (공개 2-ply sampled Expectimax):** 원본은 각 행동을 6~36개 샘플로 추정. 후보별 비교용 난수를 일치시키지 않아 표본 오차가 행동선택에 들어갈 수 있다. YachtLab에서는 정확한 주사위 분포를 Bellman 백업하므로 그런 표본 오차 없이 안정적인 행동 선택이 가능하다. 반대로 고비용 상대 정책을 모델링할 때는 일정 계산 예산에서 표본 탐색이 유용하다.
- **Dart MediumAI:** 족보 우선순위가 가장 앞선 카테고리라면 0점이라도 그 칸을 먼저 채우는 원본 범주 우선순위에 약점이 있다. YachtLab의 DP 기회비용 계산 및 보너스 장기 계획과 비교해 검증한다.
- **Pape A2C (2026):** 직접 학습된 체크포인트가 공개돼 있고 13칸 Yahtzee 평균 241.78점(원본 규칙에서 솔로 DP 최적값 254.59점)에 근접했다. 상단 보너스 전략을 충분히 학습하지 못한 점이 주요 약점으로 보고됨. '큰 보상으로 이어지는 희귀 사건의 장기 신용 할당'을 YachtLab의 모델 기반 정책 교사/훈련에 반영할 가치가 있음. 원본 13칸 학습 신경망은 12칸에 직접 호환되지 않으므로 이번 승률 대회에 포함하지 않았음. https://arxiv.org/abs/2601.00007 , https://github.com/papetronics/case-studies-final-project
- **독립 Exact DP 구현 (jeeshofone):** 원본 기대점수 최적 DP는 13칸·joker 규칙 사용. 같은 목적함수는 이전 12칸 YachtLab DP Expert와 이미 비교했지만 원본 소스 자체의 독립 이식 검증은 차후 별도로 해야 함. https://github.com/jeeshofone/yahtzee
- **OpenSpiel Yacht:** 게임 환경이 공개돼 있으므로 미래의 CFR/PSRO/상대 정책 계산 실험 기반 후보. 단지 OpenSpiel을 사용한다는 이유만으로 강한 AI가 존재한다고 주장하지 않음. https://github.com/google-deepmind/open_spiel

## 4. 연구 범위

- 각 모델 320게임(160쌍), 총 640게임. 큰 차이 검출에는 유효하지만 50% 근처의 작은 차이나 외부 SOTA 여부에 대한 결론에는 불충분할 수 있다.
- 외부 AI의 다른 규칙을 12칸으로 적용하고 샘플러를 고정한 소스 논리 포트라는 점 명시.
- 실제 웹사이트 Win DP v2 선택 로직 수정 없음. 원시 경기 로그는 Actions 아티팩트로 보관.
