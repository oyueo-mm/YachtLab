### 사전 지정된 설계
- baseline32: 79→32→16 QR 구조, gamma=.99, lr=.02, 250게임 target update, PER+importance correction, 12k replay, terminal-only 1-step TD, DP 손실 2점, 최종 2칸 Win DP v2.
- lr005: 학습률만 .005, target500: target sync 간격만 500.
- uniformReplay: PER을 균일추출로 교체; phaseBalanced: 3개 진행구간 균형 추출 후 구간 내 PER (단계별 importance가 전체 표본분포에 대해 불편인 것은 아님).
- monteCarlo: 전체 게임 결과를 이전 모든 자기 행동에 discount로 직접 전파; nstep3: 3개 자기 행동 간격의 Bellman n-step bootstrap 및 종단 시 할인승패 보상.
- wide64 / wide128: normalized rich state 79차원, 1개 tanh 은닉층 64 / 128뉴런, 출력 분위수 16개, 나머지 하이퍼파라미터 baseline32와 동일.
- 승점은 승리 1, 무승부 0.5, 패배 0. 상대는 Win DP v2 와 pure DP Expert; 양 좌석 교대, 기존 대국의 난수 시드와 중복되지 않는 확인 대국.
- 5개 학습 시드간 t(4) CI는 표본 수가 작은 클러스터 불확실성이며, 여러 대조실험 사이 다중검정 유의확률을 보정하지 않았다.
- 가치/리플레이/보상전파/네트워크 폭은 **각각 단일 인자로 비교**한 결과. 설정 간 상호작용, 장기 학습 개선 또는 이론적 최적성은 보장하지 않는다.
- 새 모델은 기본 AI로 자동 승격하지 않는다.
