## 1. 한 줄 요약

v5-R 시험판이 이미 브라우저에서 만드는 **DP Expert Float32 은행 1개를 그대로** 쓰고, 판단 함수만 `winDPv5Decision` → `productV7Decision`(I2RO1)으로 바꾼다. 추가 메모리는 없고 판단 연산만 늘어난다(평균 수 ms, 최악 수백 ms 이하, §3).

## 2. 알고리즘 (I2RO1)

1. 내 턴의 모든 득점 결과(칸, 점수)에 대해,
2. 상대가 다음 턴을 **자기 승리점수율 최대화**로 정확히 둔다고 가정(상대 미래 = DP PMF, 내 미래 = DP PMF),
3. 그 턴 결과와 이후 DP로 상대 최종 점수 혼합 PMF를 만들고,
4. **내 다음 턴을 그 PMF에 대해 정확히 푼 값**(승 + 0.5·무)을 정지가치로 쓴다.
5. 현재 턴의 재굴림 정책은 이 정지가치에 대해 정확히 푼다(v5/v6와 같은 동점 규칙).

은행이 하나뿐이라 v6-P·I1·I1R·I1O·I1RO 같은 다중 은행 구분은 사라진다(V7 §9.1 동치표). I2R1(폐루프, 내 다음 턴을 상대 결과마다 풂)은 regret이 조금 더 낮지만 약 15배 느려 고급 후보로 남긴다.

**결론(트랙 A):**
- **v4-D 교체 가능(성능 확증).** I2RO1은 v4-D를 +0.55%p(Elo +3.8) 앞선다.
- **v5-R 대비 우위는 미확정.** 같은 시드에서 v5-R도 v4-D 상대 50.547%로 거의 같고, 직접 대결 +0.064%p는 유의하지 않다. 종반 정확 regret은 I2RO1이 v5-R보다 75~85% 낮다(결정 품질 우위, 대국 이득은 작음).
- **추천:** 메모리는 v5-R과 같으므로, 실기기에서 판단 시간이 허용되면 **I2RO1**을 매우 어려움 후보로, 허용되지 않으면 **v5-R**을 쓴다. 두 모델 모두 v4-D보다 강하다. 어느 쪽이든 기존 v5-R 시험판 인프라(은행·캐시·폴백)를 그대로 쓴다.

## 5. 통합 방법 (제품 코드는 Codex가 수정)

```ts
// src/product-ai/product-worker.ts 안에서 (현재 winDPv5Decision 호출 자리)
import { productV7Decision, PRODUCT_V7 } from "../research-v7/product";
const result = productV7Decision(data.position, config);          // config: 기존 V5Config 그대로
const base = { value: result.value, candidates: result.candidates, note: result.note, execution: { id: PRODUCT_V7.id, version: PRODUCT_V7.version } };
```

- 은행 생성·OPFS 캐시·Web Locks·폴백 경로는 v5-R 시험판 것을 그대로 쓴다(은행 형식과 캐시 키 변화 없음).
- 공정성 경계: 지금처럼 `publicDecisionState`(seed 0, rng [0,0])만 워커로 보낸다. I2RO1은 점수판·주사위·굴림 횟수·차례만 읽는다.
- 굴림 전 상태(`rolls === 0`)에서는 호출하지 않는다.
- 폴백: 워커 오류·시간 제한(권장 3 s) 시 해당 경기의 남은 AI 행동은 v4-D(현행 규칙). 판단이 오래 걸리는 기기를 위해 2단 폴백(I2RO1 → v5-R 즉시 판단 → v4-D)을 권장한다. v5-R 판단은 같은 은행으로 0.1 ms다.
- 기보의 `decision.execution`에 실제 실행 모델(`v7-I2RO1` / `win-dp-v5-r` / `win-dp-v4-d`)을 기록한다.
- 복기 분석(`analyzeV6` 등)은 바꾸지 않는다.

## 6. 롤아웃 단계 제안

1. 시험 URL(`?ai-model=v7-i2ro1`)로 노출, 기본값은 v4-D 유지.
2. 실기기 점검(§7) 통과 + 9571 HA1 채택 → 매우 어려움 기본값 후보.
3. 기본값 교체는 사용자 결정.

## 7. 실기기 검증 절차 (미완료)

v5-R 절차([V5-R-PRODUCT](./V5-R-PRODUCT.md#androidios-실기기-검증-절차))와 같고, 추가로:
- AI 선공 첫 턴(가장 무거운 국면)의 판단 시간과 화면 응답성(애니메이션 끊김)을 기록한다.
- 연속 3경기 후 탭 메모리와 판단 시간이 늘지 않는지 확인한다.
- 저사양 Android(예: RAM 3~4 GB)에서 첫 턴 판단 최대 시간 ≤ 3 s를 목표로 한다. 초과하면 2단 폴백을 켠다.

## 8. 검증되지 않은 사항

- 9581 독립 재현(진행 중)과 I2RO1의 v5-R 대비 우위(미확정).
- 물리 Android·iOS 기기의 판단 시간, 최대 메모리, 백그라운드 복귀.
- 경합 없는 정식 Chromium·저사양 에뮬레이션 수치.
- I2R1의 대국 우위(개발 2샤드만, 판별력 없음).
