# 게임 리뷰

완료한 12카테고리 1인 및 1:1 경기에서 게임 리뷰를 연다. 경기 종료, 기기 기보, 최근 대전 전적에서 진입할 수 있다. 3인 이상은 기보 재생을 제공한다.

- 1인 기준은 DP Expert의 기대 최종점수다. 2인 기준은 승리점수율이다. v5-R 단일 은행이 추정값을 계산하고 순차 1:1의 마지막 칸은 정확히 푼다.
- 정확도는 최선과 실제 선택의 가치 차이를 0~100점으로 바꿔 평가한 행동끼리 평균한다. 주사위 운은 첫 굴림과 재굴림마다 실제 결과의 가치에서 당시 조건부 기대를 뺀다. 기호, 단위, 미평가 조건, A5 계약은 [C2 게임 리뷰](./C2-GAME-REVIEW.md)에 있다.
- Web Worker는 공개 카드·굴림·차례·확정 행동을 받는다. 시드, 계정 식별자와 토큰은 리뷰 분석 입력에 포함되지 않는다.
- 온라인은 서버의 완료 여부와 본인 좌석을 확인한 뒤 분석한다. 회원은 본인 경기의 인증된 아카이브를 쓸 수 있다. UserStore SQLite는 최근 64경기 리뷰를 기존 정산과 함께 저장한다. 게스트는 같은 탭에서 연속 이벤트를 확보한 경우 분석할 수 있다.
- 새 오프라인 AI 전적은 IndexedDB의 원본 기보 UUID를 공유한다. 과거 기록은 이 기기에 유일하게 연결되는 실제 기보가 있을 때 열 수 있다.
- 기존 게임 리뷰에서 그래프, 타임라인, 추천 행동, 가상 다시 도전을 이용할 수 있다. 최종 점수차 분포는 양측이 DP Expert의 정책을 따르는 경우의 분포다.
