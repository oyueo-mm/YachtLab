# AI 복기

완료한 12카테고리 1:1 경기에서 AI 복기를 연다. 경기 종료, 기기 기록과 기보, 온라인 전적의 진입점을 제공한다. 기기 AI 경기와 로컬 1:1의 기존 기보는 실제 상태를 복원한다. 온라인은 서버가 완료한 본인 경기만 복기한다. 회원의 새 1:1 경기는 서버가 기록과 함께 복기 자료를 보관하므로 다른 기기의 최근 전적에서도 열 수 있다. 게스트는 같은 탭에서 연속 이벤트를 확인할 수 있는 동안 지원한다. 이전 온라인 기록은 보통 최종 점수와 결과만 담고 있어 부족한 데이터를 화면에 알린다. 3인 이상 기보 재생은 별도로 제공한다.

## 수치의 기준

- **기대 최종점수**는 기존 DP Expert 표와 독립 공정 주사위로 계산한다. 각 국면에서 합법 점수 기록과 주사위 ID별 킵 조합을 평가한다. 선택이 같은 눈을 남기면 동일한 가치를 가진다.
- **결정 손실**은 최선 기대점수와 확정한 행동의 기대점수 차이다. Float64 연산 오차 1e-8점 이하는 동률로 취급한다. 행동별 표시는 최선과 동률인 선택과 손실이 있는 선택으로 구분한다. 정확도는 평가한 행동 중 최선과 동률인 비율이다.
- **굴림 운**은 실제 다음 굴림의 최선 기대점수에서 확정한 재굴림의 사전 기대점수를 뺀 값이다. 재굴림을 확정하기 전의 킵 토글과 자동 기록은 판단 통계에서 제외한다. 실제 다음 굴림은 운 계산에만 쓴다.
- **종반 승리점수율**은 순차 진행에서 양측 각각 최대 한 칸이 남았을 때 Win DP v5의 정확 expectiminimax를 호출한다. 승리 1, 동점 0.5, 패배 0으로 계산한다. 기대점수 기준과 비교해 추천을 따로 표시한다. 그 밖의 행동은 종반 그래프에서 제외한다.
- **점수차 분포**는 기록 직후 양측 남은 칸이 각각 두 개 이하일 때, 양측이 이어서 DP Expert를 따른다고 가정한 별도 정책 분포다. v5 승리점수율과 가정이 다르다. 299MB 연구용 PMF 은행은 제품에서 내려받지 않는다. [v5 연구와 분석 인터페이스](https://github.com/oyueo-mm/YachtLab/pull/75)

## 저장과 화면

브라우저 Web Worker에는 공개 카드, 보이는 주사위, 당시 차례 및 행동을 보낸다. 시드, 계정 식별자와 토큰은 복기 데이터에 포함되지 않는다. 온라인 분석은 서버의 완료 상태와 본인 좌석을 확인한 뒤 노출한다. Worker를 취소하거나 재시도해도 원본 기보에 쓰지 않는다. 클라이언트의 온라인 임시 기록은 탭 메모리에서 세션 변경 시 지운다. 회원이 요청한 자료는 인증된 본인 전적에서만 읽을 수 있다. 기존 UserStore SQLite 내부에서 최근 64경기의 복기를 저장하며 결과·재화와 같은 정산으로 기록한다. 일반 전적 목록에는 큰 복기 자료가 포함되지 않는다. 기기 기보 분석은 버전과 기보 내용 해시를 키로 최근 16개를 저장한다. 같은 표시 이름 대진의 같은 모델 결과가 5경기 이상일 때만 기기별 평균 결정 손실 변화를 보여 준다.

라운드·행동 탐색과 그래프 선택을 동기화한다. 양쪽 점수판, 실제·추천 행동, 기대점수 손실이 큰 행동, 상단 보너스까지 필요한 점수와 남은 칸을 표시한다. 원본과 분리된 가상 행동을 실행하거나 답을 숨긴 상태에서 국면을 다시 선택할 수 있다.

초중반 승리점수율·분포, 여러 대진에 걸친 전략 성향과 상세 위험 코칭은 확장 항목이다. 역대 온라인 요약에 행동 데이터를 소급 생성하지 않는다.

## 게임 리뷰 화면과 정확도

게임 리뷰는 경기 결과·당시 주사위·점수판·행동 타임라인을 한 화면에 제공한다. 그래프는 현재 엔진이 계산한 행동만 이동할 수 있게 표시한다. 과거 기보, 분석 캐시 및 회원 리뷰 API 식별자는 유지한다.

점수 정확도와 승리 정확도는 각각 평가 가능한 행동의 `100 × exp(-max(0, 손실 - 허용오차) / 척도)` 평균이다. 점수는 0.1점/8점, 승리점수율은 0.25%p/10%p를 사용한다. 모든 합법 행동 값이 0, 0.5, 1 중 동일한 값으로 확정된 국면은 승리 정확도에서 제외한다. 지원되는 종반은 승리점수율 손실을 적용하고 나머지는 기대점수 손실을 적용해 행동 기호를 매긴다. ★·✓·?!·?의 손실 상한은 각각 점수 0.1/1/3/8점, 승리점수율 0.25/1.5/4/10%p이며 초과는 ??다. !와 !!는 전략적 난이도 기준을 검증할 때까지 유보한다. 수치는 인간 플레이로 보정하기 전의 제품 기준이다.
