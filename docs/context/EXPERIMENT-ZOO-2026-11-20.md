## 1. 58개 전체 게임 정책·설정 탐색

실제 **12개 카테고리 닌텐도식 요트다이스, 5주사위, 턴당 최대 3회 굴림, 상단 보너스**의 엔진을 사용했다. 12개 기법 계열에서 매개변수를 포함해 58개 설정. 58개가 전부 서로 다른 원리의 알고리즘이라는 뜻은 아님.

| 실험 단계 | 실제 게임 수 | 시드 용도 |
|---|---:|---|
| 58개 정책 스크리닝 | 6,384 | 탐색(성능 주장 금지) |
| 상위 12개 + Win DP v2 재평가 | 10,400 | 후보 선택 |
| 선택된 후보 + 대조 정책의 독립 대결 | 29,000 | 최종 검증 |
| **합계** | **45,784** | 양 좌석 교대 |

모든 대전은 각 선수의 **독립 PRNG 스트림**으로 수행하고, 한 시드당 두 좌석 순서를 사용했다. 승리 점수율=승리 1/무승부 0.5/패배 0. 95% 구간은 좌석 교대 **시드별 두 경기 평균**의 정규 근사.

### 후보 선택과 최종 확증

2차 탐색 상위 5개 (모두 **DP Expert 상대 800경기**, 확증 아님):

| 후보 | 탐색 승리점수율 |
|---|---:|
| trailGate--5 | 50.6875% |
| guidedConditional-20 | 50.4375% |
| trailGate--15 | 50.4375% |
| 기존 Win DP v2 | 50.2500% |
| trailGate--25 | 50.0625% |

`trailGate--5`는 마지막 두 카테고리에서 예측 최종점수 격차가 **-5점 이하**일 때만 Win DP v2를 적용하고, 그 외는 기대점수 DP를 사용한다(마지막 한 칸은 Win DP v1). **데이터로 선택한 후보이지 성능 개선이 입증된 모델이 아니다.**

최종 미사용 시드에서 고정 후보를 평가한 직접 경기:

| 후보 | 상대 | 경기 | 승리점수율 | 짝별 95% 근사 CI |
|---|---|---:|---:|---:|
| trailGate--5 | DP Expert | **12,000** | **50.2000%** | **49.9931~50.4069%** |
| trailGate--5 | Win DP v2 | **12,000** | **49.7958%** | **49.5818~50.0098%** |
| trailGate--5 | Win DP v1 | 2,000 | 50.5000% | 49.9868~51.0132% |
| 원래 Win DP v2 | DP Expert | 3,000 | 50.9000% | 50.3610~51.4390% |

**해석:** 선택 후보는 DP Expert·Win DP v2를 상대로 95% 근사 구간이 50%를 포함하므로 유의한 우위를 입증하지 못했다. 특히 **Win DP v2와 직접 대결해도 상회하지 못했다**. 따라서 기존의 Win DP v2가 여전히 가장 검증된 경쟁형 모델이며, 신규 기본 모델로 교체하지 않는다.

앞선 [Win DP v2 vs DP Expert 20,000경기](./RESULTS.md)에서는 50.6300%(95% CI 50.406~50.854%)의 작은 우위가 보고됐지만, 시드가 다른 3,000경기와 점수 자체를 직접 비교해 후보별 우열을 단정하면 안 된다.

### 기존 탐색형 후보/위험 휴리스틱

- Guided UCB/MCTS와 conditional UCB 여러 설정을 비교했으나 탐색·재평가 단계에서 확증 가능한 개선을 얻지 못했다. **후보 별로 동일한 최종 12,000경기 확증을 실행한 것은 아니므로** 모든 탐색 설정이 열등하다는 결론은 아님.
- 위험 성향(volatile dice rerolls)과 카테고리 prior는 **진짜 점수분포/승리 확률이 아닌 대리 지표**. 탐색 중 좋아 보이는 수치를 독립 성능 개선으로 해석하지 않음.
- 평균 점수의 이론적 최적 기준선은 기존 DP Expert이며 새로운 휴리스틱의 평균점수 우위 주장은 무의미하다(수치/환경 오차 제외).
- 선택한 trailGate--5가 **Win DP v2보다 빠르게** 동작한 측정(대략 6.08ms/게임 vs 이전 측정의 11.68ms)은 실행 상태와 상대·측정 구성·시드가 달라 공정한 동일 시드 시간 대조가 아님. 판단 비용 비교는 별도 동일 하드웨어 실험이 필요.

## 2. 딥 강화학습 4종 — 초이스 한 칸만

조건: 이미 다른 카테고리는 없고 **마지막 Choice(초이스) 칸**, 공정한 다섯 주사위·최대 3회 굴림, **25점 이상** 달성 여부. 모델당 **9,000 학습 에피소드**, 별도 **5,000 평가 게임**.

| 알고리즘 | 목표 달성률 | Wilson 95% CI |
|---|---:|---|
| REINFORCE + moving baseline | 16.92% | 15.91~17.98% |
| A2C | 22.02% | 20.89~23.19% |
| DQN | 32.34% | 31.06~33.65% |
| **Double DQN** | **33.38%** | **32.09~34.70%** |
| 고정 5·6 유지 휴리스틱 | 37.24% | 35.91~38.59% |
| 고정 4·5·6 유지 휴리스틱 | 33.98% | 대조 정책 |
| 즉시 종료 | 3.14% | 대조 정책 |
| 랜덤 | 2.92% | 대조 정책 |
| 정확 목표점수 DP (분리된 완전열거 이전 연구) | **약 41.671%** | 무작위 평가가 아닌 이론 기준 |

딥 RL의 네 모델 중 Double DQN 최고. 하지만 해당 훈련량에서는 5·6 유지 휴리스틱보다도 약함. **전체 12라운드 AI로 배포하지 않음.**

## 3. 표형 강화학습 8종 — 같은 초이스 한 칸

**각 250,000 학습 에피소드**, 개별 **10,000 평가 게임**. 상태는 정렬된 5주사위 252개 조합 × 남은 재굴림 상태, 행동은 고정 비트마스크 32개와 점수 확정 1개. 딥 RL과 평가 시드 집합이 다르므로 두 표를 직접 통계 비교해서는 안 됨.

| 알고리즘 | 목표 달성률 | Wilson 95% CI |
|---|---:|---|
| Q-learning | 34.30% | 33.38~35.24% |
| SARSA | 35.10% | 34.17~36.04% |
| Expected SARSA | 34.19% | 33.27~35.13% |
| Double Q-learning | 31.46% | 30.56~32.38% |
| First-Visit Monte Carlo Control | 32.28% | 31.37~33.20% |
| **Dyna-Q** | **37.05%** | **36.11~38.00%** |
| UCB Q-learning | 33.46% | 32.54~34.39% |
| Optimistic Q-learning | 32.58% | 31.67~33.51% |
| 고정 5·6 유지 휴리스틱 | 36.64% | 35.70~37.59% |
| 고정 4·5·6 유지 휴리스틱 | 33.45% | 대조 정책 |
| 랜덤 | 3.33% | 대조 정책 |
| 정확 목표점수 DP (이론 기준) | **약 41.671%** | 해당 없음 |

Dyna-Q가 표형 학습 8종 중 최고. 같은 평가의 휴리스틱(36.64%)과 비교하면 **+0.41%p**이지만 이 결과로 유의미한 우위라고 주장하지 않음. 학습 시간, 초기화 및 하이퍼파라미터의 추가 비교가 필요.

## 4. 집계와 연구적으로 확인된 것

- 총 **58개 전체 게임 정책 설정 + 4종 딥 RL + 8종 표형 RL = 70개 정책·방법/설정**의 실제 코드를 실행.
- **전체 게임 45,784경기** (12카테고리). 별도 축소 문제: 딥 RL 4×5,000 평가 게임 + 대조군, 표형 RL 8×10,000 평가 게임 + 대조군.
- 훈련된 RL 12종의 총 학습 에피소드: **4×9,000 + 8×250,000 = 2,036,000회**.
- 일부 후보는 파라미터 변형이며 서로 독립 알고리즘이 아니다. 58개를 58종 SOTA 알고리즘으로 소개하지 않는다.
- 전체 경기에서는 **새로운 최강 모델을 찾지 못했다**. 전 연구 목표에 부합하는 정직한 음성 결과이다.
- 후속 실험에서는 작은 손실 제한/휴리스틱 게이트를 계속 튜닝하기보다, **상대 정책별 정확한 분포 확대, 3개 이상 남은 카테고리의 경쟁 솔버, 실제 게임을 대상으로 한 residual RL 및 자기 대국**을 우선 권장한다. 이는 제안이며 성능 향상을 보장하지 않는다.

## 5. 재현성·통계상의 제한

1. Win DP 계열은 상대 마지막 행동이 DP Expert 정책일 때 조건부 정확하며, 바뀌는 상대 전략의 full-game 게임 이론적 최적해가 아니다.
2. 후보 선택 과정은 다중 비교·선택 편향이 있으므로 *스크리닝 상위 수치*로 SOTA를 주장하면 안 된다. 유의 수준 조정/사전 등록 없이는 수십 개 비교의 간접적 우월성을 확정하지 않는다.
3. 각 대전의 95% 구간은 좌석 교대 시드별 평균에서 계산한 정규 근사이며, 진정한 독립 PRNG 스트림과 완전 동일 주사위 경로를 혼동하면 안 된다.
4. RL 각 실험은 단일 학습 시드 및 고정된 학습 예산의 탐색적 비교이며 학습 시드 변동성과 구조적 일반화는 아직 검정되지 않았다.
5. 모든 원시 결과와 가중치는 GitHub Actions 아티팩트(기본 90일 보존)로 제공되며, **이 보고서와 생성된 58개 결과 JSON은 git에 보존**한다.
6. 코드·문서·평가 수치가 충돌하면 동일 SHA의 성공된 CI와 원시 아티팩트를 우선한다. 미실행 후보를 실행한 것처럼 표시하지 않는다.
