# Win DP v3.1 — 3턴 계획 + 정확 최종턴 상대 대응

> 2026-11-21 연구용 후보. **승률 향상과 SOTA는 아직 검증 전이다.** 기존 기본 Win DP v2 및 사이트 AI 목록은 변경하지 않는다.

## 구체적인 정책

[실제 코드](../../src/research-v31.ts), [정확한 최종턴 BR](../../src/research-last-turn-br.ts), [3턴 v3](../../src/competitive-v3.ts).

| 내 남은 카테고리 | 조건 | 정책 | 계산의 정확성 |
|---|---|---|---|
| 4~12개 | 모든 상대 | DP Expert 전체 게임 평균점수 정책 | **단독** 평균점수 목적 정확 |
| 정확히 3개 | Win DP v2·v3·DP Expert로 알려진 상대 | 기존 v3 자기 3턴 chance-node Bellman | 내 행동의 조건부 계산 정확, **상대 최종점수 분포는 근사** |
| 정확히 2개 | 모든 상대 | 기존 Win DP v2 (불가 시 DP Expert) | DP Expert 가정 조건부, 전역 최적 아님 |
| 정확히 1개 | 내가 선공(player0), 상대도 1개, 상대가 Win DP v2 또는 v3 | 기존 v2.1의 정확 BR이 양의 이득을 내고 행동을 변경할 때만 교체 | **고정된 상대의 최종턴 v2 정책에 대해서만** 국소 최적 |
| 그 밖의 1개·상대 불명 | 모든 상대 | 기존 Win DP v1 또는 DP Expert 폴백 | 상대 모델의 한계 유지 |

**왜 v3도 정확 BR 상대인가?** 현재 [v3 코드](../../src/competitive-v3.ts)는 남은 1~2개 카테고리에서 그대로 v2로 위임하며, v2는 마지막 1개에서 Win DP v1로 위임한다. 따라서 v3의 마지막 턴은 v2.1이 정확 계산하는 상대 최종턴과 같다.

**중요:** v3의 3턴 Bellman 계획에서 상대가 나중에 행동을 바꾸는 것까지 완전히 최적화하지는 않는다. 이번 v3.1은 **정확 BR을 마지막 1턴에 안전하게 접목**한 단계별 하이브리드다. 3턴 전체를 exact expectiminimax로 바꿨다고 주장할 수 없다.

## 등록된 직접 검증 (결과는 실행 완료 후 기록)

실제 [YachtLab 12칸 엔진](../../src/engine.ts)에서 같은 시드의 선후공 교대 **2경기를 1개의 독립 관측치**로 계산한다. 배포 AI나 DP 테이블 변경 없음.

| 실험 | 시드 쌍 | 총 경기 | 목적 |
|---|---:|---:|---|
| v3.1 vs Win DP v2 | 1,000 | 2,000 | 기존 최강 기준선에 대한 직접 개선 |
| v3 그대로 vs Win DP v2 | 1,000 | 2,000 | **같은 시드**에서 v3.1−v3 증가분을 짝지어 비교 |
| v3.1 vs Win DP v3 | 1,000 | 2,000 | 기존 v3와 직접 대결 |
| v3.1 vs DP Expert | 500 | 1,000 | 상대 일반화 확인 |

이 네 비교와 짝지어진 증분 분석 **총 5개 비교**에 양측 약 99% 신뢰구간을 사용한다. 이는 정규 근사·고정 실험 묶음에 대한 다중비교 보정일 뿐 게임 이론적 최적성 입증은 아니다. 최종 확증을 근거로 하이퍼파라미터를 조정했다면 새 미사용 시드가 필요하다.

첫 실행의 미사용 shard=3. [자동 독립 실험/정기 감시 워크플로](../../.github/workflows/v31-research.yml)는 GitHub Actions에서 main 반영 시 실행하고, 매주 일요일 **21:00 KST**에 신규 shard로 다시 검사한다. 반복 관측에서 한번의 유리한 결과만 선택하면 순차검정/선택 편향이 생기므로 **자동 승격 금지**.

## 더 개선할 여지 및 반증 실험

1. **P0 — 3턴의 상대 모델 오차:** DP Expert 미래 점수 평균+Gaussian은 v2/v3의 실제 선택 정책을 정확히 표현하지 못한다. 이전 조건부 PMF는 어떤 상대에서는 악화됐으므로 **분포 예측의 proper scoring rule 개선**과 **승률 개선**을 분리 검증한다.
2. **P0 — 상대가 반응하는 후반부:** v2.1의 정확 최종턴 response를 2턴 이상 부분게임으로 확장할 때 상대 점수판·차례·행동 적응을 명시한 expectiminimax 또는 동적 게임 상태를 필요로 한다. 일방향 미래점수 PMF를 exact BR로 오해하면 안 된다.
3. **P0 — 실제 변화 빈도/CPU:** v2.1의 행동 변화는 희귀하다. 행동 변경 횟수, 실제 경기 승패 변경, 주사위 기대값, 최대/중앙/p95 latency와 메모리도 함께 기록한다.
4. **P1 — 외부 상대·범용성:** DP Expert, v2, v3뿐 아니라 강한 독립 정책과 동일한 12칸 룰에서 확인한다. 다른 13칸 Yahtzee와 직접 SOTA를 비교하면 안 된다.
5. **P1 — 건전한 후속 실험:** 긍정적 결과가 나오면 정책·코드 커밋 고정 후 새 미사용 shard에서 더 큰 별도 확인, 사전등록 대조군과 순차검정 보정을 수행한다.
