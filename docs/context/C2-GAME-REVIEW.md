# C2 게임 리뷰 엔진

## 선정

1인은 **DP Expert 기대 최종점수**를 사용한다. 2인전은 **v5-R** 단일 Float32 PMF 은행과 기존 분석 API v6을 사용한다. 순차 대전에서 양측 남은 칸이 최대 1개이면 같은 승리점수율 목표를 정확 expectiminimax로 푼다. 동시 진행은 공개 점수판과 고정 상대의 미래 점수 분포를 사용한 모델 추정이다. 은행 초기화에 실패하거나 제한 시간을 넘기면 순차 대전의 정확 종반만 평가한다.

후보 평가는 이미 확보한 종반 연구 결과와 4개 고정 시드의 공개 국면 40개를 대조했다. 라운드 2와 6에서 각 8개, 라운드 10~12에서 24개다. 양측 DP Expert를 쓰고 대표 표본에 굴림 1~3회 국면이 들어가도록 최대 세 번 굴렸다. 학습이나 승률 재실험은 하지 않았다. 이 표본은 인간 플레이 분포나 독립 홀드아웃이 아니다. 정확 기준은 순차 대전 양측 ≤3칸 expectiminimax다.

MAE는 국면마다 공통으로 노출한 합법 행동들의 절대오차를 평균하고 국면별 평균을 다시 평균했다. Exact regret은 정확 최선의 가치에서 각 후보가 고른 행동의 정확 가치를 뺀 값이다. 일치율은 동가치 최선도 포함한다. DP Expert와 v4-D는 통일된 승리점수율 행동가치가 없어 MAE를 산출하지 않았다. 정확 기준을 계산하지 않은 초·중반에서는 v5-R 대비 추천 일치만 비교했으며, 표본에서 여섯 후보가 각 8/8 일치했다. 정확도 보정 효과는 이 구간에서 미확인이다.

종반 현재 점수차 절댓값 ≤15점인 7개 표본에서 regret은 DP Expert 0.1392%p, v4-D 0.0418%p, v5-R 0.0212%p, v6-P 0.0212%p, I2RO1과 I2R1 0이었다. 15점 초과 17개에서는 여섯 모델의 regret이 모두 0이었다. 정확 최선 가치가 30~70%인 7개 표본의 행동가치 MAE는 v5-R 0.680%p, I2RO1 0.502%p, I2R1 0.321%p, v6-P 0.713%p였다.

기존 개발 시드 9101의 정확 턴 전체 regret은 K=4/5에서 v5-R 0.0270/0.0258%p, I2RO1 0.0043/0.0062%p, I2R1 0.0035/0.0050%p였다. 이 지표는 턴의 모든 굴림 가능성을 적분한 값이다. 위 표의 실제 굴림 국면별 regret과 표본 단위가 다르다. I2RO1은 종반 모델 후보로 가치 오차가 더 낮았다. 현재 대전 리뷰는 이미 검증된 확률·첫 굴림 분석 계약과 가벼운 계산을 채택했고, 마지막 순차 턴에서 정확값으로 전환한다. 대국 승률은 선정 기준으로 쓰지 않았다.

## 정확도와 운

가치 기준 `U`는 1인에서 기대 최종점수(점), 2인에서 승리점수율(승 1, 무 0.5, 패 0)이다. 2인의 손실과 운은 승리점수율 차이에 100을 곱한 %p로 제공한다.

- 재굴림은 최종 킵 집합 하나, 점수 기록은 최종 선택한 족보 하나를 평가한다. 실제 행동가치 `Q(a)`와 합법 행동 중 최선 `V = max Q`의 차이 `L = V − Q(a)`가 가치 손실이다. 킵 토글은 제외한다.
- 판단 정확도는 `100 × exp(−max(0, L − t) / s)`다. 기대점수는 `t = 0.1, s = 8`점, 승리점수율은 `t = 0.25, s = 10`%p다. 경기와 라운드에서는 평가된 행동을 동일 가중치로 평균한다. 자동 기록, 분석 기준이 없는 행동, 합법 선택 하나뿐인 행동, 정확 종반에서 모든 선택이 동일한 확정 승·무·패인 행동은 미평가다. 평가 건수와 추정 건수를 함께 제공한다.
- ★·✓·?!·?·??의 손실 경계는 점수 0.1/1/3/8점, 승리점수율 0.25/1.5/4/10%p다. !와 !!는 정확 종반에서 실제 선택이 유일한 최선이고 다음 선택을 각각 10/20%p 이상 앞설 때만 부여한다. 같은 가치를 내는 복수 선택은 ★ 기준을 따른다. 행동 평가 기호는 인간 난이도 보정 점수가 아니다.
- 첫 굴림 운은 관측된 첫 굴림의 최선 가치에서 직전 공개 점수판으로 계산한 다섯 주사위 첫 굴림의 기대값을 뺀다. 같은 점수판과 가치 모델에서 모든 결과를 평균하면 0이다.
- 재굴림 운은 실제 결과에서의 최선 가치에서 선택한 킵 집합의 조건부 기대값 `Q(a)`를 뺀다. 상대가 동시에 기록할 수 있으면 굴림 시작 시의 공개 점수판을 고정한다. 새 상대 점수로 변한 가치는 이 주사위의 운에 들어가지 않는다.
- 각 굴림의 `V(굴림 후) − V(굴림 전)`는 `−L + 운`으로 분해된다. 첫 굴림에는 선택 손실이 없다. 다섯 개 킵은 굴림 횟수만 소비하므로 운은 0이다. 기록 선택 자체에는 주사위 운을 부여하지 않는다. 같은 굴림은 한 번만 집계한다.
- 양측 각각의 첫 굴림과 재굴림의 차이를 부호 그대로 라운드별·경기별로 합산한다. 양수는 행운, 음수는 불운이다. 0~100 재정규화는 하지 않는다. 2인 누적 운과 누적 손실은 각 행동 시점 변화의 합으로, 확률 그 자체가 아니므로 ±100%p를 넘을 수 있다. 교대 시 상대 판단, 양 플레이어 점수 변동, 턴 사이 근사 가치 재추정이 있어 이 합만으로 경기 결과를 역산할 수 없다.
- 당시 공개 점수판·주사위·굴림 수를 사용한다. 실제 다음 눈은 해당 굴림의 운 계산에 한해 사용한다. 과거 기보가 첫 굴림 시점 카드를 증명하지 못하는 동시 진행, 존재하지 않는 행동은 수치를 복원하지 않는다. 기권 전 첫 굴림 이벤트가 확인되면 해당 라운드 굴림 운을 계산할 수 있다. 새 굴림 문맥은 이 탭이 수신한 완전한 이벤트에 의존한다. 계정 리뷰 아카이브는 기존 형식으로 읽는다.

## 기보 및 A5 계약

오프라인 AI는 완료 시 자동 저장하는 IndexedDB 기보 UUID를 로컬 전적 ID로도 사용한다. 계정에 가져온 전적과 연결할 때도 같은 ID를 조회한다. 이전 형식은 기기 내 기존 기보에서 시작 시각, 양측 역할·이름·난이도, 내 최종 전체 카드와 양측 점수가 모두 일치하고 양방향 후보가 유일할 때만 연결한다. 시간 허용 오차는 두지 않는다. 기보 부재, 다른 기기, 삭제 및 모호한 결과는 기록 목록에서 안내한다. 기존 1인·로컬 2인 기보 진입은 유지한다.

`src/review/report.ts`의 `ReviewReport`는 `yachtlab-review-a5-v1` 스키마다. `useReviewAnalysis`가 준비·진행·취소·실패·확정 행동 없음·완료를 구분해 반환한다. 완료 결과에 기보 ID, 모델·알고리즘 버전, 기준과 단위, 플레이어 좌석별·라운드별 평가 건수·정확도·종류별 운·손실을 포함한다. 라운드별 타임라인에는 공개 국면, 실제 선택, 추천 선택, 손실, 정확/추정 여부, 미평가 사유, 기호, 누적 운·손실, 각 굴림의 주사위와 기대·실현 가치가 있다. 확정 행동 없는 차례의 첫 굴림은 라운드의 `unpairedFirstRolls`에 들어간다. 하이라이트는 좌석별 가장 큰 실수·양의 운·음의 운 최대 3건이다. 화면 구현은 [A5 게임 리뷰 화면](./A5-GAME-REVIEW-UI.md). 없는 합계는 `null`이며 측정값 0과 구분한다. 승리점수율 가치(수준)는 0~100%, 가치 차이는 %p다.

기기 기보의 완료 분석은 IndexedDB 최근 16건과 탭 메모리 최근 10건에 둔다. 온라인 결과는 탭 메모리에서 재사용한다. 키는 기보 ID, 모델 버전(DP 자산 포함), 분석 알고리즘 버전, 공개 분석 입력의 직렬화 해시를 포함한다. 취소·실패를 저장하지 않는다. 정확 종반 폴백 결과는 별도 모델 키를 사용한다. 은행 생성·복원은 기존 OPFS·Web Locks 경로를 쓴다.

## 실행 비용과 검증 범위

- 기존 단일 은행 WASM 측정은 데스크톱 Chromium 워커 8.1 s, 모바일 4배 감속 에뮬레이션 메인 스레드 약 33 s, OPFS 복원 약 0.5~1 s, WASM 메모리 146.3 MiB다. C2 Node 40국면 표본에서 초기 생성 약 8.8 s, 단일 은행 후보를 비교한 프로세스 최대 RSS 약 382 MiB다. v6-P 7은행을 포함한 실행의 최대 RSS는 약 3.42 GiB였다(초기 생성 및 나머지 후보 포함). v5-R 분석 어댑터에서 평균 국면당 약 4~8 ms(시작·재굴림 운을 독립 측정한 전체 경기 비용과 구분).
- 모바일 브라우저에서는 계산을 워커에서 수행한다. 저메모리 Android·iOS Safari 실기기의 탭 메모리, 백그라운드 복원, 첫 생성·OPFS 할당량은 미검증이다.
- 초·중반의 정확 행동가치 오차, 동시 진행의 상호 최적 솔버 기준, 인간 판단 난이도 보정은 미검증이다. 3인 이상 리뷰는 별도 연구로 보류한다.
