## 1. 설정·오디오

- **설정 위치 버그의 원인**: Tailwind preflight가 `<dialog>`의 `margin: auto`를 0으로 만들어 모달이 왼쪽 위에 붙었다. 공통 `Sheet`가 `margin: auto`를 되살리고 640 px 이하에서는 아래에서 올라오는 시트가 된다. Esc·바깥 클릭·닫기 버튼, 여는 버튼으로 포커스 복귀(네이티브 `showModal`).
- **설정 모델**(`yachtlab.settings.v1`, 기존 키 유지): `muted`(이제 전체 음소거), `sfx`, `volume`(효과음 70%), `bgm`, `bgmVolume`(30%), `fxQuality`(자동·높음·낮음), `shortcuts`, `reducedEffects`, `diceQuality`, `opponentFx`. 예전 저장값은 그대로 읽힌다. 단, 예전에 "효과음 끄기"(`muted: true`)였던 사용자는 이제 전체 음소거로 해석되어 새 BGM도 꺼진 상태로 시작한다(의도: 소리를 끈 사용자에게 갑자기 음악을 틀지 않음).
- **BGM**: 외부 음원 없이 직접 작곡·합성(라이선스: [docs/audio/LICENSES.md](../audio/LICENSES.md)). 홈 84 bpm 메이저7 마림바풍, 대기실 96 bpm, 경기 66 bpm(박자 없음·고음역 차단 3.4 kHz로 사고 방해 최소화), 상점 104 bpm, 리뷰 70 bpm, 승리 112 bpm 4마디, 패배 72 bpm. 꼬리를 앞부분에 겹쳐 더하는 방식으로 이음매 없는 반복. 장면 우선순위: 페이지(0) < 진행 중 온라인 경기(1) < 리뷰·기보(2) < 결과 창(3). 같은 장면 재요청은 무시, 전환 중 늦게 도착한 렌더는 버림(세대 번호) → 중복 재생 없음(테스트: 전환 2.2 s 뒤 재생 소스 1개).
- 자동 재생 정책: 첫 pointerdown/keydown 전에는 아무것도 재생하지 않는다(테스트로 확인). 탭 숨김·`pagehide`에서 페이드아웃 후 정지, 다시 보이면 재개.

## 2. 키보드 단축키

| 화면 | 키 |

| 게임 | Space 굴리기 · 1~5 주사위 고정/해제(스크린리더 번호와 같고 키보드 사용 중 주사위에 번호 표시) · A 모두 고정 · D 모두 해제 · ↑↓ 족보 선택 · Enter 기록 · Esc 선택 취소 |
| 리뷰·기보 | ←→ 이전·다음 · Space 자동 재생 · Home/End |

가드: 입력·textarea·select·contenteditable·열린 목록에서는 무시, Ctrl/Alt/Meta 조합 무시, 행동 키의 자동 반복 무시, 상대 차례·주사위 애니메이션 중에는 버튼과 같은 조건(`can`)으로 막힘, 족보 선택은 Enter가 있어야 기록(선택은 새 굴림·차례 변경 시 초기화), 설정 등 다른 모달이 열리면 게임 키 비활성. 한글 자판(ㅁ·ㅇ·ㅡ·ㅠ·ㄹ)도 같은 키로 인식. 휴대폰(거친 포인터만)에서는 설정 항목을 숨긴다. 단축키는 마우스·터치와 같은 콜백을 호출하므로 새 상태 변경 경로가 없다.

## 3. 효과 엔진

- `FxCanvas`(풀링된 입자 160개 상한, 링·균열·번개·광선·광선 궤적): 주사위(3D 테이블 위 오버레이), 보드(트레이 안, 주사위 캔버스 아래), 이모티콘(재생 중에만 생성 후 해제)이 같은 엔진을 쓴다. 효과 예산 `fxBudget()`: 동작 줄이기 0, 낮음 0.4, 모션 간단히 0.4~0.6, 좁은 화면 0.7, 그 외 1.
- **네온 주사위 본체 보존**: 기존 Lv.2/3은 재질 전체에 발광색을 더해 검은 본체가 분홍·초록으로 물들었다. 이제 발광은 눈과 네온 테두리만 그린 마스크(`paintGlowMap` → `emissiveMap`)로 제한된다. 모든 강화 주사위의 면·눈·테두리 색은 Lv.1과 같다(테스트).
- 게임 이벤트 버스 `fx-bus`(굴림·충돌·착지·고정·해제·라지 스트레이트·요트·승리): 표현 계층 전용, 엔진·AI·서버는 읽지 않는다.
- 2.5D 폴백·WebGL 미지원: 주사위 입자는 3D에서만, 보드 Lv.2/3은 2.5D 줄(`.dice-row`)에도 붙는다. 동작 줄이기에서는 모두 꺼진다.

- 등급·가격·뽑기 종류 필터: 네이티브 select → 공통 `Select`(listbox, ↑↓/Home/End/Enter/Esc/글자 이동).
