## 0. 사전 등록 (개발 결과를 보기 전, 확증 대국 전에 커밋)

- **개발·선택 시드:** family 9011~9049 (9011 = 후보 비교, 9099 = 스모크·시간 측정). 이 시드의 수치는 "개발 결과"이며 홀드아웃이 아니다. v5의 9001~9004, 9501, 9502와 겹치지 않는다.
- **확증 시드:** family **9511**(주 확증), **9512**(독립 재현). 이 시드는 후보 선택·튜닝에 쓰지 않는다. 시드 = `hash(0x5eed0000 + family·1000003 + shard·20011 + i)`, `createGame(seed, true)`, 시드마다 좌석 교대 2경기(bench.ts 그대로).
- **후보:** v6-P(정책군 롤아웃), v6-P3(λ 3개), v6-P2(깊이 2 개방루프 BR), v6-A3/A4/A6(남은 칸 ≤K 전 구간 정확 BR), v6-PB3(v6-P + 양측 ≤3 정확 상호작용), v6-L/v6-Lm(상대 정책군 최대최소/혼합). 기준: v5-R.
- **Apex 선택 규칙:** 개발 9011에서 상대 Win DP v2, 각 4,000쌍(8,000경기). 같은 시드의 v5-R 대비 **쌍별 대비(paired contrast)**가 가장 큰 후보 중 평균 판단 ≤ 25 ms. 최고값과 0.15%p 이내의 더 단순·빠른 후보가 있으면 그것을 고른다. 직접 대결 v6-P vs v5-R(4,000쌍)도 참고한다. 어떤 v6 후보도 v5-R 대비 개발 대비가 양수가 아니면 확증은 v6-P로 진행하되 "개선 없음" 가설 검정으로 보고한다.
- **주 가설(확증 9511):** H1 Apex vs v5-R 직접 대결 승리 점수율 > 50% (100,000경기). H2 같은 시드에서 (Apex − v5-R) 대비 vs Win DP v2 > 0 (각 100,000경기). H3 Apex vs DP Expert > 50% (40,000경기). 시드쌍 단위 99% 정규 근사 CI, H1~H3 Holm 보정 p 병기.
- **보조:** Apex vs Win DP v3 40,000 · vs v5-B3 40,000. 재현(9512): Apex vs v5-R 40,000 · Apex vs v2 40,000 · v5-R vs v2 40,000.
