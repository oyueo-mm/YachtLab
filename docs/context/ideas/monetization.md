# 수익화 후보 (ideas/monetization)

> 미승인. 현재 현금 결제·광고·구독은 없다. 결제 도입 전 법률·세무·확률형 아이템 표시 의무·미성년자 보호 검토가 필요하다(ROADMAP 장기 로드맵). 재화를 거는 대전은 사행성 위험으로 법적 검토 전 금지.

| 후보 | 순서(검토안) | 메모 |
|---|---|---|
| 광고(배너·보상형) | 1 (광고 우선) | 경기 중 노출 금지, 동의·개인정보 고지 선행 |
| 광고 제거 | 2 | 일회성 구매 |
| 멤버십 | 3 | 꾸미기·편의 혜택, 경기 승패 영향 금지 |
| 시즌 패스 | 3 | 퀘스트 구조 재사용 |
| 꾸미기 상품·재화 직접 판매 | 3 | 컬렉션 표를 패키지로 |
| 고급 분석 혜택 | 4 | 리뷰 워커 재사용, 기본 리뷰는 무료 유지 여부 결정 필요 |
| 후원 | 언제든 | 혜택 없는 후원 |
