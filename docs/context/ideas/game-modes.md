# 보류된 게임 모드 (ideas/game-modes)

> 미승인. 모든 연구·대전의 기준 규칙은 12칸 Nintendo-style Yacht Dice이며, 다른 규칙은 **별도 규칙 id**로만 추가한다(기존 기록·AI 테이블 보존).

| 후보 | 메모 | 선행 조건 |
|---|---|---|
| 13룰 | 13칸 변형. 미국식 Yahtzee 수치와 혼동하지 않도록 이름·규칙 id 분리 | `src/rulesets.ts` 확장, 기록 `RULES_ID` 분리, AI는 12칸 전용임을 표시 |
| 15룰 | 확장 족보 | 위와 동일 |
| 고전 요트 | 전통 규칙 | 규칙 출처 확인 |
| 아이템전 | 경기 중 아이템 | 공정성·서버 검증, 경제 영향 |
| 팀전 | 2:2 등 | 방 구조·결과 화면(다인전 순위표 재사용) |
| 속도전 | 짧은 차례 제한 | 서버 차례 시간(`TURN_LIMITS`) 재사용 |
| 커스텀 규칙 | 방장 설정 | 기록·랭크 제외 표기 |
| 랭크 대전 | 레이팅 | 부계정 대책, 시즌 구조 |
