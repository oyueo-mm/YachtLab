# 온라인 요트다이스 제품 업데이트

## 브랜드와 탐색

서비스 표기는 온라인 요트다이스(Online Yacht)다. 돛의 세 점은 주사위의 눈을, 아래 실루엣은 배와 물 위 항적을 나타낸다. 기존 흰색 화면에서 어두운 바탕과 붉은 돛으로 구분한다. 로고는 SVG로 제공하고 브라우저용 파비콘, PWA 이미지와 공유용 1200×630 JPEG를 포함한다.

상단은 로고, 상점, 인벤토리, 회원 재화, 설정, 프로필을 제공한다. 작은 화면은 메뉴를 아이콘으로 표시하고 큰 잔액을 축약한다. 메뉴는 온라인 대전·오프라인 대전·친구·내 기록·퀘스트다. 설정의 효과음 스위치와 음량 조절기를 쓰며 연습은 오프라인 대전에서 연다. 최초 방문 기록, IndexedDB, 계정 키, PWA ID, 시작 URL, 범위, 서비스 워커 캐시 접두사 및 업데이트 절차는 기존 값을 사용한다. 진행 중 경기를 벗어날 때 기존 확인을 거친다.

기본 매우 어려움은 v4-D이며 v5-R은 시험 경로다. 연구 코드는 별도 연구 브랜치에서 진행한다.

## 검색 운영

- 홈과 [규칙과 전략](https://oyueo-mm.github.io/YachtLab/guide/) 등 검색용 문서는 정적 HTML, 절대 canonical, 공유 메타 및 내부 링크를 제공한다. 홈은 빈 브라우저에서도 바로 렌더링된다. 같은 문서를 사용하는 게임의 해시 경로 전환은 홈의 제목과 설명을 수정하지 않는다. 홈 제목·설명과 첫 화면에 요트다이스, 야추 다이스, PC·모바일, 친구 멀티플레이와 AI를 반영한다. [사이트맵](https://oyueo-mm.github.io/YachtLab/sitemap.xml)
- GitHub Pages 프로젝트는 `/YachtLab/`만 배포한다. 검색 로봇 정책의 위치는 호스트 루트의 `/robots.txt`이고 확인 시 404였다. 프로젝트 경로에는 효력이 없는 robots.txt를 만들지 않는다. 존재하지 않는 경로의 404 HTML에는 noindex를 넣었다. [robots.txt 위치](https://developers.google.com/crawling/docs/robots-txt/create-robots-txt)
- Google Search Console의 속성은 `https://oyueo-mm.github.io/YachtLab/` URL 접두사다. 홈의 기존 HTML 인증 태그를 보존한다. 사이트맵 제출은 속성의 접두사 뒤에 `sitemap.xml`을 사용한다. 2026-11-26 진단에서 프로젝트 사이트맵은 HTTPS 200과 `application/xml`을 반환했고, 일반 브라우저·Googlebot·Googlebot-Image 사용자 에이전트 요청의 XML이 일치했다. 등록된 8개 URL 모두 HTTPS 200과 자체 canonical을 반환했다. 호스트 루트의 `/sitemap.xml`은 404이며 프로젝트 사이트맵 URL과 구분한다. Search Console의 특정 가져오기 실패 시각과 내부 오류는 공개 HTTP 응답에서 확인할 수 없다. [사이트맵 보고서](https://support.google.com/webmasters/answer/7451001) · [소유 확인](https://support.google.com/webmasters/answer/9008080)
- 홈의 `WebSite` 이름과 공유 사이트 이름은 Online Yacht이며 같은 canonical을 사용한다. 파비콘은 기존 48×48과 브랜드 192×192 PNG를 노출한다. Google 검색의 별도 사이트 이름·파비콘은 도메인이나 서브도메인 루트에 적용된다. 현재 `/YachtLab/`은 하위 경로이고 호스트 루트는 GitHub Pages 404를 반환해, 프로젝트 메타데이터만으로 별도 사이트 이름·파비콘 표시를 지정할 수 없다. 공개 SERP 제목과 설명은 Google이 다시 크롤링한 뒤 생성한다. [사이트 이름](https://developers.google.com/search/docs/appearance/site-names) · [파비콘](https://developers.google.com/search/docs/appearance/favicon-in-search)
- Bing Webmaster Tools는 확인된 Google 속성을 가져오는 절차를 사용할 수 있다. 가져온 사이트맵을 확인한다. [Bing 가져오기](https://www.bing.com/webmasters/help/add-and-verify-site-12184f8b)
- 네이버는 사이트 등록 및 소유 확인에서 호스트를 요구할 수 있다. 프로젝트 경로를 거부하거나 호스트 루트 인증만 제공하면 현재 Pages 프로젝트에서 소유 확인을 마칠 수 없다. 계정이 프로젝트 등록을 허용하면 제공된 메타 태그 방식으로 확인하고 사이트맵을 제출한다. [네이버 등록·소유 확인](https://searchadvisor.naver.com/guide/faq-start-register)
- HTTP 응답과 새 브라우저에서 자바스크립트 실행 전후에 같은 홈 제목·설명·본문·링크가 제공되는지 확인한다. 실제 색인, 검색 노출, 클릭수와 사이트맵 가져오기 상태는 각 도구의 속성 리포트에서 확인한다.

## 점수와 첫 굴림 확률

공정한 5개 주사위의 순서 있는 `6^5 = 7,776`개 결과를 `src/engine.ts`의 `score`로 검산했다. 포커 156, 풀 하우스 300, 스몰 스트레이트 1,200, 라지 스트레이트 240, 요트 6이다. 검색용 도움말은 각 족보를 독립적으로 세며 확률이 겹친다는 점을 설명한다.

## 경기와 상품 화면

상점과 인벤토리는 상품 관리 탭으로 연결한다. 기존 `#shop`·`#inventory`를 탭 주소로 쓰고, 화면 안에서 탭을 바꿀 때 장착 초안을 보관한다. 마우스 세로 휠은 넘길 공간이 있는 상품 레일 안에서만 가로로 이동한다. 각 상품군의 전체 보기와 효과 미리보기 진입점을 제공한다. 퀘스트는 일일·주간·업적 탭을 제공하며 기존 `#achievements`는 업적 탭을 연다.

프로필에는 닉네임·장착 외형·간단 전적·계정 조작을 두고, 상세 통계·계정 경기 리뷰는 내 기록에서 연다. 리뷰는 주요 선택과 추천을 먼저 보여 주며 상세 분석에서 전체 타임라인, 점수판, 추정치와 시뮬레이션을 열 수 있다. 1:1 대전·관전 말풍선은 발신자 프로필 근처에 잠깐 표시한다. 다인전에는 보낸 사람의 이름과 프로필을 붙인 메시지를 두고 내 프로필 근처에서 보낼 수 있다. 채팅 패널에서 최근 수신 기록을 볼 수 있다. 기록은 브라우저 메모리에만 둔다.

## 경제와 시즌

[등급·가격·뽑기·퀘스트 교체 설계와 검증](../economy/ONLINE-YACHT-DRAW.md)에 서버 계약, 확률, 시뮬레이션, 롤백 절차를 기록했다. 3D 강화는 렌더러가 주사위의 표시 위치에 그리는 연출이다. Lv.2는 굴림 자취, Lv.3은 충돌과 착지의 입자를 더하며 물리와 결과를 계산하는 데이터는 그대로 전달한다.

배포 단계는 PR CI, 기존 Worker의 무료 플랜 및 로그인·원장 확인, Worker 운영 배포, Pages 배포, 공개 빌드 확인 순서다. 기존 Google 계정과 실제 Android·iOS 설치 여부는 브라우저 에뮬레이션과 별도로 기록한다.

## 출시 전 확인

- 변경 브랜치의 타입 검사와 프로덕션 빌드, 기존 Worker 주소를 넣은 Pages용 빌드를 실행했다. 브라우저 첫 엔트리의 압축 크기는 로컬 동일 설정에서 약 205KB에서 200KB로 줄었다. 실제 검색 노출과 사용자 Core Web Vitals 측정은 운영 리포트에서 확인한다.
- 로컬 SQLite·Worker 포함 경제/소셜 테스트 44개에서 기존 데이터, 정산 중단, 응답 유실 재요청, 기간 경계, 원장 합계와 계정 권한을 확인했다. 전체 로컬 Vitest는 440개가 통과했다. 서버 AI 시간 기준 8ms의 초과는 기준 main에서도 재현됐다.
- 데스크톱 및 Pixel 7 에뮬레이션으로 상품·장착·뽑기·프로필·리뷰·SEO 회귀 42개를 확인했다. iPhone 13 WebKit 에뮬레이션으로 온보딩·연습·도움말을 확인했다. Chromium에서 이전 앱 캐시가 대기 중 남고, 새 워커 활성화 후 관련 앱 캐시만 교체되며 연습과 도움말이 오프라인에서 열리는 것을 확인했다.
- 기존 공개 빌드 `b88c738-mwwfzia4`에서 데스크톱과 Pixel 7 게스트가 친구 초대로 24차례를 완주하고 새로고침 후 같은 자리로 복귀해 게임 리뷰를 열 수 있었다.
- 장기 구독의 브랜드명은 Online Yacht Pass다. 이 출시안은 플레이 재화와 꾸미기 상품을 다룬다.
