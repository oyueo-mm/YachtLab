# A5 게임 리뷰 화면 (2026-11-27)

C2 리뷰 엔진과 `yachtlab-review-a5-v1` 계약을 그대로 쓰는 화면 개편이다. 분석 모델·알고리즘 버전(`yachtlab-review-c2.1`)·캐시 키·워커는 바꾸지 않았다. 공용 게임 엔진, 경제, Worker, 실제 플레이 AI, 경기 종료 화면도 변경하지 않았다.

## 화면 구성

1. **요약**(`최종 결과`): 좌석별 카드에 최종 점수, 판단 정확도, 누적 주사위 운(첫 굴림·재굴림 분리), 누적 판단 손실, 평가 기호 분포. 정확도는 평가 건수와 함께 `추정`(모델 추정 포함) / `정확`(2인 정확 종반만) / `DP`(1인) 표식을 단다. 평가 0건·운 없음은 `미평가`이며 0과 구분한다. 1인은 한 카드와 점 단위, 2인은 두 카드와 %p 단위.
2. **분석 상태**: 준비 중, 진행(n/전체·%), 취소(중단 위치), 실패(메시지·중단 위치), 완료와 **저장된 분석**(탭 메모리·기기 캐시 적중)을 구분한다. 폴백(정확 종반만)은 별도 안내. 분석 전·실패·취소 상태에서도 기보 탐색, 점수판, 타임라인, 점수 그래프는 쓸 수 있다.
3. **선택한 행동**: 실제 선택과 AI 추천을 같은 주사위로 나란히 표시(킵 주사위 강조, 재굴림 주사위 흐리게, 기록 족보와 점수). 판단(손실·정확도·정확/추정)과 주사위 운(굴림별 기대→실현 가치, 차이)을 별도 상자로 분리. 당시 점수판에 실제 기록 족보(채움)와 추천 족보(점선)를 표시. 대안 행동·다시 도전은 유지. 모바일에서는 탐색 버튼이 하단에 고정된다.
4. **경기 전체 분석**: 그래프 탭 `승리점수율`(1인: `기대 최종점수`), `점수`(라운드별 누적 점수, 양측), `손실·운`(좌석별 라운드 막대: 운 ±, 손실 아래). 그래프 점·막대를 누르면 해당 행동으로 이동하고 현재 행동 위치를 점선 커서로 표시한다. 아래 타임라인은 라운드별로 묶이고, 필터 `전체·좋은 판단·실수·행운·불운`과 플레이어 선택(2인)을 제공한다. 현재 행동은 타임라인 내부 스크롤만 이동한다.
5. **주요 장면**: 좌석별 주요 실수·좋은 판단·행운·불운 최대 3건. 실수·행운·불운은 리포트의 `highlights`를 그대로 쓴다.

## 데이터 경계

- 새로 계산한 값은 표시용 변환뿐이다: 승리점수율 그래프는 한 좌석 시점으로 그리며 상대 행동의 값은 `100 − 값`으로 바꾼다(1:1에서 양측 승리점수율의 합은 1). 점수 그래프는 공개 점수판의 기록 후 합계다.
- **좋은 판단** 하이라이트: 등급 !!·!·★인 평가 행동 중, 같은 행동가치 목록에서 다른 주사위 구성(또는 다른 족보)의 최고값보다 실제 선택이 앞선 차이(`차선 대비`)가 양수인 것. 차이 내림차순(등급 우선). 엔진이 준 옵션 가치만 쓴다.
- 필터 `좋은 판단`은 !!·!·★·✓, `실수`는 ?!·?·??(기존 등급 경계), `행운`/`불운`은 해당 행동의 굴림 중 양/음의 운이 있는 경우(임계값 없음).
- 운은 0~100점으로 바꾸지 않는다. 누적 손실·운은 C2 문서의 정의대로 ±100%p를 넘을 수 있다.

## 색 역할

플레이어 식별은 기존 D-060 좌석색(나 빨강, 상대 파랑)만 쓰며 점·테두리·그래프 선에 한정한다. 판단 등급은 청록(!!·!)→초록(★)→올리브(✓)→황갈(?!)→주황(?)→보라(??) 칩으로, 빨강·파랑을 쓰지 않는다. 운은 금색(+)/회청(−), 손실은 먹색이다. 실제·추천 비교는 색 대신 채움/점선과 문자 라벨로 구분한다.

## 동명·좌석

2인 카드에 항상 `선공`/`후공`(동시 진행 기보는 `1번/2번 좌석`)과 `나` 표식을 둔다. 두 이름이 같으면 표시 이름 자체를 `이름 (선공)`처럼 바꿔 그래프 범례·타임라인·필터에서도 구분한다.
