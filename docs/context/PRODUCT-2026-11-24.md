## 이번 작업 상태 구분

### 완료(자동 테스트·로컬 Workers 검증)
- 첫 굴림 GPU 준비, 빠른 재굴림 물리 준비 앞당김 — 에뮬레이션 측정 [PHASE-A](../ui/PHASE-A-2026-11.md)
- 휴대폰 점수 칩·한 화면 행동 버튼·추천 점수 오조작 방지, 고정 순서 Hibernation 보존
- 재대결(같은 방·새 matchId·선공 교대), 프리셋 채팅 10·이모티콘 8, 관전(동의·키·5명·철회)
- 닉네임 정책, 게스트 기기 기록·프로필·통계, 서버 검증 기록 아웃박스, 계정 저장소·세션·게스트 이전·계정 삭제 — [설계](../online/SOCIAL-AND-ACCOUNTS.md)

### 부분 완료 / 실제 검증 안 됨
- **실기기**(iPhone·Galaxy) 성능·발열·화질·효과음 — 에뮬레이션만. 체크리스트: [PHASE-A §8](../ui/PHASE-A-2026-11.md)
- 효과음 v3 — 사람이 들어 보고 기본값 결정 필요
- **실제 Google 로그인** — 가짜 OIDC 제공자 테스트만. 시크릿 설정 후 사람 확인 필요
- 회원끼리·회원 vs 게스트 **실서버** 대전 기록 저장 — 로그인 활성화 전에는 실서버에서 확인 불가(로컬·단위 테스트로만 확인)
- 첫 굴림 탭→첫 프레임(CPU 4배 약 65~72 ms)은 개선되지 않음(React 첫 마운트) — 후속 후보

### 외부 설정 필요 (사용자)
- Google OAuth 클라이언트 + Cloudflare Worker 시크릿 3개 — 정확한 절차: [SOCIAL-AND-ACCOUNTS §6](../online/SOCIAL-AND-ACCOUNTS.md#6-사용자가-직접-해야-하는-설정-google-로그인-켜기)
