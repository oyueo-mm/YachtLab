# YachtLab 후속 연구: v3.3 Bayesian 상대 적응 · v3.4 적응형 계산 · v4 A~E 절제

> 상태: **연구용 코드와 GitHub Actions**. 실제 성능은 Actions 결과가 성공적으로 완료되고 원시 자료 검증을 마쳐야 판단한다. 기존 Win DP v2 기본값/웹 UI를 변경하지 않는다.

## 연구 가설 1 — v3.3의 상대 인식

- [상대 행동 Bayesian 필터](../../src/research-opponent-belief.ts): 가설 정책 `Win DP v2`, `Win DP v3`, `DP Expert`, `Aggressive`, `Conservative`, `Random`.
- 관찰 가능한 주사위·점수판·남은 굴림에 대해 각 정책의 예측 행동과 실제 상대 행동의 확률을 계산하고, **완만한 오차 확률 12%**를 둔 우도로 베이즈 업데이트. Random 가설은 현재 합법적인 동등 재굴림 행동을 포함해 균일 우도를 부여.
- [가중 혼합 경쟁 정책](../../src/research-v33-belief.ts): 상대가 마지막 3칸 남았을 때 고정된 한 모델을 선택하지 않고 posterior로 Gaussian·CART 조건부 점수분포·DP Expert 정확 PMF의 **payoff 함수를 가중 평균**한다.
- 실제 사람에 대한 일반화 성능을 추측하지 않는다. 데이터 수집된 실제 인간 플레이나 비정상적 정책 교체가 없기 때문에 **동일인 단일 고정 정책** 가정은 한계다.
- [상대별 데이터 생성](../../scripts/train-v33-belief.mjs): 여섯 정책마다 800 train/300 validation/300 untouched confirm, scorecard mask·상단 보너스·현재 점수 특징 이용. 검증 CRPS 개선이 없으면 기존 원형 가우시안으로 복귀.
- [시험](../../scripts/bench-upgrades.mjs): v3 기존 / v3.3 알려진 상대 / v3.3 Bayesian × 6종 상대 × 각 200시드 쌍 2좌석 = **7,200경기 탐색적 파일럿**. 추후 긍정적 증거를 확인한 후보에 대해 200,000경기 독립 검증.
- 주의: Random 상대는 **엔진 주사위 RNG와 분리된 비공개 시드**에서 합법 행동을 균일 추첨한다. Bayesian 관찰자는 상대의 랜덤 시드·미래 행동을 읽지 않는다. 사람의 행동과는 동일시할 수 없음.

## 연구 가설 2 — v3.4 탐색 예산·범위

- 기존 `v3.4`는 2개 행동 × 2번 MC, 마지막 2칸. 이전 200,000경기 v3 대비 **−0.0995%p**, 99% CI **−0.1515~−0.0475%p**.
- [v3.4 핵심](../../src/research-v34.ts): 최대 256 롤아웃 지원, 공통 가상 난수, 처음부터 끝까지 상대 실제 정책 시뮬레이션. 개인 평균 승리 추정값이 신뢰롭지 않으면 DP anchor 동작 보존. 실행 상한은 **소프트 시간제약**: 한 배치가 길면 지정 시간을 넘길 수 있음.
- [예산 분배](../../src/research-v34-adaptive.ts):

| 모드 | 후보 행동 | 행동당 최대 롤아웃 | 타깃 | soft cap |
|---|---:|---:|---|---:|
| legacy | 2 | 2 | 남은 2칸 | 40ms |
| A | 2 | 16 | 남은 2칸 | 60ms |
| B | 4 | 64 | 남은 2칸 | 120ms |
| C | 최대 8 | 256 | 남은 2~3칸 | 240ms |
| D | 최대 4 | 64, 최종 1칸의 **eligible exact BR 우선** | 1~2칸 | 120ms |
| adaptive | 점수차·DP Q-gap을 고려해 A/B/C 선택 | 가변 | 마지막 2~3칸 + 조건부 최종 1칸 BR | 상황별 |

- **D가 마지막 2칸의 전체 2인 게임을 정확히 푼다는 뜻이 아니다.** 기존 정확 BR 증명은 제한된 **마지막 1칸 1대1** 상태에만 적용되며, 나머지는 표본 탐색.
- 99% 통계적 추론에 쓰이는 CI와 구분: 탐색 내부 조기 종료는 **검증되지 않은 휴리스틱**이다.
- [파일럿](../../scripts/bench-upgrades.mjs): 6개 예산 모드 × 80시드 쌍 2좌석 = **960경기**. 주요 지표는 평균 의사결정시간, 결과 변동 수, 미사용 시드의 승률. 256롤아웃이 전체 국면에 항상 실행되는 것이 아니므로 후반 도달 빈도를 함께 기록하고 추후 50/95퍼센타일 지연 분석 필요.
- 계산량을 늘리는 것만으로 승률 증가가 보장되지 않는다. 이 탐색은 완전 게임 트리 Expectiminimax나 Nash solver가 아니다.

## 연구 가설 3 — v4 정책 불일치와 학습 목표

기존 원본 v4 체크포인트를 GitHub Actions run `44922054901`의 `v4-actor-frozen-selected`에서 바이트 그대로 읽어 [연구 아카이브](../../training/research-archive/v4-original-seed0.json)로 보존했다. **A/B는 정확히 같은 기존 학습 정책**이며 마지막 2칸의 v3.3/v3.4만 차이 난다. 원래 validation은 v3.3을 사용했고 최종 실전은 v3.4를 사용한 불일치 문제를 직접 통제한다.

| 구분 | 학습 actor | 마지막 3칸 | 마지막 2칸 | 실험 가설 |
|---|---|---|---|---|
| A | 기존 v4 고정 가중치 | v3.3 | v3.3 | v3.4를 제거하면 결과가 달라지는가 |
| B | **같은** 기존 v4 가중치 | v3.3 | v3.4 | 기존 최종 정책의 재현 |
| C | **새로 훈련**, DP imitation만 | v3.3 | v3.3 | 교사만의 효과 |
| D | **새로 훈련**, REINFORCE만 | v3.3 | v3.3 | 승패 학습만의 효과 |
| E | **새로 훈련**, imitation + REINFORCE | v3.3 | v3.3 | 두 목적의 결합 효과 |

C/D/E는 **훈련 시드별 3,000경기 × 3 초기화 × 3목표=27,000경기**, 모델 선택용 검증은 **상대별 2,000개 seed-pair / 4,000경기**로 확대. v2 상대 검증으로만 시드 선택하고, DP Expert 상대 검증도 따로 기록한다. C/D/E의 훈련 코드는 학습 구성 요소만 다르며 후반의 정책이 서로 동일하다.

> A/B와 C/D/E는 학습된 가중치가 서로 다르다. A-B 차이는 기존 체크포인트에서 **후반 구성만의 인과적 비교**다. C-D-E는 같은 설정의 **학습 목적별 절제**다. A/C를 단순한 단일 변경 실험으로 취급하지 않는다.

- 후속 **A/B/C/D/E 각각 200,000경기, 총 1,000,000경기**, 동일 100,000개 시드쌍과 양좌석. 신규 시드 범위 `2201…2220` 20 shard × 5,000 seed-pairs × 2 seats.
- 기초 99% CI는 시드쌍 단위이고, A-B, A-C, A-D, A-E 차이는 같은 시드의 paired contrast로 평가한다. 복수 후보·복수 결과를 통한 성능 주장에는 다중 비교 보정과 새 holdout 검증이 필요하다.
