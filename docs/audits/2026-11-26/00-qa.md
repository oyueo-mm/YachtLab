## 테스트 실행 한계

전체 Vitest 443/447, 파일 50/54. 시간 비용 표본(서버 AI p99 26.33ms, 호스트 복원 중앙값 42.07ms)과 별도의 두 제한 회귀가 초기 실행에서 실패했다. 시간 검사 두 건을 좁혀 재실행했을 때 호스트 복원은 통과했고 서버 AI는 평균 3.58ms가 테스트 기준 3ms를 넘었다. 경합과 에뮬레이션 비용을 운영 수치로 환산하지 않는다. PWA는 최초 미리보기 설정의 오리진과 returning-visitor fixture가 불일치해 설치 안내 케이스 1개가 실패했다. 검증 설정에서 오리진을 맞춘 재실행은 4/4 통과했다. 독립 스크립트는 결과 리뷰를 실제 모달로 검사하고 정상 점수판 버튼을 사용한 최종 실행에서 게스트 흐름 2/2 통과했다.
