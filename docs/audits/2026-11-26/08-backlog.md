# 출시 게이트와 후속 개발

현재 판정은 **격리 리허설 진행 가능, 공개 확대 보류**다. 아래 우선순위는 제품 코드 변경 요청을 대신하지 않는다.

| 순위 | 작업 | 병행 담당 | 완료 조건 |
|---|---|---|---|
| P0 | 현재 검증에서 확인된 장애 없음 | — | 계정·원장 사고나 서비스 전체 불능 관측 시 공개 행사 중지, 운영자가 비공개 대응 |
| P1 | 실제 Google 승인·콜백, 계정 프로필·로그아웃·기록 연동 | 제품 운영자 | 승인된 두 테스트 계정과 Android/iOS 각 1대에서 닉네임·기록·기기별 철회가 일치 |
| P1 | 20석 브라우저·실기기 리허설 | 온라인 담당 | 로컬 20개 WebSocket 순차·동시 완주를 기준으로, 행사 운영에 쓸 20석 모드·재접속·결과·재대결을 브라우저에서 확인 |
| P1 | 무료 한도와 서버 AI CPU·요청 제한 회귀 판정 | 온라인 운영자 | 끊김·재시도를 포함한 리허설에서 p95·행 쓰기·GB-s 확인, 같은 계정 사용량에 30% 이상 여유, 방 사용량 알림 준비. 기존 시간 의존 회귀 검증 |
| P1 | 계정 정산·시즌 운영 안전 | 경제 운영자 | 정상 재시도 및 데이터 복구 일치, 시즌 자정 기준과 미리보기 검증, 승패와 기능 플래그·롤백 순서 리허설 |
| P2 | 1366×768 및 가로 863×360, 오프라인 점수표 | Claude 변경 검증 + QA | 데스크톱 12행과 고정 버튼. 가로 화면에서 점수 기록과 보너스 탐색을 테스트하고 이중 스크롤 여부 기록 |
| P2 | 튜토리얼 3D 첫 화면 비용, ARIA | 프런트 | 같은 조건 3회 중간값으로 LCP·TBT·stage 바이트 비교, 역할/이름 진단과 실제 스크린리더 확인 |
| P2 | SEO 출시 검증 | Claude SEO + 운영자 | 정적 의도 페이지 200·self-canonical·사이트맵, JS 없는 진입, 수집/색인 콘솔에서 검증. 기존 작업 중복 방지 |
| P2 | 20명 파일럿과 친구 초대 운영 | 커뮤니티 담당 | 일정별 입장·매칭·첫 완료·복기 전환 집계. 입장 목표 70% 미달이면 재공지 전에 원인 파악 |
| P2 | 경제 첫 30일 가시화 | 경제 담당 | 첫 구매 일수·퀘스트 완료율·순수 공급/소비·보석 잔액 분포, 시즌 접근성 및 신규 격차를 익명 집계 |
| P3 | 연구 샤드 매니페스트·프로파일 | 연구 담당 | 코드/모델/시드 해시, 로컬 일시 중지·재개 parity, Worker/Node/C++·WASM 비용 지표 |
| P3 | 동일 주사위 한 수 복기 공유와 한국어 규칙 링크 | 제품/콘텐츠 담당 | 개인정보 제외한 예시로 사용자가 한 수를 다시 시도할 수 있다. 실제 규칙·확률 표에만 외부 링크 |
