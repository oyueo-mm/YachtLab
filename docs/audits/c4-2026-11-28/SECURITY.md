> **표기:** 심각도 = 치명 / 높음 / 중간 / 낮음 / 정보. 상태 = **확인됨**(코드·격리 재현으로 입증) / **잠재**(조건부, 외부 확인 필요). 우선순위 = P0(즉시) ~ P3, 게이트 = 유료화 전 필수.

## 2. 확인된 양호 통제 (유지)

| 영역 | 통제 |
|---|---|
| OAuth/OIDC | 인가 코드 + PKCE S256, state·nonce, `scope=openid`만(이메일·이름·사진 미수집), 서명 알고리즘 고정, 발급자·대상·만료 검증, 열린 리디렉션 없음 |
| 로그인 상태 | 봉인된 단기 1st-party 쿠키, 시작한 탭에 묶인 일회용 코드, 로그인마다 새 세션 |
| 비밀 저장 | 세션·로그인 코드·좌석 토큰은 해시만 저장, OAuth client secret은 서버 시크릿 |
| 계정 격리 | 계정마다 독립 저장 객체, 요청은 인증된 계정의 객체에만 도달 |
| 입력 검증 | 요청 크기 제한, 요청 ID 형식 검사, 닉네임 정책(제어·양방향 문자·사칭 문자열 차단), 기록 정화 |
| 게임 공정성 | 서버 권위 엔진, CSPRNG 주사위, 난수 상태 비저장, 클라이언트 보고 기록은 보상 제외 |
| 재화 원장 | 서버 단일 경로, 음수 잔액 금지 제약, 이벤트 ID 멱등, 구매·강화·뽑기 단일 트랜잭션, 합계 검증 |
| 소셜 | 자유 채팅 없음(프리셋만), 친구 검색은 완전 일치·일일 한도, 차단 사실 비공개, 관전은 전원 동의 |
| 차단 스위치 | 재화·뽑기·서버 AI를 설정 변수로 즉시 중지 |

## 3. 향후 기능 사전 검토 (보안·정책 요건)

| 기능 | 보안 요건 | 정책 요건 |
|---|---|---|
| **보상함(우편함)** | 지급은 서버가 만든 원장 이벤트로만, 수령은 우편 ID 기준 멱등 + 한 트랜잭션, 만료는 서버 시각, 대량 발송은 관리자 감사 로그 + 대상 조건 서명, 회수 이벤트 정의, 계정별 미수령 상한 | 보상 사유·유효기간 표시, 만료 전 알림, 유상 재화 지급분 구분(환불 산정), 탈퇴 시 미수령 소멸 고지 |
| **교환 코드(쿠폰)** | 충분한 무작위 길이·혼동 문자 제외, 해시 저장, 계정당 1회·코드당 사용 한도를 원자적으로, 시도 횟수 제한(계정·IP·봇 확인), 존재 여부를 드러내지 않는 균일 응답, 배치 폐기 기능 | 유효기간·대상·1인 1회 조건 표시, 유상 판매 코드면 전자상거래·환불 규정, 외부 경품 이벤트는 경품 규정 확인(⚖) |
| **공지사항** | 관리자만 작성(접근 통제), HTML 허용 목록 정화 또는 일반 텍스트, 외부 링크 `noopener noreferrer`, 정적 배포로 서버 부담 최소화, 수정 이력 | 약관·처리방침 변경 공지(시행일·사전 공지 기간은 약관에 명시, ⚖), 점검·장애·확률 변경 공지 |
| **신고 시스템** | 신고자·대상·사유 코드만 저장, 계정당 일일 한도·중복 병합, 열람은 관리자만, 처리 감사 로그, 허위 신고 대응 | 접수·처리 절차와 기간, 제재 유형·사유 통지, 이의제기 경로·기한, 신고 데이터 보관 기간을 처리방침에 |
| **친구 추가 개선** | 연락처 연동·근처 사용자 추천 지양, 부분 검색 도입 시 열거 방지, 요청 스팸 한도 유지, 탈퇴 정리 경로(SEC-03) 선행, 차단 즉시 상태·초대 차단 | 만 14세 미만 소셜 기능 기본값(LEGAL-05), 접속 상태 공개 범위 선택, 처리방침에 친구 관계 데이터 명시 |
