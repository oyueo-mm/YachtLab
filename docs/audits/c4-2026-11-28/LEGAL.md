## 2. 항목별 상세

### LEGAL-01 개인정보 처리방침과 이용약관 — 높음 · P0

- **근거:** 개인정보 보호법 제2조 제5호(개인정보처리자에 "개인" 포함, "업무를 목적으로 개인정보파일을 운용"), 제30조(처리방침 수립·공개), 제30조의2(처리방침 평가제, 2024-03-15 시행). PIPC 「개인정보 처리방침 작성지침」 2025-04 개정판·2026 봄 개정판(보도). Google API Services User Data Policy(처리방침에서 Google 사용자 데이터 처리 방식 공개). 콘텐츠산업진흥법 제27·28조, 공정위 게임 표준약관(약관 구성 참고).
- **사실:** 사이트·저장소 어디에도 처리방침·약관이 없다. 로그인 화면에도 고지·링크가 없다.
- **[현재]:** 공개 서비스에서 계정·전적·친구 관계를 체계적으로 DB로 관리하므로 비영리 개인이라도 처리자에 해당할 가능성이 높다(⚖ 비영리 개인 운영자에 대한 PIPC 해석례 미발견). 보수적으로 **적용된다고 보고 처리방침을 공개**하는 것이 맞다. 약관은 법정 필수는 아니지만, 무상 재화의 성격(현금 가치·양도·환전 불가, 서비스 종료 시 소멸), 이용 제한·이의제기(LEGAL-09), 서비스 변경·중단, 면책의 근거가 없으면 제재·재화 회수 시 분쟁 근거가 없다.
- **[수익화 후]:** 약관은 사실상 필수(청약철회·환불·미성년자 취소·구독 해지·서비스 종료 환불). 처리방침에 결제(PG 위탁), 광고 쿠키·행태정보, 마케팅 수신 동의를 추가한다.
- **권고:** BACKLOG B-01·B-02. 처리방침은 홈(`/YachtLab/`)·로그인 화면·프로필에서 한 번에 찾을 수 있게 하고, Google OAuth 동의 화면 설정에 처리방침 URL·홈페이지 URL을 등록한다.

### LEGAL-02 개인정보 수집·이용·보관 — 중간 · P0

- **근거:** 개인정보 보호법 제15조 제1항 제4호(2023-09-15 시행, 계약 이행에 필요한 처리는 동의 없이 가능), 제16조(최소 수집), 제22조(고지 방법), 처리방침 작성지침(계약 이행 항목과 동의 항목 구분).
- **[현재] 평가:**
  - 양호: `openid`만 요청해 이메일·실명·사진을 받지 않는다. IP는 원문 저장 없이 해시로 메모리 처리. 공개 프로필은 가입 "월"만 노출.
  - 고지 필요: 위 §0 "서버 저장 개인정보" 전체, 브라우저 저장소(세션·게스트 키·UTM)와 거부 방법(로그인하지 않으면 서버 저장 없음), Workers Logs 3일(SEC-01 결과에 따라 항목 확정).
  - 닉네임은 자유 입력이라 실명이 들어갈 수 있다 → 입력 화면에 "실명·연락처를 넣지 마세요" 안내 권장.
  - 보관 기간 정의 필요: 세션 30일(만료 행 정리 필요, SEC-04), 전적·친구는 탈퇴 시까지, 리뷰 64경기, 방 48시간, 탈퇴 시각 30일, 로그 3일. 장기 미접속 계정 파기는 법적 의무가 아니다(유효기간제 2023-09-15 폐지) — 그래도 처리방침에 보유 기간은 써야 한다.
- **[수익화 후]:** 결제 내역은 전자상거래법상 보존 기간(거래 기록 5년 등 — ⚖ 원문 확인)에 따라 분리 보관.

### LEGAL-03 파기·회원 탈퇴·권리 행사·유출 대응 — 중간 · P1

- **근거:** 제21조(지체 없는 파기), 제35~37조(열람·정정·삭제·처리정지), 제31조(개인정보 보호책임자), 제34조(유출 통지·신고). 2026-09-11 시행 개정법(보도): 유출 통지 범위 확대(위조·변조·훼손, 유출 "가능성이 높은" 단계), 법정손해배상(최대 300만 원), 과징금 상향, 일정 규모 이상 CPO 신고(⚖ 소규모 적용 범위).
- **사실:**
  - 탈퇴(`POST /api/me/delete`, 확인 문구 필요)는 계정 DO 전체 삭제 + 게스트 연결 해제 + 친구에게 관계 삭제 통지 + 친구 색인 삭제를 한다(양호).
  - 그러나 탈퇴 후 다른 회원 쪽에 친구 관련 데이터 일부가 남는 경우가 있다(**SEC-03**, 상세 비공개). 다른 회원의 경기 기록에는 상대로서의 닉네임·내부 ID가 남는다(상대방 자신의 기록이므로 삭제 대상인지 ⚖, 최소한 처리방침에 고지).
  - 탈퇴 후 30일 "삭제 시각" 보관 목적(신규 보상 재수령 방지)은 문서화돼 있으나 법적 근거(정당한 이익 등)는 ⚖. 이 행은 계정 DO 안에 시각만 있고 다른 식별자는 없다(양호).
  - 열람(전적 조회)·정정(닉네임)·삭제 기능은 있으나 **처리정지·문의 연락처·보호책임자 표시가 없다.**
  - 유출 대응 절차·통지 템플릿이 없다(SEC-13과 함께).
