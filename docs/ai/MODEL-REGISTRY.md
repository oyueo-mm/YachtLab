# AI 모델 전수 조사와 통합 레지스트리 (3차 개편)

> 근거: 실제 코드(`src/`, `training/`, `scripts/`, 워크플로)와 이번에 작성한 전체 대국 테스트(`tests/ai-models.test.ts`).
> 레지스트리: 메타데이터 `src/model-catalog.ts`(앱 본체, 가벼움) · 결정 함수 `src/ai-models.ts`(Worker 전용) · ID 목록 `src/model-ids.ts`.
> **강함 순위가 아님.** 분류는 알고리즘 유형과 실행 가능 여부이며, 벤치마크가 없는 모델의 강함을 단정하지 않는다.

## 분류 기준

| 분류 | 의미 | 선택기 |
|---|---|---|
| **A. 대전 가능** (playable) | 12칸 전체 게임을 스스로 결정하며 전체 대국 테스트 통과 | 선택 가능 |
| **B. 조건부** (conditional) | 전체 대국은 가능하지만 고유 로직은 특정 단계·알려진 상대에서만 작동. 그 밖에는 명시된 **대체 정책**이 결정 | 선택 가능, 조건·대체 정책 표시 |
| **C. 연구 전용** (research) | 학습 코드만 있음, 체크포인트 미포함, 하위 문제 전용, 또는 정책이 아닌 구성요소 | 목록·사유만 표시, 선택 불가 |

파일이 존재한다는 이유만으로 A/B로 분류하지 않았다. A/B는 `decideModel`에 실제 결정 함수가 등록되고 아래 검증을 통과한 모델뿐이다.

## 공통 검증 (tests/ai-models.test.ts, 연결한 19개 모델 각각)

- 좌석 0·1 각각 Greedy 상대로 12라운드 완주, 모든 행동이 엔진 규칙상 합법(재굴림 ≤ 3회, 빈 칸만 기록), 무한 반복 없음(250 스텝 제한)
- 결정 노트가 선택한 모델 ID로 시작 → **실제로 그 모델이 결정**, 안전 대체 정책 사용 0회
- 초반·중반·후반(남은 칸 12/6/3/2/1) 상태에서 **비공개 seed/RNG를 바꿔도 같은 결정**(미래 주사위 정보 미사용)
- 등록 모델 전체: 중복 ID 없음, 조건부 모델은 조건·대체 정책 필수, 연구 전용은 사유 필수·선택 불가, 지원 규칙은 12칸뿐
- 실행 중 오류·불법 행동이 나오면 그 수만 DP Expert(불가 시 Greedy)로 대체하고 노트에 기록(게임은 항상 끝까지 진행)
- 기보: 연구 모델 ID가 저장·검증(`validateReplay`)을 통과

## 새 모델을 추가하는 방법

1. `src/model-ids.ts`에 ID 추가(DP 필요 여부 포함).
2. `src/model-catalog.ts`에 유형·분류·조건·대체 정책·비용 기재.
3. `src/ai-models.ts`의 `researchDecision`에 결정 함수 연결.
4. `tests/ai-models.test.ts`가 자동으로 전체 대국·합법성·비공개 정보 불사용을 검사한다. 통과하지 못하면 등록하지 않는다.
5. 일반 5단계 난이도에는 별도 벤치마크 검증 없이 추가하지 않는다.

기존 `Random`은 자기 무작위성을 엔진 RNG 상태에서 시드한다(미래 주사위 예측에는 쓰지 않음). 이번 작업에서는 기존 모델을 수정하지 않았으므로 그대로 두었다.
