## 디자인

- 주사위: 파스텔(5)·나무(2)·대리석(2)·얼음·카본·보석(루비·사파이어·에메랄드)·유리(2)·금속(실버·브론즈·황금)·오로라·용암·은하(우주)·네온(2)·홀로그램 + 기존 5. 면 무늬·마감(무광/반광/광택/금속/유리)·발광·움직임을 `src/dice3d/face-paint.ts`가 캔버스로 그리고, 3D 표(`table.ts`)는 그 텍스처에 거칠기·금속성·투명도·발광을 적용한다. Lv.3 움직임은 약 15fps, 화면 밖·탭 숨김·"효과 줄이기"에서 멈춘다. 눈과 면의 명도 대비 4.5 이상(테스트).
- 보드판: 펠트(4)·원목(2)·가죽(2)·대리석·바다·사막·얼음·우주·네온·오로라·황금 테이블·심해 + 기존 3. CSS 그라데이션·무늬(이미지 없음).
- 이모티콘·채팅: 표준 유니코드 이모지와 한국어 문구만(캐릭터·이미지 없음). 자유 채팅 없음.
- 말풍선·프로필 테두리·닉네임 효과·칭호: CSS. 닉네임 효과는 이름을 가리지 않는다.
- 특수 연출: DOM 입자(하트·별·비눗방울·꽃잎·눈·단풍·음표·불꽃·금화·번개·리본·은하·무지개·꽃가루) 최대 26개, 1.8초, 입력을 막지 않음, Lv.3 효과음은 `src/sound.ts` 합성.

## 상점·인벤토리·미리보기

- 상점: 상품군 탭(개수 표시), 등급·가격 필터(코인/보석/지금 살 수 있는 것), 반응형 카드 그리드(PC 6열·휴대폰 2열), 보유·구매 가능 표시, 카드 → 상세(미리보기·Lv.1~3 탭·구매) → 확인 대화상자 → 요청 ID와 함께 구매. 재화가 부족해도 미리보기는 열린다.
- 인벤토리: 장착 조합 미리보기(닉네임 카드·주사위·보드·이모티콘)와 저장, 상품군 탭, 장착·해제, 이모티콘·채팅 순서·슬롯, 상세에서 해금된 단계 선택·확인 후 강화. 저장 전 변경은 표시만 하고 서버 장착은 바뀌지 않는다.
- 실제 미리보기: 주사위는 실제 3D 표에서 굴리기, 보드는 실제 게임판, 이모티콘·채팅·말풍선은 경기 중 메시지 줄, 프로필·닉네임 효과·칭호는 플레이어 카드, 특수 연출은 결과 카드 위 재생과 효과음. 미리보기는 장착·게임 상태를 바꾸지 않는다(요청 없음, 테스트).
- 상대 화면: 서버가 검증한 장착에서 만든 look에 단계(`diceLv`·`boardLv`·`bubbleLv`·`profileLv`)를 추가했다. 예전 look은 Lv.1로 읽는다. 승률·주사위·물리에 영향 없음.
- 가격: M3i-W30 등급표(300/1,000/3,000/10,000/25,000코인 · 40/120/300/600/1,200보석) 그대로, 강화 1:0.5:1.
