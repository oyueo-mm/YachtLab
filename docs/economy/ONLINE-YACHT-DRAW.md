# 온라인 요트다이스 뽑기와 경제 변경

## 출시안

뽑기 1회에 플레이로 번 250코인을 쓴다. 재굴림 없이 주사위 5개를 한 번 굴리고, 중복 보상은 25코인이다. 일반과 시즌을 합쳐 계정당 하루 5회까지 허용하며 한국 시간 00시에 초기화한다. 10회 묶음은 별도 할인가와 미리 결제한 연속 정산을 유도하므로 출시 범위에서 보류했다. 같은 날 일반/시즌을 바꿔도 한도는 한 번만 적용된다.

당첨 우선순위는 요트 → 라지 스트레이트 → 포카드 → 풀 하우스 → 스몰 스트레이트 → 트리플 → 투 페어 → 원 페어 → 노 페어다. 같은 굴림은 한 족보로만 보상한다. 등급 내 상품은 균등 확률로 뽑는다. 보유 상태에 따른 가중치는 적용하지 않으며, 색다른 미스나 가짜 아깝다 연출을 제공하지 않는다. 특정 상품을 원하는 플레이어는 판매가를 확인하고 바로 구매할 수 있다.

| 등급 | 족보 발생 수 | 등급 확률 | 일반 상품 수 / 상품당 확률 | 크리스마스 상품 수 / 상품당 확률 |
| --- | ---: | ---: | ---: | ---: |
| 일반 | 3,120 | 40.1235% | 57 / 0.70392% | 3 / 13.37449% |
| 고급 | 3,000 | 38.5802% | 48 / 0.80376% | 2 / 19.29012% |
| 영웅 | 1,260 | 16.2037% | 46 / 0.35225% | 2 / 8.10185% |
| 전설 | 390 | 5.0154% | 27 / 0.18576% | 2 / 2.50772% |
| 신화 | 6 | 0.0772% | 12 / 0.00643% | 1 / 0.07716% |

일반 뽑기에는 일반 판매 목록 중 코인 구매가 가능한 상품을 넣었다. 기본 지급·업적 전용·보석 전용 상품은 각각 기존 획득 조건을 따른다. 7,776개 원시 경우의 수는 `enumerateDrawHands()`과 테스트에서 재현한다.

## 데이터와 서버

- 기존 사용자 SQLite Durable Object에 `draws` 테이블과 날짜 인덱스를 `CREATE IF NOT EXISTS`로 추가한다. 계정·세션·기보·인벤토리의 스키마와 상품 ID는 그대로 사용한다.
- 서버가 Web Crypto의 거부 샘플링으로 눈과 상품을 정한다. 같은 트랜잭션에서 코인 차감, 중복 코인 환급 또는 상품 지급, 관련 업적 처리, 결과 저장을 완료한다. 원장 ID는 `draw:<requestId>` 및 `draw-duplicate:<requestId>`다.
- 같은 계정·요청 ID·풀 조합을 다시 보내면 최초 영수증과 현재 잔액을 반환한다. 최초 요청 후 시즌이 끝나도 재조회는 가능하다. 다른 풀로 해당 ID를 쓰면 거부되며 다른 계정은 자기 기록만 읽는다.
- 브라우저는 해당 탭의 세션 저장소에 요청 ID를 남긴다. 통신이 끊기면 같은 ID로 결과를 확인할 수 있고 새 탭에서는 최근 30회 기록을 읽는다. 3D 엔진에는 서버가 정산한 눈만 넘긴다.
- 일일 퀘스트는 기존 무료 1회를 개별 또는 전체 교체 중에 쓸 수 있다. 주간은 무료 전체 교체 1회를 따로 둔다. 완료 슬롯·이미 지급한 원장 행은 보존하며 바뀐 슬롯은 진행도 0에서 시작한다. 클라이언트가 현재 날짜/주 식별자를 보내므로 이전 갱신 요청을 다음 기간으로 넘기지 않는다. 주간 교체 값이 없는 데이터는 0으로 읽는다.
- `DICE_DRAW="off"`로 뽑기를 일시 중단할 수 있다. 전면 되돌리기는 먼저 신기능과 새 가격을 표시하는 Pages 버전을 되돌린 뒤 호환 Worker로 롤백한다. Worker만 먼저 되돌리면 오래된 가격이 일시 적용될 수 있다. 새 테이블을 지우지 않으며 재배포하면 기존 영수증을 조회할 수 있다.

## 등급과 가격

일반·고급·영웅·전설·신화의 기존 기준가와 게임 내 획득 방식을 이용한다. 주사위 기준가는 300·1,000·3,000·10,000·25,000코인이다. 보드 90%, 외형이 단순한 말풍선 70%, 프로필과 일반 이모티콘 75%, 단순 채팅과 칭호 55%, 닉네임 효과 80%, 족보·승리 연출 95%를 적용했다. 특수 사운드와 시각 효과가 있는 새 채팅·이모티콘은 등급 기준가를 적용한다. 롤백과 이전 앱의 가격 표시를 고려해 기존 상품 가격은 인상하지 않는다.

예를 들어 민트 주사위는 300코인, 기존 인사 채팅은 165코인, 강조 연출이 있는 ‘그게 최선이야?’는 3,000코인이다. 외형 중심 골드 말풍선과 왕관 프로필은 전설에서 영웅으로, 일반 인사와 응원 성격의 일부 채팅은 등급을 낮췄다. 기존 구매·강화 기록과 잔액을 그대로 사용한다. 등급 조정에 따른 자동 차액 보상은 적용하지 않는다.

크리스마스 컬렉션은 2026년 12월 1일 00:00부터 2027년 1월 1일 00:00 직전까지 한국 시간 기준으로 판매한다. 산타 펭귄·루돌프·눈사람 프로필과 선물 이모티콘, 주사위·보드·말풍선·칭호·채팅·눈꽃 연출을 포함한다. 시즌이 끝나도 받은 상품의 장착과 강화가 가능하다. 이후 이벤트에 일부 또는 전부를 다시 판매할 수 있다.

## 경제 시뮬레이션

`npx tsx scripts/economy/simulate-live-draw.ts`로 시드 112626을 실행했다. 30일, 활동 유형별·전략별 500계정이다. 승률 50%의 회원 빠른 대전, 기존 연구의 족보 출현률, 운영 보상 함수, 신규 회원 보너스, 퀘스트 교체를 적용했다. 각 플레이 전략에서 같은 경기 표본을 사용했으며 소비 의사결정과 경기 간 상관관계 일부는 단순화했다. 운영 유저 로그는 이 실행에 사용하지 않았다.

| 1일 경기 / 주간 활동 | 월 코인·보석 획득 평균(가입 포함) | 250코인마다 뽑을 때 평균 횟수 / 중복 | 영웅 루비 주사위만 살 때 평균 강화 횟수 |
| --- | ---: | ---: | ---: |
| 2경기 / 3일 | 1,245코인 · 62보석 | 4.46 / 0.05 | 0 |
| 5경기 / 5일 | 4,744코인 · 161보석 | 18.58 / 1.01 | 0.79 |
| 12경기 / 7일 | 9,730코인 · 322보석 | 38.86 / 4.50 | 2 |

중복일 때도 225코인을 소비하므로 뽑기 반복만으로 잔액을 늘릴 수 없다. 영웅·전설·신화의 직접 구매 가격과 목표 수집은 플레이 패턴에 따라 다르다. 월 활동량이 적은 유형은 원하는 상품에 코인을 모으는 데 여러 달이 걸릴 수 있다. 이 수치는 출시 후 실제 소비량과 별도로 관리한다.
