## 0. 한눈에 보기

- **추천: M3 혼합·소프트캡** — 경기 코인(무작위 대전 승리 보너스) + 일일 3·주간 3 퀘스트 + 일회성 업적 보석, 하루 보상 경기 10까지 전액·30까지 25%·이후 0, 친구 대전 승리 보상 없음. 공식 재화는 **server-verified 기록에만** 지급. 수치는 출시 전 실제 데이터로 재보정(가정 기반).
- **실제 게임 데이터:** 숙련도 5단계 × 20,000경기 + 교차 30,000경기(기존 엔진·DP 기반 정책). 전문가 단계 통계가 정확 분포와 일치.
- **희귀 업적:** DP Expert **정확 점수 분포**를 처음 계산(평균 오차 1.4×10⁻¹³). 300점 이상 2.29×10⁻⁶(약 44만 경기에 1번), 323점 완벽 경기 4.4×10⁻¹⁶. 중요도 표집은 250·270점 교차 검증에만 유효.
- **무과금 신화(M3, 사용자 유형당 200명):** 일반 유저 1년 39% → 3년 91% → 5년 96%, 헤비 6개월 26%·1년 77%·3년 100%, 극단 헤비 1년 100%. 라이트는 5년 1%, 비정기는 0% — "충분히 노력하면 가능" 조건 충족, 가벼운 사용자에게는 장기 목표.
- **무과금 최대 강화(신화 Lv.3):** 5년 기준 일반 22%, 헤비 32%, 극단 80% — 가능하지만 매우 긴 목표(강화 기하급수 ×3, 기준 가격×0.5).
- **어뷰징(M3, 30일):** 하루 23시간 서버 AI 봇 = 헤비 유저의 **1.35배**(상한 없는 M1은 12.3배), 로컬 기록 위조 **0.02배**(클라이언트 기록을 믿는 M0는 15.8배), 친구 2계정 승리 거래 1.07배.
- **보석 희소성:** M3 일반 유저 보석 4.4/일(보석 1 ≈ 23코인 시간 가치). 보석을 3배로 늘린 M5는 일반 유저 1년 신화 39%→84%로 **희소성 붕괴** → 기각.
- **가격(기준 일반 유저 100코인/일):** 일반 200·고급 600·영웅 2,000·전설 6,000·신화 15,000코인 / 보석 40·120·300·600·1,200. 슬롯 300·600·1,000·1,500코인(또는 25·50·80·120보석). 강화 신화 8,000/20,000. 상징 초고가 80,000코인.
- **Cloudflare:** 경제 처리는 행 쓰기를 약 12% 늘릴 뿐이고, 병목은 **현재 온라인 방의 경기당 약 120 쓰기**. 무료 플랜(하루 방 300)은 이 사용자 구성으로 DAU 수십 명 수준이 상한이며, Workers Paid 추정 $5~8/월(신규 10~30명/일), $41(100명/일), $217(300명/일).

## 1. 확정 정책(사용자 지시) — 설계 제약으로 그대로 사용

- 재화 2종: **코인**(일반 플레이로 지속 획득), **보석**(어렵지만 무과금 획득 가능). 둘 다 추후 현금 구매 가능.
- 재화 간 교환·선물·사용자 간 거래·현금 환전 **불가**. Pay to Win 없음(아이템·강화는 순수 외형).
- 등급: 기본·일반·고급·영웅·전설·신화 + **특수(업적 전용·상징)**. 신화까지는 무과금도 충분한 노력으로 획득 가능. 업적 전용 아이템은 현금·재화로 구매 불가.
- 숙련도 시스템 없음. 강화는 **재화 소비 확정 강화**, 단계가 높을수록 가파르게 비쌈.
- 상점·인벤토리는 별도 페이지. 이모티콘 슬롯 기본 4·최대 8, 프리셋 채팅 슬롯 기본 6·최대 10, 추가 슬롯은 영구 구매.

방법론 결론:
1. **시간 기반 가격(time-to-earn):** 가격 = 목표 획득 일수 × 기준 사용자 일 소득. 기준 사용자는 "일반 유저(로그인·무과금)".
2. **정규화 비교:** 모델마다 코인 지급을 정규화해 기준 사용자 소득을 같게 맞추고 분포·어뷰징·누적만 비교.
3. **발행·소각 균형:** 거래가 없으므로 전체 통화량보다 **개인 잔액과 출시 속도**가 핵심.
4. **서버 권위 원장:** 공식 재화는 서버 검증 이벤트만 입력, 이벤트 ID 멱등 처리.

## 3. 실제 게임 데이터 생성(기존 엔진·AI 활용)

- `scripts/economy/generate-match-data.ts`: `src/engine.ts`의 실제 게임(플레이어별 독립 주사위, `createGame(seed, true)`)을 DP Expert 행동가치(`dpActionValues`)에 **소프트맥스 온도 τ**를 준 정책으로 진행. τ=0은 DP Expert와 같다.
- 숙련도 5단계: 입문 τ2.5, 초급 1.6, 중급 1.0, 숙련 0.5, 전문가 0. 단계당 동형 대전 20,000경기, 교차 10쌍×3,000경기(선후공 교대). 시드 71,000,000~(**경제 연구 개발용 시드, 홀드아웃 아님**).
- 공정성: 정책은 공개 상태(주사위·점수판·굴림 수)만 읽는다. 엔진 RNG·시드를 읽지 않으며, 정책 자체 난수는 별도 xorshift.
- 검증: 전문가 단계의 200점·250점·270점 이상 비율이 정확 분포와 신뢰구간 내 일치(§4).
- 한계: 사람의 실수 패턴은 소프트맥스와 다를 수 있다(예: 특정 칸 집착). 실제 사용자 기록(server-verified)이 쌓이면 단계를 다시 보정한다.

## 4. 희귀 업적: Monte Carlo에서 안 나와도 "불가능"이 아니다

| 방법 | 대상 | 결과 요약 |
|---|---|---|
| 닫힌 식·이항 | 첫 굴림 요트(굴림당 6/7776), 경기당 2회·3회 | 경기당 ≥2 ≈ 3.9×10⁻⁵, ≥3 ≈ 1.0×10⁻⁷ |
| 턴 단위 최적 DP | 한 턴에 요트(최적 보유) | 4.6029% (알려진 값과 일치) |
| 게임 전체 패턴 DP(4,096 마스크) | 323점 완벽 경기, 상단 105점, 0점 없는 경기 | 목표만 노리는 최적 플레이에서도 완벽 경기 3.2×10⁻¹⁴ |
| **DP Expert 정확 점수 분포**(마르코프 연쇄 역전파, 31초) | 총점 꼬리 P(≥x) | 평균이 DP 테이블 값과 1.4×10⁻¹³ 이내 일치. 300점 이상 2.29×10⁻⁶, 310점 6.65×10⁻⁹, 323점 4.4×10⁻¹⁶ |
| 중요도 표집(교차 엔트로피로 주사위 면 분포 조정) | 250·270·290점 | 250·270점은 정확값과 일치. 290점은 상대오차 약 40%로 비효율, 첫 소규모 시험에서는 적중 0 → **부정적 결과로 기록**하고 정확 분포를 사용 |
| 쿠폰 수집 정확식 | 1~6 모든 눈 요트 | 기대 경기 수 계산(포함-배제) |

설계 결론: **기대 경기 수 10⁶ 초과는 "상징(사실상 불가능)" 등급**으로 분류해 숨김 업적·칭호만 주고 재화 보상은 상한(100보석)으로 묶는다. 323점 완벽 경기는 규칙상 가능하지만 22해(2.3×10¹⁵) 경기에 한 번 수준이라 목표로 제시하지 않는다.

## 5. 퀘스트·업적 후보

전체 후보·확률·기대 경기 수·보상: [RESULTS-GENERATED §3~4](./RESULTS-GENERATED.md#3-퀘스트-후보-달성-확률일반-유저-경기-수-중급-기준), 코드 `src/economy/content.ts`.

- **일일(3개: 쉬움·보통·어려움 각 1, 자동 수령):** 경기 3회 / 풀 하우스 / 스몰 스트레이트 · 1승 / 상단 보너스 / 라지 2회 / 180점+ · 2승 / 200점+ / 요트 / 포커 2회.
- **주간(3개):** 15경기 / 풀 하우스 8 · 7승 / 상단 보너스 5 / 요트 2 · 220점+ 2회 / 요트 4 / 12승.
- **월간:** 별도 월간 퀘스트는 **도입하지 않음 권장**, 대신 "한 달에 일일 퀘스트 15일 완료" 월간 도전(M6)을 선택 후보로 둔다(근거 §7).
- **업적 분류:** 누적(경기·승리·요트·보너스), 실력(200/250/270점, 0점 없음, 정석 보너스, 역전승, 무작위 대전 5·10연승), 행운(첫 굴림 요트, 헥사 30, 마지막 라운드 요트, 첫 굴림 라지 10회), 특수(한 경기 첫 굴림 요트 2·3회, 300·310·323점), 수집·장기(1~6 요트 수집, 서버 검증 경기한 날 30~1000일, 일일 퀘스트 30~365회).
- **랭크(향후, 분석만):** 배치 완료, 상위 구간, 상위 1%, 연속 시즌 유지 — 보상은 칭호·테두리(업적 전용), 재화 없음.
- **보상식:** 업적 보석 = 1.5·√(중급 기대 경기 수), 상한 100. 첫 보정(5·√E, 상한 300)은 업적이 무과금 보석의 72%를 차지해 **기각**.
- **제외한 퀘스트:** 패배·0점 기록(고의 패배), 친구와 N경기(담합), 이모티콘·채팅 N회(도배), 빨리 끝내기, 출석만, 구매·강화(과금 유도), 로컬 AI 승리(위조 가능), 특정 칸 특정 점수(비정상 전략).

## 11. 어뷰징 방지 정책

1. **공식 재화는 server-verified만.** 로컬 AI·로컬 2인·기기 업로드·게스트 가져오기 기록은 보상 입력 금지(D-028 유지).
2. **멱등 원장:** 보상 이벤트 키 = `matchId:playerId:rewardType`, 계정 DO에 기본키로 저장 → 재전송·중복 처리 무해. 잔액은 원장의 합과 주기적으로 대조.
3. **하루 보상 경기 상한:** 10경기 전액 → 30경기까지 25% → 이후 0(퀘스트·업적 진행은 계속). 서버 AI 봇의 초과 이득을 헤비 유저 대비 약 1.5배(하루 22시간 플레이 가정)로 제한.
4. **친구 대전:** 승리 보상 없음, 하루 10경기, 연승·랭크 업적 제외 → 2계정 승리 거래 이득 ≈ 정상 헤비 수준.
5. **무작위 매칭:** 같은 기기 키·IP 해시 쌍 매칭 금지, 같은 상대 반복 시 보상 감소 후보, 기권·조기 이탈 경기는 완료 보상 없음.
6. **신규 보상:** 계정에 귀속·이전 불가. 다중 계정 이득은 각 계정에 갇히므로 경제 전체 피해는 "발행량 증가"뿐(구매력 이전 없음).
7. **업적 보상 상한:** 업적 보석은 평생 공급이 유한(상한 100/개)이라 봇이 빨리 달성해도 장기 초과분이 제한됨.
8. **서버 AI 대전(미구현 설계):** 상태 저장 방 대신 서명된 전사 방식(굴림마다 서버가 HMAC 서명 상태 발급, 종료 시 서버가 같은 엔진·AI로 재생 검증 후 1회 기록) 후보. 주사위는 서버가 굴려 클라이언트가 미래 눈을 알 수 없다. 위험: Workers Free CPU 10ms/요청 안에 DP 테이블(2MB) 로드·재생이 가능한지 측정 필요.
9. **감시 지표:** 계정별 일 보상 경기 수 분포 상위 0.1%, 동일 상대 반복률, 승률 극단치, 업적 달성 속도 이상치(확률 대비 z-점수 — 확률표가 있으므로 계산 가능).
10. **조작 불가 표시:** 상대에게 보이는 장착 아이템은 서버가 계정 저장소에서 읽은 값만(클라이언트 주장 무시).

## 14. 한계와 다음 연구

- 사용자 행동(접속·경기 수·소비·결제·수명)은 전부 가정. 민감도에서 활동량이 가장 큰 변수였다 → 실제 server-verified 기록이 생기면 가장 먼저 교체.
- 숙련도는 DP 소프트맥스 대리 지표. 실제 사람의 승률·사건 확률과 다를 수 있다.
- 경기 내 사건(요트·고득점·승리) 상관을 무시했다(독립 이항). 상관 반영 시 일부 퀘스트 동시 달성 확률이 달라진다.
- 하위 단계의 300점 이상 확률은 전문가 정확값을 상한으로만 썼다(하위 단계 정확 분포는 소프트맥스 정책 PMF로 계산 가능 — 후보).
- 무작위 매칭 승률 0.5 가정(실력 매칭). 매칭 풀이 작으면 실력차 대전이 많아져 승리 보상 분포가 바뀐다(교차 승률표 활용 가능).
- Cloudflare 쓰기 수는 설계 추정치. 실제 대시보드 측정으로 교체 필요.
- 이번 실행의 시드는 개발용이며 홀드아웃 검증을 하지 않았다(경제 시뮬레이션은 예측 모델 선택이 아니므로 다른 시드 반복으로 안정성만 확인 권장).
