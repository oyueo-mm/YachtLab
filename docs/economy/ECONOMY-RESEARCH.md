## 0. 한눈에 보기 (2차 추가 검증 반영, 2026-11-24)

- **채택 후보: M3 혼합·소프트캡의 정수 운영안 `M3i-W30`** — 무작위 대전 완료 10·승리 +3·무승부 +2, 친구 대전 완료 10(승리 보상 없음, 하루 10경기), 서버 AI 완료 7·승리 +2, 하루 10경기 이후 경기당 3, 30경기 이후 0. 일일 퀘스트 15·20·30(+전부 완료 15·보석 1), 주간 70·100·130·보석 2·3·5(+전부 완료 70·보석 5). 업적 보석 5~100(+보석×7코인). 신규 200코인·20보석·첫 7일 경기당 +5. 이벤트(6주마다 7일) 경기당 +5·완료 150코인·10보석. 공식 재화는 **server-verified 기록에만**. 사용자 행동이 모두 가정이므로 출시 후 실제 기록으로 다시 보정.
- **가격(정수안 기준, 일반 유저 약 150~156코인·4.1보석/일):** 일반 300 · 고급 1,000 · 영웅 3,000 · 전설 10,000 · 신화 25,000코인 / 40 · 120 · 300 · 600 · 1,200보석. **신화는 모두 "선택 결제(코인 또는 보석)"** — 보석 전용 신화 비중이 1년 신화 획득률을 2~65%로 좌우했다(§16.7).
- **강화(코인 전용, 보석으로 산 아이템도 코인):** 가격 : Lv1→2 : Lv2→3 = **1 : 0.5 : 1** 권장(신화 12,000 / 25,000). 신화 하나만 노리는 일반 유저 기준 신화 156일·최대 강화 401일, 헤비 89일·239일. 1차안 1:0.5:1.5는 507일·300일, 1:1:3은 861일·509일, 1:2:4는 1,169일·695일 — "지나치게 어렵다"는 우려가 수치로 확인됨(§16.12).
- **무과금 신화(일반 구매형, 5개 시드·카탈로그 평균):** 일반 유저 1년 26%(13~35%) → 3년 82%, 헤비 1년 57%. 신화를 전부 선택 결제로 두면 일반 1년 65%·3년 90%, 헤비 1년 94%.
- **반복 vs 일회성:** 업적·신규 보상(일회성)은 1년차 보석의 약 42%, 5년차 10% 이하. 업적을 대부분 달성한 장기 사용자도 반복 보석 연 880(일반)~1,230(극단)으로 신화 보석 상품을 1~1.4년에 하나 살 수 있다 — 보석 희소성 유지(§16.4~5).
- **승리 보너스:** 10·20·30·67% 비교에서 강자/약자 수입 차는 3~6%, 봇 배수는 거의 같음 → **+3(30%)** 채택 후보(승리 체감은 남기고 담합·봇 유인은 작게).
- **이벤트 없이도 유지:** 이벤트를 없애도 일반 유저 코인 −4%, 3년 신화 84→83%.
- **게스트 소급(후보, 미확정):** 상한 없는 30일 소급은 게스트 봇이 4,400코인을 가져감. **기간 무관 최대 20경기(G20)** 또는 소급 없음(G0)을 후보로.
- **어뷰징(30일):** 서버 AI 봇 헤비 대비 1.33~1.39배, 로컬 기록 위조 0.02배(클라이언트 신뢰 반례 M0는 15.9배), 친구 2계정 승리 거래 1.07배.
- **Cloudflare(실측):** 온라인 1경기 = 행 쓰기 **약 110**(기존 추정 120). 무료 몫 70%·경제 2쓰기면 하루 **PvP 약 610경기**, "턴 첫 굴림 병합" 설계면 약 765경기. 단, **DO 실행 시간 한도가 하루 약 270~550경기에서 먼저 닿을 수 있어** 대시보드 실측이 최우선. 유료 전환·신규 유료 리소스는 만들지 않음.
- **희귀 업적:** DP Expert **정확 점수 분포**(평균 오차 1.4×10⁻¹³) — 300점+ 2.29×10⁻⁶, 323점 4.4×10⁻¹⁶. 상단 보너스 관련 퀘스트·업적과 매우 어려운 AI 승리 퀘스트는 **보류**.

## 1. 확정 정책(사용자 지시) — 설계 제약으로 그대로 사용

- 재화 2종: **코인**(일반 플레이로 지속 획득), **보석**(어렵지만 무과금 획득 가능). 둘 다 추후 현금 구매 가능.
- 재화 간 교환·선물·사용자 간 거래·현금 환전 **불가**. Pay to Win 없음(아이템·강화는 순수 외형).
- 등급: 기본·일반·고급·영웅·전설·신화 + **특수(업적 전용·상징)**. 신화까지는 무과금도 충분한 노력으로 획득 가능. 업적 전용 아이템은 현금·재화로 구매 불가.
- 숙련도 시스템 없음. 강화는 **재화 소비 확정 강화**, 단계가 높을수록 가파르게 비쌈.
- 상점·인벤토리는 별도 페이지. 이모티콘 슬롯 기본 4·최대 8, 프리셋 채팅 슬롯 기본 6·최대 10, 추가 슬롯은 영구 구매.

방법론 결론:
1. **시간 기반 가격(time-to-earn):** 가격 = 목표 획득 일수 × 기준 사용자 일 소득. 기준 사용자는 "일반 유저(로그인·무과금)".
2. **정규화 비교:** 모델마다 코인 지급을 정규화해 기준 사용자 소득을 같게 맞추고 분포·어뷰징·누적만 비교.
3. **발행·소각 균형:** 거래가 없으므로 전체 통화량보다 **개인 잔액과 출시 속도**가 핵심.
4. **서버 권위 원장:** 공식 재화는 서버 검증 이벤트만 입력, 이벤트 ID 멱등 처리.

## 3. 실제 게임 데이터 생성(기존 엔진·AI 활용)

- `scripts/economy/generate-match-data.ts`: `src/engine.ts`의 실제 게임(플레이어별 독립 주사위, `createGame(seed, true)`)을 DP Expert 행동가치(`dpActionValues`)에 **소프트맥스 온도 τ**를 준 정책으로 진행. τ=0은 DP Expert와 같다.
- 숙련도 5단계: 입문 τ2.5, 초급 1.6, 중급 1.0, 숙련 0.5, 전문가 0. 단계당 동형 대전 20,000경기, 교차 10쌍×3,000경기(선후공 교대). 시드 71,000,000~(**경제 연구 개발용 시드, 홀드아웃 아님**).
- 공정성: 정책은 공개 상태(주사위·점수판·굴림 수)만 읽는다. 엔진 RNG·시드를 읽지 않으며, 정책 자체 난수는 별도 xorshift.
- 검증: 전문가 단계의 200점·250점·270점 이상 비율이 정확 분포와 신뢰구간 내 일치(§4).
- 한계: 사람의 실수 패턴은 소프트맥스와 다를 수 있다(예: 특정 칸 집착). 실제 사용자 기록(server-verified)이 쌓이면 단계를 다시 보정한다.

## 4. 희귀 업적: Monte Carlo에서 안 나와도 "불가능"이 아니다

| 방법 | 대상 | 결과 요약 |
|---|---|---|
| 닫힌 식·이항 | 첫 굴림 요트(굴림당 6/7776), 경기당 2회·3회 | 경기당 ≥2 ≈ 3.9×10⁻⁵, ≥3 ≈ 1.0×10⁻⁷ |
| 턴 단위 최적 DP | 한 턴에 요트(최적 보유) | 4.6029% (알려진 값과 일치) |
| 게임 전체 패턴 DP(4,096 마스크) | 323점 완벽 경기, 상단 105점, 0점 없는 경기 | 목표만 노리는 최적 플레이에서도 완벽 경기 3.2×10⁻¹⁴ |
| **DP Expert 정확 점수 분포**(마르코프 연쇄 역전파, 31초) | 총점 꼬리 P(≥x) | 평균이 DP 테이블 값과 1.4×10⁻¹³ 이내 일치. 300점 이상 2.29×10⁻⁶, 310점 6.65×10⁻⁹, 323점 4.4×10⁻¹⁶ |
| 중요도 표집(교차 엔트로피로 주사위 면 분포 조정) | 250·270·290점 | 250·270점은 정확값과 일치. 290점은 상대오차 약 40%로 비효율, 첫 소규모 시험에서는 적중 0 → **부정적 결과로 기록**하고 정확 분포를 사용 |
| 쿠폰 수집 정확식 | 1~6 모든 눈 요트 | 기대 경기 수 계산(포함-배제) |

설계 결론: **기대 경기 수 10⁶ 초과는 "상징(사실상 불가능)" 등급**으로 분류해 숨김 업적·칭호만 주고 재화 보상은 상한(100보석)으로 묶는다. 323점 완벽 경기는 규칙상 가능하지만 22해(2.3×10¹⁵) 경기에 한 번 수준이라 목표로 제시하지 않는다.

## 5. 퀘스트·업적 후보

전체 후보·확률·기대 경기 수·보상: [RESULTS-GENERATED §3~4](./RESULTS-GENERATED.md#3-퀘스트-후보-달성-확률일반-유저-경기-수-중급-기준), 코드 `src/economy/content.ts`.

- **주간(3개):** 15경기 / 풀 하우스 8 · 7승 / 요트 2 · 220점+ 2회 / 요트 4 / 12승. (상단 보너스 5회는 **보류**)

- **업적 분류:** 누적(경기·승리·요트), 실력(200/250/270점, 0점 없음, 역전승, 무작위 대전 5·10연승), 행운(첫 굴림 요트, 헥사 30, 마지막 라운드 요트, 첫 굴림 라지 10회), 특수(한 경기 첫 굴림 요트 2·3회, 300·310·323점), 수집·장기(1~6 요트 수집, 서버 검증 경기한 날 30~1000일, 일일 퀘스트 30~365회).
- **보류(합의):** 상단 보너스 10·100·500회, 상단 모든 칸 3개 이상(정석 보너스), 일일·주간 상단 보너스 퀘스트, 매우 어려운 AI 승리 퀘스트. 카탈로그에 `onHold`로 남기고 시뮬레이션·추천에서 제외.
- **랭크(향후, 분석만):** 배치 완료, 상위 구간, 상위 1%, 연속 시즌 유지 — 보상은 칭호·테두리(업적 전용), 재화 없음.
- **보상식:** 업적 보석 = 1.5·√(중급 기대 경기 수), 상한 100. 첫 보정(5·√E, 상한 300)은 업적이 무과금 보석의 72%를 차지해 **기각**.

## 11. 어뷰징 방지 정책

1. **공식 재화는 server-verified만.** 로컬 AI·로컬 2인·기기 업로드·게스트 가져오기 기록은 보상 입력 금지(D-028 유지).
2. **멱등 원장:** 보상 이벤트 키 = `matchId:playerId:rewardType`, 계정 DO에 기본키로 저장 → 재전송·중복 처리 무해. 잔액은 원장의 합과 주기적으로 대조.
3. **하루 보상 경기 상한:** 10경기 전액 → 30경기까지 25% → 이후 0(퀘스트·업적 진행은 계속). 서버 AI 봇의 초과 이득을 헤비 유저 대비 약 1.5배(하루 22시간 플레이 가정)로 제한.
4. **친구 대전:** 승리 보상 없음, 하루 10경기, 연승·랭크 업적 제외 → 2계정 승리 거래 이득 ≈ 정상 헤비 수준.
5. **무작위 매칭:** 같은 기기 키·IP 해시 쌍 매칭 금지, 같은 상대 반복 시 보상 감소 후보, 기권·조기 이탈 경기는 완료 보상 없음.
6. **신규 보상:** 계정에 귀속·이전 불가. 다중 계정 이득은 각 계정에 갇히므로 경제 전체 피해는 "발행량 증가"뿐(구매력 이전 없음).
7. **업적 보상 상한:** 업적 보석은 평생 공급이 유한(상한 100/개)이라 봇이 빨리 달성해도 장기 초과분이 제한됨.
8. **서버 AI 대전(미구현 설계):** 상태 저장 방 대신 서명된 전사 방식(굴림마다 서버가 HMAC 서명 상태 발급, 종료 시 서버가 같은 엔진·AI로 재생 검증 후 1회 기록) 후보. 주사위는 서버가 굴려 클라이언트가 미래 눈을 알 수 없다. 위험: Workers Free CPU 10ms/요청 안에 DP 테이블(2MB) 로드·재생이 가능한지 측정 필요.
9. **감시 지표:** 계정별 일 보상 경기 수 분포 상위 0.1%, 동일 상대 반복률, 승률 극단치, 업적 달성 속도 이상치(확률 대비 z-점수 — 확률표가 있으므로 계산 가능).
10. **조작 불가 표시:** 상대에게 보이는 장착 아이템은 서버가 계정 저장소에서 읽은 값만(클라이언트 주장 무시).

## 14. 한계와 다음 연구

- 사용자 행동(접속·경기 수·소비·결제·수명)은 전부 가정. 민감도에서 활동량이 가장 큰 변수였다 → 실제 server-verified 기록이 생기면 가장 먼저 교체.
- 숙련도는 DP 소프트맥스 대리 지표. 실제 사람의 승률·사건 확률과 다를 수 있다.
- 경기 내 사건(요트·고득점·승리) 상관을 무시했다(독립 이항). 상관 반영 시 일부 퀘스트 동시 달성 확률이 달라진다.
- 하위 단계의 300점 이상 확률은 전문가 정확값을 상한으로만 썼다(하위 단계 정확 분포는 소프트맥스 정책 PMF로 계산 가능 — 후보).
- 무작위 매칭 승률 0.5 가정(실력 매칭). 매칭 풀이 작으면 실력차 대전이 많아져 승리 보상 분포가 바뀐다(교차 승률표 활용 가능).
- Cloudflare 쓰기 수는 설계 추정치. 실제 대시보드 측정으로 교체 필요.
- 이번 실행의 시드는 개발용이며 홀드아웃 검증을 하지 않았다(경제 시뮬레이션은 예측 모델 선택이 아니므로 다른 시드 반복으로 안정성만 확인 권장).

### 16.12 강화: 비율·대상·재화 정책

신화 하나만 노리고 다른 것은 사지 않는 **목표 저축형**과, 여러 상품을 사는 **일반 구매형**을 분리했다(무과금).

| 가격:Lv1→2:Lv2→3 | 신화 총비용 | 목표형 일반: 신화 · 최대 강화 | 목표형 헤비 | 목표형 극단: 최대 | 일반 구매형 헤비: 최대 강화 3년 / 5년 |
|---|---|---|---|---|---|
| 1:0.25:0.75 | 51,000 | 156일 · 327일 | 89일 · 196일 | 148일 | 69% / 93% |
| **1:0.5:1** | **62,000** | **156일 · 401일** | **89일 · 239일** | **180일** | **50% / 85%** |
| 1:0.5:1.5 (1차) | 77,000 | 156일 · 507일 | 89일 · 300일 | 227일 | 8% / 38% |
| 1:1:2 | 100,000 | 156일 · 657일 | 89일 · 393일 | 302일 | 0% / 10% |
| 1:1:3 | 130,000 | 156일 · 861일 | 89일 · 509일 | 393일 | 0% / 3% |
| 1:2:4 | 175,000 | 156일 · 1,169일 | 89일 · 695일 | 540일 | 0% / 0% |

- 라이트 유저는 목표형이어도 신화까지 약 2년(723일), 최대 강화는 1:0.25:0.75에서만 5년 내(1,525일).
- **권장 1:0.5:1**: 단계마다 비용이 2배로 "가파르게 증가"를 유지하면서, 신화 하나에 집중한 일반 유저가 약 13개월, 헤비가 8개월에 최대 강화. 1:1:3·1:2:4는 일반 유저 2.4~3.2년으로 지나치게 어렵다.
- **보석으로 산 아이템의 강화 재화**: 항상 코인(권장) → 일반 신화 최대 327일, 구매한 재화(보석)로 강화 → 723일(+1,391보석 소모, 보석 희소성 악화), 둘 중 선택 → 코인과 같음(합리적 사용자는 코인 사용). **강화는 항상 코인**으로 단순화.

### 16.13 특수 등급 구조(명칭·조건 미확정)

특수 등급은 하나의 "등급"이 아니라 **획득 경로가 다른 두 계열을 담는 틀**로 둔다. 이름과 조건은 확정하지 않는다.

| 계열 | 획득 | 구매 | 예시 조건(후보) | 경제 역할 |
|---|---|---|---|---|
| 특수-업적형 | 업적 달성만 | **불가**(현금·재화 모두) | 300점+, 한 경기 첫 굴림 요트 2회, 무작위 대전 10연승, 1~6 요트 수집, 장기 플레이 | 상징·자랑. 재화 공급 없음(보석 보상 상한 100) |
| 특수-상징 구매형 | 코인 구매 | 코인만(보석·선택 결제 없음) | 80,000~999,999코인 후보 | 장기 코인 싱크. 능력치 없음 |

- 데이터 모델: `tier: "special"`, `specialKind: "achievement" | "symbolic-purchase"`, `acquisition`은 둘 중 하나로 고정하고 서버가 구매 요청에서 `achievement` 계열을 거부한다(D-026 카탈로그 불변 ID 규칙 재사용).
- 업적형은 업적 확률표(정확 계산·실측)를 그대로 조건 후보로 쓴다. 기대 경기 수 10⁶ 초과(310점, 323점, 첫 굴림 요트 3회)는 "숨김 업적"으로만.
- 상징 구매형은 **코인 전용**: 현금으로 산 코인으로도 살 수 있으므로(정책상 코인 현금 구매 허용) "무과금만 가능"하게 만들 수 없다. 대신 가격을 반복 수입 기준으로 정하고 능력치가 없음을 명시한다.
