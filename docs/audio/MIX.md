# 오디오 믹스 (2026-11-27)

> 사용자 피드백: "BGM이 100%로 올려도 잘 안 들린다", "이모티콘 전용 효과음이 너무 작다".
> 작곡 방향은 그대로 두고 **출력 수준·믹싱·음량 곡선**만 고쳤다. 저장된 음량 값(`yachtlab.settings.v1`)은 초기화하지 않는다.

## 변경

- **BGM 정규화** (`src/audio/bgm-render.ts` `normalize`): 렌더된 반복 구간을 목표 RMS(기본 −20 dBFS, 경기 −22, 리뷰 −21)로 맞추고 샘플 피크는 −1 dBFS를 넘지 않게 한다. 곡 구성·반복 이음매·크로스페이드·지연 렌더는 그대로.
- **믹스 그래프** (`src/sound.ts`): 효과음을 범주 버스(dice 1.0 · ui 1.25 · moment 1.6 · item 2.6 · emote 3.2)로 나누고, 효과음 버스와 BGM 버스를 하나의 피크 리미터(−1.5 dBFS, 20:1, 1 ms)에 모은다. 예전 압축기는 제거.
- **소리별 보정** `LV3_TRIM_DB`·`EMOTE_TRIM_DB`·`LAND_TRIM_DB`: 측정값을 범주 목표로 모으는 dB 보정(피크는 기본 음량에서 −8 dBFS 아래).
- **음량 곡선** `volumeCurve`: 같은 슬라이더 간격 = 같은 dB. 효과음 30 dB 범위(100 % = +6 dB 여유, **기본 70 %의 실제 이득은 예전과 동일**하게 0.63), BGM 20 dB 범위(100 % = 0 dB). 10 % 아래는 무음까지 직선.
- **클릭 제거** `silentGain`: 모든 포락선 GainNode를 0에서 시작(BGM 렌더러 포함).
- **덕킹**: 요트·라지 스트레이트·결과·이모티콘 Lv.3이 울리면 BGM을 약 5 dB 낮췄다가 되돌린다.
- 라지 스트레이트 음 +3 dB(요트보다 약간 작게 유지).
- 그대로인 것: 전체 음소거·효과음/BGM 개별 스위치·음량, 장면 우선순위, 같은 장면 재요청 무시, 숨은 탭 정지, 첫 제스처 전 무음, 주사위 충돌음 예산(동시 10개·같은 종류 최소 간격).

## 검증 범위

- ✅ 자동: `tests/audio-mix.test.ts`(곡선·정규화), `tests/ui/audio-mix.spec.ts`(브라우저 오프라인 렌더: BGM 7곡 RMS·피크, 이모티콘 41종 크기·100 % 클리핑 없음, 이모티콘 중앙값 > 주사위 충돌), 기존 `polish.spec.ts` BGM·설정 테스트 통과.
