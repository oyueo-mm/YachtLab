- 오디오 자산 파일이 0개이므로 초기 로딩 용량이 늘지 않는다. 곡은 장면에 처음 들어갈 때 렌더링(약 0.1~0.3 s, 오디오 스레드)되어 메모리에만 캐시된다(22.05 kHz 스테레오 Float32, 곡당 약 2~3 MB).
- 향후 BGM·사운드 팩을 상품화할 때: `TRACKS`(장면 → 작곡)와 같은 형태의 표를 상품별로 두고 `bgm.ts`의 `track()`이 선택된 팩의 표를 쓰게 하면 재생·크로스페이드·설정은 그대로 재사용된다. 외부 음원을 도입하면 이 표에 출처·라이선스·표시 의무를 반드시 추가한다.
- 실제 사람 귀로 들은 평가는 개발 환경(헤드리스 브라우저)에서 할 수 없었다. 운영에서 음량 균형·피로도를 확인해야 한다(아래 보고서 "미확인").
