# 운영자 확인 필요 사항 (C4.3)

정책 페이지는 아래 항목이 모두 확정되고 운영자가 문구를 승인해야 공개할 수 있다. 확정되면 `src/legal/release.ts`의 `OPERATOR` 값을 채우고 각 문서의 `[[확인 필요: …]]` 표시를 실제 문구로 바꾼 뒤 `LEGAL_RELEASED = true`로 바꾼다. `tests/legal.test.ts`가 빈 값이나 남은 표시가 있으면 공개를 막는다. **Claude·Codex 등 개발 에이전트는 이 값을 추측해 채우지 않는다.**

## 0. 운영자 결정 (2026-11-28, D-093)

| 결정 | 반영 |
|---|---|
| 운영자 표시명·문의 이메일·개인정보 보호책임자·시행일은 **추후 확정** | `OPERATOR` 모두 `null` 유지 → 공개 게이트 유지 |
| 모든 변경에 일률적인 7일·30일 사전 공지를 **자체적으로 부과하지 않음** | 약관 제3조·제6조·제9조, 처리방침 14항에서 고정 기간 삭제 |
| 기능 추가·UI 개선·오류 수정·보안 패치는 **신속 적용** | 약관 제9조 제1항: 이용자에게 불리하지 않은 변경은 별도 공지 없이 적용 |
| 약관 변경·중대한 불이익 변경·서비스 종료는 **관계 법령·적용 보호지침의 기간과 절차 준수** | 약관 제3조 제2항, 제6조 제2·5항, 제9조 제2항, 처리방침 14항 |
| 서비스 종료 공지 기간·문의 답변 목표 기간 등 **법정 의무 이상의 자체 약속은 확정하지 않음** | 해당 "확인 필요" 표시 삭제, 이의제기 기한 삭제, 관할은 「민사소송법」에 따름 |
| **만 14세 미만 가입 허용** 방향 유지 | 처리방침 10항, 약관 제5조 — 법정대리인 권리 안내, 동의가 필요한 처리를 하게 되면 법정대리인 동의 |
| **GRAC 질의 보류** 방침 유지 | 질의문 초안은 보관만, 제출하지 않음(§C3) |
| 운영자 정보 확정 전 **정책 초안 공개 방지 게이트 유지** | `LEGAL_RELEASED = false`, 운영 빌드에서 초안 제외(D-092) |
| **오픈소스 라이선스 고지는 독립 배포** | `#licenses`는 게이트와 무관하게 항상 포함 |

## 1. 법적 의무 · 권장 · 자체 약속 구분 (현재 무료 개인 운영 서비스)

"의무"는 국가법령정보센터 원문으로 확인한 조문만 적었다. 그 밖의 법령은 C4 조사 기준이며 원문 미대조다.

| 구분 | 항목 | 근거 | 초안 상태 |
|---|---|---|---|
| **법적 의무**(원문 확인) | 처리방침 수립·공개: 목적, 처리·보유 기간, 파기, 위탁, 권리 행사, 보호책임자 연락처, 자동 수집 장치 | 개인정보 보호법 제30조 제1항·제2항 | 처리방침 2~9·12항. 보호책임자·연락처는 운영자 확정 대기 |
| **법적 의무**(원문 확인) | 국외 이전 사항 공개(항목, 국가·시기·방법, 이전받는 자 명칭·연락처, 목적·보유 기간, 거부 방법·효과) | 같은 법 제28조의8 제1항 제3호 가목, 제2항 | 처리방침 7항. 국가·연락처는 운영자 확인 대기 |
| **법적 의무**(원문 확인) | 만 14세 미만: 동의가 필요한 처리 시 법정대리인 동의·확인, 아동에게 쉬운 고지 | 같은 법 제22조의2 제1항·제3항 | 처리방침 10항. 계약 이행 처리에 법정대리인 동의가 필요한지 ⚖ |
| **법적 의무**(원문 확인) | 처리방침과 계약 내용이 다르면 이용자에게 유리한 것 적용 → 실제보다 넓게 약속하지 않기 | 같은 법 제30조 제3항 | 미구현 기능은 "확인 필요"로 남김 |
| 법적 의무(원문 미대조) | 열람·정정·삭제·처리정지 요구 처리, 처리 기한 | 같은 법 제35~37조, 시행령 | "관계 법령이 정한 기간 안에" — 고유 기한을 따로 약속하지 않음 |
| 법적 의무(원문 미대조) | 안전성 확보 조치와 그 내용의 처리방침 기재 | 같은 법 제29조, 제30조 제1항 제8호·시행령 | 처리방침 11항, 관리적 조치는 운영자 확인 대기 |
| 법적 의무(원문 미대조) | 약관 변경·서비스 종료 시 공지 기간·방법 | 약관규제법, 콘텐츠산업진흥법 이용자보호지침 등 | "관계 법령과 적용되는 보호지침에 따름" |
| 법적 의무(해당 시) | 등급분류 또는 면제 | 게임산업법 제21조 제1항 제4호, 시행령 제11조의3 제2항 | 면제 해당 여부는 질의 보류 중 — 운영자 자체 판단(§C3) |
| **권장** | 이용약관 게시(무료 재화 성격, 이용 제한, 면책) | 분쟁 예방 | 약관 초안 |
| **권장** | 권익침해 구제 기관 안내 | PIPC 처리방침 작성지침 | 개인정보분쟁조정위원회만 기재(원문 화면에서 확인한 번호). 다른 기관은 원문 확인 후 추가 가능 |
| **라이선스상 의무** | 오픈소스 저작권·라이선스 고지 | 각 라이선스의 고지 조건(MIT·ISC·0BSD·Apache-2.0) | 항상 포함(독립 배포) |
| **권장** | 운영 정책(닉네임·관전 공개 범위·금지 행위·조치 단계) | 이용자 안내 | 운영 정책 초안 |
| 자체 약속 — **하지 않음** | 모든 변경 7일·30일 사전 공지, 서비스 종료 공지 기간, 문의 답변 목표 기간, 이의제기 기한, 변경 이력 보관 약속 | D-093 | 초안에서 삭제 |
